# 笔记篇 · 排一份 A4 物理复习笔记

用 Windows 版 InkStruct **0.1.74**，把练习包里的大学物理笔记排成 5 页 A4，再导出第一页的 SVG。只用电脑就可以完成。手边有写字机，可以接着试写一页。

## 1. 打开 InkStruct 并解压练习包

从下面的链接下载 Windows 安装包，按安装提示操作。安装完成后，从 Windows 开始菜单打开 **InkStruct**。[下载 Windows 版 InkStruct 0.1.74](https://github.com/lixiang1haoo-glitch/InkStruct-Public/releases/tag/app-v0.1.74)

<p><a :href="withBase(frontmatter.practiceDownload)" download><strong>下载笔记篇练习包 ZIP</strong></a></p>

在浏览器的下载记录里找到练习包，点 **在文件夹中显示**。在 Windows 文件资源管理器中右键点击 ZIP，选 **全部解压缩…**。打开解压后的文件夹，应该看到这三个文件。

| 文件 | 在哪里用 |
| --- | --- |
| `physics-notes.md` | 在排版页导入，作为笔记正文 |
| `physics-a4-template.json` | 在模板库导入，应用单页循环的 A4 版式 |
| `physics-notes.inkfont` | 在字体库导入，应用「学生篇练习字体」 |

## 2. 导入正文、字体和模板

1. 在 InkStruct 左侧点 **排版**。从上方 **文件** 菜单选 **导入 Markdown / 文本…**，在刚解压的文件夹里选 `physics-notes.md`。这是已经准备好的笔记正文，导入后左侧应出现「第五章 狭义相对论」。
2. 在左侧点 **字体库**，点 **导入字体…** 并选 `physics-notes.inkfont`。等导入完成，选中列表中的 **学生篇练习字体**，再点 **用于当前文档…**。等弹窗显示试排结果，确认显示 **0 项错误**，再点 **应用到本文**。
3. 在左侧点 **模板库**，点 **导入模板…** 并选 `physics-a4-template.json`。模板决定纸张大小和笔迹写在哪里。选中刚导入的模板，点 **用于当前文档…**，确认试排中的纸张是 **210 × 297 mm**，再点 **应用到本文**。回到 **排版**，右侧预览的每页上方应显示「墨构牌物理笔记专用纸」。

试排弹窗出现 **我已查看上述影响** 时，先阅读列出的问题，再勾选并应用。

## 3. 试排并保存

1. 排版页的 **字大小** 设为 **4.5 mm**，**行高** 设为 **6.6 mm**，**笔宽** 设为 **0.28 mm**。本例使用 **1.7 mm** 段距和 **3.0 mm** 标题段距。
2. 点 **公式设置… › 字号与字形**，把 **公式字号** 设为 **5.0 mm**，**独立公式对齐** 选 **左对齐**，**公式字距** 选 **按笔迹紧凑排列（推荐）**。
3. 在 **分式** 中把 **手写分数线** 设为 **字体减号 −（横向拉伸，默认）**。在 **根式** 和 **括号与定界符** 中把 **手写构件来源** 设为 **录制字形（缩放适配）**，再点 **应用设置**。
4. 在右侧预览确认文档共 **5 页**，翻到第 3 页，看分数线、根号和上下标是否清楚。若有文字显示为空框，先点 **查看问题** 找到出错的位置，再确认练习字体已应用到本文。
5. 点 **文件 › 保存项目**，将项目命名为「物理复习笔记」。保存后的 `.inkdoc` 是可继续编辑的 InkStruct 项目，下次可以直接打开。

## 4. 导出第一页 SVG

SVG 是记录笔迹路径的文件，写字机可以沿着这些路径写字。这个练习的 SVG 只包含笔迹，页面预览里的标题和分隔线来自练习纸张的底图。

1. 在 **排版** 页顶部点 **导出 SVG…**。在 **导出页码** 填 **1**，把 **横向比例校正** 和 **纵向比例校正** 都设为 **100%**。
2. 点 **选择输出位置…**，在桌面指定一个新文件夹，例如「物理笔记 SVG」。InkStruct 会创建这个文件夹。
3. 导出完成后打开该文件夹，将 `page-001.svg` 拖进浏览器窗口。看到第一页的笔迹，就完成了电脑上的练习。

### 有写字机时，试写第一页

1. 打开写字机厂家指定的控制软件。**炽写**是这类软件的一种。第一次使用写字机时，可以在机器的说明书里查软件名称。
2. 以 **炽写 3.0.310** 为例，在 InkStruct 的 **导出 SVG…** 窗口将 **导出页码** 填 **1**，把 **横向比例校正** 和 **纵向比例校正** 都设为 **132.293%**，导出到一个新文件夹。再在炽写中导入这个文件夹里的 `page-001.svg`。**132.293%** 是本例的校正值，你可以根据自己机器的试写结果调整。使用其他控制软件时，可以先导入按 **100%** 导出的 `page-001.svg`。
3. 先用一张 A4 草稿纸试写，检查字的大小和第一行的落笔位置。若大小合适但位置有偏差，先核对纸张放置方向和机器的起笔位置。若整页写得偏大或偏小，再调整 InkStruct 导出时的横向或纵向比例。每次只试写第一页，确认效果后再导出其余页。
