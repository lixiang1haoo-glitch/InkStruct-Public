# 常见问题

适用于 InkStruct **0.1.69 Windows x64**。第一次使用可以先跟着 [上手教程](./first-document) 做完一份短文。

## 安装提示缺少 Visual C++ 运行库 {#runtime}

安装版与免安装 ZIP 都需要 **Microsoft Visual C++ x64 运行库 14.51 或更新版本**。在安装器里选择打开微软下载入口，运行下载的 `vc_redist.x64.exe`。完成后重新运行 InkStruct 安装器。使用 ZIP 时，重新打开解压目录里的 `InkStruct.exe` 即可。[微软 x64 运行库下载](https://aka.ms/vc14/vc_redist.x64.exe) · [InkStruct Releases](https://github.com/lixiang1haoo-glitch/InkStruct-Public/releases)

如果安装过仍出现提示，检查安装的是 **x64** 版本以及运行库版本号。静默安装缺少所需运行库时返回退出码 `10`。

## 补录后何时纳入生成档案？ {#sample-updates}

回到 **生成**，先核对 **作者** 和 **样本目录**。目录与已导入索引有差异时，**样本与档案** 会提示 **有样本变化尚未纳入当前档案**。点 **开始生成**，应用会核对样本、自动更新索引与档案，再生成。准备失败时本次生成会停止，可从 **运行记录** 看原因，上一次成功的索引和档案仍可使用。

**成功导入份数** 是索引收录的样本数量。**有效供体数** 是当前方法建档后可用于生成的数量。若供体数偏低，检查录制时的笔画数量、笔顺和建档排除记录。切换作者时优先使用 **跟随采集目录**，手选外部目录前核对样本归属。

## 字体包里缺字，应该从哪里补？ {#missing-glyphs}

先看缺字出现在哪一步：

| 出现位置 | 怎样处理 |
| --- | --- |
| **生成 → 查看清单…** 显示结构库不支持 | 核对字符是否正确。本次生成范围可以先跳过该字符，或用适合正文的替代字。 |
| **生成结果** 的完成字数少于目标 | 展开 **运行记录** 查找未完成的字。同一作者补录或重录后，再用原字表或原文档生成。 |
| **待制包清单** 中汉字没有入选 | 确认当前 **本地汉字批次** 的作者和完成范围，且已勾选汉字类别。重新核对后再看预计覆盖。 |
| **待制包清单** 中缺标点、字母或其他扩展 | 进入 **采集 → 标点与扩展** 为同一作者补录。制包时核对 **标点与扩展来源**，展开类别查看缺字符、失效共用或合成来源。 |
| **排版** 中提示字体缺字 | 点 **查看问题**，在 **问题与定位** 中查看具体位置，确认当前文档使用的字体版本。补齐后制作新字体，并通过 **用于当前文档…** 检查试排影响。 |

制包列表用 **字符数 / 候选份数** 表示覆盖。有多份候选的字符只算一个字符。**同形共用** 和 **规则合成** 的覆盖随来源及勾选变化，可以点 **复用与合成规则…** 查看规则与本次结果。

## 取消生成后，还能使用部分批次吗？ {#partial-batch}

可以使用已完成并留下的字形。在 **字体库 → 制作字体…** 选择对应作者和 **本地汉字批次**，看批次的状态、完成数和目标数，再展开 **待制包清单** 确认它覆盖了你需要的字。生成页如果显示 **制作上次批次…**，旁边的作者、日期和完成字数说明按钮指向哪一批。

## 保存 Markdown 和保存项目有什么区别？ {#save-project}

**保存 Markdown / 文本…** 保存源码。**保存项目** 创建或更新 `.inkdoc`，下次用 **打开项目…** 可以继续使用文档的排版和已采用的字形选择。还需要独立分享字体时，可在 **字体库** 选中字体并点 **导出字体包…**。
