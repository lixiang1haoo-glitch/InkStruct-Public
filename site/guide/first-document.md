# 从录字到排版：做出你的第一份手写文档

本教程使用 Windows 版 InkStruct **0.1.72**。你会录下「一、二、三」各一份笔迹，制作一套三字字体，再用它排出两行短文。截图使用合成笔迹与示例目录，点截图可查看大图。

## 准备两份小文件

从 [GitHub Releases](https://github.com/lixiang1haoo-glitch/InkStruct-Public/releases) 下载 Windows 安装器或免安装 ZIP。用 ZIP 时，先解压完整目录，再打开 `InkStruct.exe`。安装器提示缺少 Visual C++ 运行库时，见 [运行库说明](./faq#runtime)。

用记事本创建两个 **UTF-8** 文件。字表决定采集哪些字，Markdown 决定最终要排哪些内容。

将下面一行存为 `练习字表.txt`：

```text
一二三
```

将下面的内容存为 `第一份手写文档.md`，两行之间留一个空行：

```text
一二三

三二一
```

## 1. 采集三个汉字

1. 在侧栏点 **采集**，进入 **汉字样本**。点 **新建书写者…**，输入显示名称，例如「练习书写者」。
2. 点 **导入 TXT / CSV**，选择 `练习字表.txt`。在 **确认汉字采集任务** 中检查书写者和任务名称，把 **CSV 空份数 / 默认份数** 改为 `1`。看到 **3 个汉字 · 共 3 份** 后，点 **创建并开始采集**。
3. 按当前目标字和左侧笔顺提示，在右侧画布上书写。点 **保存并下一个** 或按 `Enter`。按笔顺录完「一、二、三」。如果笔画数不符，先撤销、补写或重写当前字，再保存。

[![采集页正在录制三，左侧是笔顺参考，右侧已写三笔](/screenshots/01-capture.png)](/screenshots/01-capture.png)

*保存「三」之前，进度显示已保存 2 / 3，笔画数量匹配时可保存。*

出现 **任务完成** 提示，确认三份均已保存后关闭提示。之后可以从 **任务列表…** 找回这个任务。

## 2. 从短文提取目标并生成

1. 点侧栏 **生成**。在 **作者** 下拉框选择刚才的书写者。确认 **样本与档案** 显示该书写者及 **自动跟随采集目录**。如果先前选过外部目录，可以点 **跟随采集目录** 切回。
2. 在 **生成内容** 点 **从文档提取汉字…**，选择 `第一份手写文档.md`。两段虽然有六个字的位置，去重后只生成「一、二、三」三个目标字。可用 **查看清单…** 核对。
3. 选择 **v6.3 exp**，点 **开始生成**。首次使用会依次核对样本、导入并建档，再生成字形。若档案和样本都有效，后续可直接复用档案。若使用连笔样本，只有 v6.3 会将它们作为供体校验。[连笔录制说明](./faq#connected-handwriting)

[![生成页显示示例作者、样本与档案、目标和完成后的生成结果](/screenshots/02-generation.png)](/screenshots/02-generation.png)

*看「生成结果」中的本次完成字数。本例应完成 3 字，随后「制作字体…」可用。*

如果完成字数不足，先展开 **运行记录** 查看缺了哪些字以及原因。补录给同一书写者，再用同一份 Markdown 重新生成。[缺字处理](./faq#missing-glyphs)

## 3. 制作字体包并加入字体库

1. 在 **生成结果** 点 **制作字体…**。应用会打开 **制作字体包**，并带入刚才的汉字批次。
2. 填写 **字体名称**，例如「墨构练习字体」。确认 **本地汉字批次** 的方法和完成数，**包类型** 选 **用户版 · 用于排版与分享**。本例只需要勾选汉字批次，无需添加标点与扩展来源。
3. 等待 **待制包清单** 自动更新。展开汉字行查看字符，确认预计入包 **3 个字符**。界面分别显示字符数和候选份数，同一个字可以有多份候选。汉字行中的 **制包时核验** 表示完整核验将在制作时进行。
4. 点 **制作并加入字体库**。看到 **字体已验证并入库**，并在 **我的字体** 中选中新字体，即可用于排版。

[![制作字体包窗口显示本次汉字批次、待制包清单和制作并加入字体库按钮](/screenshots/03-font-package.png)](/screenshots/03-font-package.png)

*等清单更新完再确认本次覆盖。修改批次、来源或勾选后，软件会重新核对。*

## 4. 把字体用到短文并保存

1. 点侧栏 **排版**。在 **文件 → 导入 Markdown / 文本…** 中选择 `第一份手写文档.md`。左侧 **Markdown 源码** 应显示刚才的两行短文。
2. 回到 **字体库**，选中刚制作的字体，点 **用于当前文档…**。在 **更换本文字体 · 影响确认** 中，等试排结果出现。确认无新增缺字后，点 **应用到本文**。
3. 回到 **排版** 后，检查右侧 **页面预览 · 连续滚动**。两段文字应显示为你的笔迹，没有缺字占位。点 **文件 → 保存项目**，保存为 `第一份手写文档.inkdoc`。以后用 **文件 → 打开项目…** 继续编辑。

[![排版页左侧显示两行 Markdown 源码，右侧页面预览显示相应的手写字形](/screenshots/04-layout.png)](/screenshots/04-layout.png)

*项目文件会保存文档内容、排版及已经采用的字形选择。*

## 如果你的实际短文缺字

- **生成前就发现缺字。** 用 **查看清单…** 区分结构库不支持的字符和本次可生成的汉字。结构库不支持时，先调整练习文本。可生成的汉字在结果里仍缺失时，回到同一作者补录或重录，再生成。
- **制包时发现缺字。** 展开 **待制包清单** 对应类别，看是否缺原始样本、缺可用共用供体，或缺合成来源。勾选改动后等清单重新核对。若这一段文字需要该字符，先补齐来源，再制作新字体包。
- **排版时发现缺字。** 点 **查看问题**，在 **问题与定位** 中定位到原文，核对当前应用的字体版本。汉字和标点分别回到对应的采集页补录，再制作并应用新字体。应用前先看影响确认中的新增缺字和重新选样提示。
