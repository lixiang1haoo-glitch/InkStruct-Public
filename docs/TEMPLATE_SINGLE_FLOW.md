# 简单模板、自定义模板与单份 Markdown（0.1.23）

0.1.23 延续现有模板协议。英文字距设置保存在 FlowStyle v3；旧 FlowStyle v1/v2 保留采集字距与原排版，字体和模板协议不变。已有文档需明确选择应用新字距。

新模板使用 `inkstruct_page_template_v3`，新原生项目使用 `inkstruct_document_package_v3`，命名字段协议为 `inkstruct_named_fields_v1`，对应的 FlowStyle 为 v2。旧 v1/v2 模板、旧固定区源码块绑定和项目 v1/v2 保留原读取与排版路径。应用版本与这些协议独立。

## 制作与使用入口（0.1.22）

右上角齿轮打开“设置”。“排版默认设置 → 纸张与默认模板”只决定以后新建文档的纸张与默认模板，不提供立即编辑当前文档的按钮。

“模板管理”分开显示当前文档布局和可复用模板。当前文档通过“编辑当前文档布局”进入独立工作台；可复用模板通过唯一的“新建模板”入口选择简单或自定义，也可以导入已有模板、编辑副本。列表是显式导入/另存文件的最近记录，不扫描改写用户文件。未保存的默认设置在离开前选择保存、放弃或取消；工作台与设置分开确认。

自定义工作台左侧为起始页组、循环页组及未使用布局，中间为画布，右侧为对象属性和字段声明。页组可拖动或上移下移排序，新增引用与复制独立布局明确区分。点击选择文本框，拖动移动，拖动右下角缩放；精确毫米位置和尺寸始终可输入。选中框时直接显示框属性。正文编号和连接关系持续显示，共用布局修改影响所有实例。PDF 导入选择页面、物理尺寸和目标页组，完成后选中导入布局。

简单模板只显示纸张、四向边距与预览，不展示页组或字段工具。字号行距仍在排版样式中管理。所有修改进入统一草稿，支持撤销重做；取消不影响外部文档。无效输入保留并提示，确认前必须修正。不再设置每页的“应用草稿”。最终按钮明确为“应用到当前文档”或“保存为新模板”；另存不覆盖原文件，也不顺带修改另一范围。JSON 与旧布局显式迁移放在高级操作。

主界面右侧“模板”栏负责使用：显示当前模板和字段状态，提供更换模板、填写字段、复制写法/骨架、查看与定位当前实际适配问题。更换只改变模板，保留本份源码、样式、资源及冻结选样。模板操作通过编辑菜单和快捷键与正文按操作顺序撤销重做，移除常驻的模板撤销按钮。

填写字段使用表单，不再打开第二个完整正文编辑器；确认后修改本份唯一 Markdown，尽量保留未改变源码的稳定身份和原换行。重复字段或协议错误禁用表单写回，需定位主编辑器处理；可选字段未填写不会凭空插入。旧版模板仍通过“编辑旧版内容对应”使用原源码块绑定。

工作台的“试排当前文档”使用实际内容与冻结资源的独立快照，后台完成，不修改文档或选样。布局结构有效不代表实际内容通过；问题按错误/提醒显示，可定位字段、框或源码。没有当前文档上下文时明确标为示例预览。保留缺字、来源和纸面校准提示。

## 简单模板

简单模板为重复单页布局。纸张宽高和四向边距决定唯一正文区，字号、行距、段距在“正文与段落”设置。正文复用普通 Markdown 毫米排版器，自动换行和分页，未排完内容进入下一页。纸张与边距不会被写入正文。普通简单页面及旧文档原有统一边距也继续有效。

## 自定义模板

“页面组与文本框”左侧维护源布局、起始页组与循环页组。先选择源布局，再加入相应页组，通过上／下按钮排序；同一源布局可以多次引用。起始页组不循环，循环页组必须至少包含一项。源布局修改统一作用于所有自动实例，不单独编辑某张自动页。

PDF 可一次导入 1–64 个指定页面（如 `1-4` 或 `1,3,4`），按所选顺序替换起始或循环组，原布局保留。PDF 物理尺寸优先读取，默认采用首个所选页的尺寸，也可以保留当前纸张。在确认前显示原物理尺寸；每个布局保存 PDF 哈希、页码、原尺寸及独立嵌入背景。修改纸张时，背景分别按宽高拉伸铺满，框线和文本框保持毫米几何，出界时拒绝应用。多个不同原尺寸页面也遵循此明确规则。图片底图仍支持 PNG/JPEG；不识别字段、不描摹扫描内容。

正文框按明确的编号排序。画布显示编号与连接方向，左侧列出循环末尾返回首布局的关系；阅读顺序不取决于空间位置。字段框引用声明的字段标识，可在多个布局或多个框重复引用，独立排版，不推动正文续页。自动页码为独立框角色，实际文档页码连续递增。画布和预览都标识来源布局。

例如循环组为 PDF 1、2、3、4，则背景为 1、2、3、4、1、2……；起始组包含封面，则为封面、1、2、3、4、1、2……。

“末尾补齐整个循环页组”默认关闭。有正文时，关闭就在最后使用页停止（包括在起始组内结束）；开启仅补完已经进入的当前循环组，不凭空再增加一个循环。补齐页仍绘制固定字段和自动页码。空正文或仅字段时，起始组输出一次；没有起始组则输出首个循环布局，开启补齐时输出整个首循环。定义过但在实际页面没有字段框承接的内容会报错，不能静默丢失。

正文为空且没有正文框可以有限输出固定信息；正文非空而后续没有正文框，会停止并定位错误。不可拆的公式、图片、表格原子行组会尝试后续正文框；完整循环无法放入或无法推进时停止。原页数、结构、轨迹点数和严格成品导出限制保留。

## 单份 Markdown 协议

```markdown
:::field name
张三
:::

:::field student_id
20260001
:::

:::field experiment_title
单摆周期测量
:::

# 实验目的

这里开始是唯一的连续正文。

# 实验原理

这里可以正常编写公式、表格等已支持的 Markdown。
```

标识为英文字母开头，后接字母、数字、下划线或连字符，最多 64 字符，区分大小写。显示名“姓名”和框名称“封面姓名框”都不是标识。字段块外全部进入正文，字段内容不再出现在正文中。字段块可置于不同位置，建议集中在开头；不根据名称猜测归属。

同一标识重复定义、必填缺失或为空、未声明字段、缺少结束标记和嵌套字段块均为错误，正式导出前必须解决。缺少结束标记只把错误开头标记为语法错误，后续正文照常解析，不吞掉文稿。代码围栏内的标记按普通代码处理。可选字段缺失时留空。字段内部支持已有 Markdown，但必须完整放入固定框，溢出报错，不续流、不默认缩字或改变框尺寸。首版脚注仅用于正文，字段内的脚注明确报错。

字段声明的类型可选 Markdown、文本、数值或 ISO 日期；数值和日期执行格式检查。字段写法和包含全部字段的骨架可以直接复制。填写窗口编辑的是本份唯一 Markdown 草稿，确定时形成一个可撤销事务，尽量保留未改动源码段的稳定身份。

## 排版、诊断与导出

正文只解析一次，内核跨框传递尚未消费的测量项、列表状态与表格行组。每个正文框按自身宽度重新断行；不截断原 Markdown 重解析。源范围、冻结样本和资源身份保留。表格仍按已有原子行组续排并按设置重复表头；公式与图片不因进入文本框而放宽尺寸或导出规则。

脚注在实际页面的最后一个正文框底部安排。为使不同布局间的脚注续排使用一致测量，脚注正文使用各有效布局最后正文框的最小可用宽度，并在该框内左对齐，不改变字号；正文仍按各框自身宽度排版。字段脚注和无法容纳的正文／脚注组合均阻止导出。

预印纸只书写内容，PDF/图片底图仅作参考。空白纸只输出明确配置的框线及内容。毫米坐标与平移校准保留，显示缩放不改变输出。字形校正后越出所属文本框也报错。没有旋转、比例校准、OCR 或背景自动描摹。

“适配报告”来自本次真实排版，包含字段状态、源码定位、实际页面到源布局的映射及全部诊断。来源提醒与缺字规则不被关闭。报告通过不代表已完成实体数位板、打印机、写字机或纸面校准。

## 兼容与显式迁移

旧模板和项目按原版本读取，不自动改写文件、原文或绑定。旧项目可通过右侧“模板内容”首次绑定、修改或解除固定区源码块，原算法继续排版。旧的同名几何标识只作为原有对象关系使用，不根据“姓名”等显示文字推断内容。

迁移只显式复制旧几何、背景、来源与校准到新布局，并记录原 schema 和模板内容哈希；旧文件必须保留。原固定区绑定、锚点与倍率／页面策略需人工核对，不自动变成字段块。存在旧源码绑定的项目不能直接切入新字段模型；先保留原项目与模板，再在新项目中显式配置字段并编写单份 Markdown。新模板另存与外部文件更新不会扫描改写其他项目。

`.inkdoc` 嵌入本份 Markdown、模板配置、资源、身份和冻结选样，不依赖外部模板继续存在。外部模板更新不会偷偷改变已保存文档。
