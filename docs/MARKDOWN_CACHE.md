# Markdown 内容缓存

2026-10-13，第 9.3 节的缓存子项。编辑器已接入解析、资源解析、独立度量、完整布局、路由决定、Qt 页面 SVG 缓存，以及普通文档的前部块续排和后部页面收敛复用。模板正文已接通续排，固定字段重新合成；脚注协调状态已接通续排，最终脚注合成仍重算，不将完整快照或度量命中称为增量分页。

## 已实现的行为

同一份源码、身份、资源、选样和设置再次请求预览时，编辑器可以复用已完成的解析与页面几何。命中后重新绑定当前请求 revision；旧请求仍由原 request key 和 revision 检查拒绝发布。源码修改期间继续显示旧页面，但旧快照的评价和正式导出保持禁用。

缓存不进入 `.inkdoc`，关闭应用后不保留；项目中的源码、身份、资源和选样仍是权威数据。保存项目可复用符合当前请求的完整结果，但“保存期间的新修改仍未保存”的 generation 检查不变。人工评价不放入页面缓存，预览使用当前评价记录。

解析键包含原始源码、文档 ID、每个字符的身份锚点、Markdown 方言和数学语法版本，不包含临时请求 revision。相同文字重新创建了身份，不能复用旧源映射。

布局键额外包含完整冻结字形描述和池顺序、全部选样、种子、页面、正文及各元素设置、布局/数学/脚注/字段算法版本。字形几何、度量、源 JSON 和 provider 都参与比较，不能仅凭 asset ID 或标定标签复用。设置采用与快照一致的 JSON 表示，区分整数/小数及带符号零对持久化身份的影响。

首次布局前后的选样键可以指向同一条缓存记录，避免初次选样完成后立即失效；别名共享预算并一同淘汰。缓存仅存不可变结果和选样元组，每次返回独立 resolver/选样字典，不让下一次编辑改写缓存记录。

## 外部资源更新

生成目录和符号 ZIP 每次请求仍检查存在性、大小并读取当前内容；内容哈希相同才复用解析好的轨迹。即使文件大小、修改时间不变，内容变化也必须重新解析。标定变化会产生另一缓存键。失败结果不作为成功资源缓存，文件损坏、缺失或删除后不能回退到资源解析缓存中的旧文件。

这里缓存的是资源解析，**没有省略外部文件 I/O**。已内嵌项目资源的预览不需要外部目录或 ZIP。

## 容量与正确性边界

| 阶段 | 最大记录数 | 估算权重预算 |
| --- | ---: | ---: |
| 解析 | 4 | 16 MiB |
| 资源解析 | 256 | 32 MiB |
| 完整布局 | 2 | 192 MiB |
| 独立度量 | 4096 | 64 MiB |
| 前后部续排检查点 | 1 | 192 MiB |
| 路由决定 | 128 | 16 MiB |
| Qt 页面 SVG | 4 | 64 MiB |

采用加锁的 LRU，超过单项预算的结果照常返回但不缓存。估算包括源身份、语义/数学节点、选样、页面碎片、轨迹点、图片和键所保留的完整资源目录；共享对象可能重复计数。这些是淘汰权重，不是进程 RSS 硬上限，也不替代整个文档的工作量预算。

撤销会恢复源码身份，所以解析结果可以命中。但编辑过程中会增加选样记录，撤销后未使用的历史记录仍保留。若完整选样注册表与缓存不一致，则完整布局继续重算，避免返回错误 snapshot ID。不能据此承诺每次撤销都会命中页面缓存。

完成的纯解析结果可被后续请求复用；被取消的布局不写入完整布局缓存。取消信号在命中前后均检查，缓存不能绕过取消或旧任务发布门槛。缓存开关未作为普通用户设置暴露。

## 独立度量

正文行内盒、数学盒、表格宽高约束与单元格断行、代码网格可以独立复用。编辑器工作函数及单表出口建立请求局部的 `measurement_scope`，嵌套的模板和脚注多轮分页在同一作用域内复用；作用域使用 ContextVar，异常退出后恢复，不把一个工作线程的开关带入另一个线程。单独调用内核默认无缓存，也可以显式建立作用域。

键保留完整结构、字符身份、源码范围、字号/笔宽/比例/宽度等实际参数，以及度量、布局、数学和选样版本；不包含请求 revision 或取消事件。受控 dataclass/序列/设置参数的表示区分整数、浮点与带符号零。**偏移改变的旧盒不会直接搬用**，当前不做源映射重绑定；若前部插入导致后文范围变化，相应盒重新度量。

度量期间代理 resolver 记录实际字形依赖。命中时按原调用顺序重新解析每个 occurrence，恢复当前 resolver 的选样副作用，核对完整冻结字形值，包括轨迹、度量、原 JSON 和 provider。任一依赖不同或失效就重新度量；没有依靠 asset ID 相同就复用旧几何。资源解析失败的结果不写入度量缓存。完成的子度量可以保留，但被取消的当前度量不发布；命中前、依赖核对期间和返回前继续检查取消。若事件恰在完整记录插入后触发，调用仍抛出取消异常；已经完整计算的记录可保留供后续请求核对复用，不返回给已取消的调用。

缓存内部保存冻结记录；返回的列表、行列表与集合分别重建，调用者不能清空缓存中的结果。不同记录共同引用的 ResolvedGlyph 按对象引用计数只收一次权重，最后一个记录淘汰时释放该笔账目，其余记录内部对象做保守估算。此核算仍不是进程 RSS 上限。统计中的 hits 是依赖核对后实际复用的次数，invalidations 是候选存在但资源已变化的次数。

## 路由和页面预览

路由缓存仅存输出顺序与反转标志，键包含按输入顺序排列的端点、执行域、起点、优化开关、算法和成本模型版本。当前算法的距离搜索与空间扫描仅依赖这些端点；中间轨迹点不参与排序决定。每次导出都从当前已校验页面重建路径，保留当前全部点、笔宽、页面尺寸、路径 ID 和来源，再重新计算空行程及整页不退化检查。SVG 与 JSON 清单每次重新写入新目录，不缓存旧文件或文档身份。未来若排序算法使用笔压、绘制长度或中间点，必须同时扩展缓存键并更新版本。

整篇与单表导出共用每窗口路由缓存。输入更新不执行优化，优化开启时仍自动允许反转。单表的导出范围、省略格记录以及文档/快照身份按当前请求重新生成。导出对话框期间仍冻结已接受快照与优化选项。

页面缓存保留 Qt 已解析的 SVG，键包含渲染版本、页面配置表示、完整不可变页面与调试标志；不单靠 snapshot ID 或请求 revision。缓存读取前仍检查正式预览门槛，命中后更新当前快照与点击映射。人工评价、选中框和任务交互继续使用当前数据；缩放直接重绘矢量。每个 renderer 无 QObject 父对象，LRU 淘汰后可释放原生对象。此缓存只在 GUI 线程访问，通用 LRU 的锁不意味着 Qt 对象可以跨线程使用。

2026-10-14 补充：页面键在构造时只计算一次内容哈希，后续字典查找/插入复用该值，仍保留全部不可变内容参与相等比较；不同内容即使哈希碰撞也不会复用 renderer。未建立全局无界哈希缓存。SVG 点对序列化使用等价的六位小数格式，未改变点数、顺序或精度；54 页普通/调试预览的 108 份 SVG 与修改前逐字节一致。首次页面加载的分段及原生复测见 [性能记录](MARKDOWN_PERFORMANCE.md)。

这些缓存减少重复计算，不省略实际写文件和绘制，也不代表新增内容的增量布局或真实可见帧率达标。

## 普通文档的前部块续排（首阶段）

编辑器在实际源码变化、完整布局缓存未命中时，比较新旧已测量块的精确输入：源范围、字符和节点身份、当前选中字形的几何/度量/来源、断行、表格、图片和代码续行。此前的解析和全篇度量仍执行，因此当前选样副作用和测量诊断不会漏掉。页面、样式、文档 ID、限额及算法版本也必须相同。源位置改变的后文不做偏移重绑定。

每个块前保存分页检查点：当前页、该页片段/路径/图片数量、纵向位置、全局行号、前标题状态和布局诊断数量。复用前部完整页面及当前页的前部内容，然后从首个变化块续排；若它前面有 keep-with-next 标题链，一并回退。一个跨多页的大段落或表格仍以整个块为重排单位。检查点只保存计数，不为每个块复制此前所有页面。

返回的页面、源映射和诊断须与完整重排相同，snapshot ID 和 revision 按当前请求生成。复用路径仍计入全篇点数/页数上限；新增展开工作另行计数。取消、失败或超限不发布不完整检查点；若取消恰在完整记录插入后到达，该记录仍须在下次使用时核对。历史错误诊断仅复用已确认的前部，后部诊断重新生成。

该阶段支持普通正文、标题、列表、引用、任务、公式、代码、表格和图片。**有脚注或固定模板字段的外层布局及其内部辅助布局均禁用续排；普通模板也完整重排**，保留已有度量缓存。首阶段仅复用前部；后续加入的后部收敛复用见下节，不能将这些子项视为第 9.3 节全部完成。

每窗口保留一个检查点记录，上限为 192 MiB 估算权重。共享资源目录计一次，确认未变的前部块复用权重统计；页面点数采用保守估算。记录与完整布局、度量缓存可能共享对象，预算总和不是实际 RSS。超预算不保留记录，结果仍正常返回。内核单独调用默认无缓存；测试和脚本可显式使用 `continuation_scope`。`reused_blocks` / `placed_blocks` / `reused_pages` 表示完成构建中跳过和重新放置的数量，普通 `hits` 仅表示找到候选。

## 普通文档的后部收敛复用

在前部续排基础上，`exact-boundary-pagination-v2` 从文末核对最长一致后部。必须同时保留当前源偏移和身份、实际选中字形、测量/断行及结构内容；不能只比较文字或边界框。多处编辑时，第一处修改之后但最后一处修改之前的中间区段不会被误当作可复用后部。此前的完整解析、依赖核对、度量和测量诊断继续执行。

进入一致后部后，逐个块检查旧/新分页状态：页码、纵向位置、全局行号和前标题状态全部相同才停止重排。仅页面外观相同但全局行号不同仍不能复用，因为片段和结构线身份依赖行号。修改高度后可以先继续排版，直到后面的实际边界重新一致；无法收敛就排到文末。块数量可以变化，但后部各块的精确源位置和身份必须保持不变。

收敛所在页保留当前已排的新内容，只接入旧页的后部片段、路径和图片；它后面的完整 Page 对象直接共享。新旧前部的片段数、笔画数、图片数和诊断数可以不同，因此重新计算后部检查点在当前页的缓冲区计数，以及后续检查点的诊断偏移。后续编辑能继续使用这些检查点，不会回到旧内容数量。当前页面预算仍计入全部复用点，取消和超限不发布部分记录。`reused_blocks` 现在是前后部合计，并另列 `reused_prefix_blocks` / `reused_suffix_blocks`；`reused_pages` 只统计共享的完整页，不包含拼接页。

相同长度的中部编辑通常可以受益；前插或删除导致后文源偏移变化时，仍使用当前源映射重新排版，不重绑定旧偏移。脚注、模板、固定字段及其辅助布局仍完整重排。全篇解析和度量仍占用时间，因此跳过绝大部分放置工作并不保证端到端耗时同比下降。

### 回放中发现的有序列表身份修正

中部编辑回放暴露了原有的编号身份问题：改变列表起始数字时，后面条目的段落身份保持不变，但自动生成的编号文字会改变。原先编号第 i 个字符仅按段落和位置生成身份，结果拿旧数字的选样去解析新数字，报“Selected asset identity is incompatible”。

现在保留未变化编号的旧身份和选样；若同位置已有选样记录的字符与当前自动编号不同，为新字符分配带字符值的派生身份。重新修改、撤销、重做均保留各自既有选样。未改变字符但资源缺失或标定/选择不兼容时，仍报错，不借此重新选样。编号数量变化、新增列表条目及跨越 9/10 的情形有专项验证。布局版本增加 `marker-identity-v2`，使派生缓存失效；旧项目中未改变编号的几何和选择保持不变。


最终验证：专项 **94 passed**，全量 **1204 passed、4 skipped，64.05 秒**，相关 Ruff 和 diff 检查通过。25 个原生项目、128 页未缓存/首次缓存/续排快照一致，优化机器 SVG 与冻结文件逐字节相同。24 个含数字项目做实际中部数字替换，当前快照、源映射、诊断和选样均与完整重排相同；其中 22 个仍可导出，机器 SVG 也一致。另两项编辑分别制造重复脚注标签、无效 rowspan 网格，正确阻止导出；纯文字长脚注项目无数字，仅参与原样回放。

## 脚注协调状态续排

`footnote-pagination-v4` 将脚注游标、已开始定义、当前页预留、正文下界、已结束的脚注页和诊断纳入续排检查点。前部恢复这些状态；后部仅在输入、正文位置与脚注分页状态全部一致时复用。最终正文页扩展与脚注独占页排放从收尾前状态重新执行，脚注绘制与最终页面合成仍重算，因此不宣称已缓存整套脚注几何。

定义、引用映射、脚注设置或完整资源描述变化会使该记录失效，包括原 JSON 改变但笔迹相同的情况。固定字段中的脚注引用纳入协调输入。辅助定义标签布局不覆盖正文记录；内存计量包含脚注状态和度量单元，取消不发布半成品。
