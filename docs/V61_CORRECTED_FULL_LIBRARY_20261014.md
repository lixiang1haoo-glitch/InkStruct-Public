## 来源与缺口

每笔记录目标标准 ID/笔序、供体字、样本 ID、源笔画 ID、来源哈希、变换及来源类别：完整部件、关键笔替换保留部分、替换关键笔、作者单笔。无可靠作者来源则为明确缺口。

图册用橙色虚线显示缺口的诊断参考位置，不能视为作者笔形或完整可交付的全作者字体。每字显示缺口笔序，可展开逐笔来源，下载完整诊断轨迹与拒绝日志。诊断 JSON 含参考点时显式标记，不静默伪装作者输出。
