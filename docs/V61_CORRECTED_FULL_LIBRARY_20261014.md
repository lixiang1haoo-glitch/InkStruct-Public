# 修正后的 v6.1 exp 全库人工浏览

## 范围与入口

独立入口 `scripts/generate_v61_corrected_library.py`，复用当前候选扩展、位置变体、禁止拆分与作者单笔回退模块。生产默认不变。旧档案、旧全库与审查记录保持只读。

```sh
MPLCONFIGDIR=/tmp/inkstruct-mpl OPENBLAS_NUM_THREADS=1 .venv/bin/python scripts/generate_v61_corrected_library.py --output artifacts/v61_corrected_library_20261014/full_v1 --workers 8 --shards 2
```

全库按同字排除的跨字检验口径生成，不将同字原稿复用混入覆盖率。未引入验证原稿。已确认的来源/变换从原档案完整重建；其余目标执行当前完整部件检索。等比优先，保留已有最高 1.35 轴比的独立回退，逐笔记录变换。

启用 `author_reuse_no_split_v1`，禁止“尹→一＋尸”的组件拆分检索，保留完整尹、君及作者单笔路径。原数据库不改写。既有关键笔替换只复用已核查的位置变体计划，本次不开发通用替换器。

## 来源与缺口

每笔记录目标标准 ID/笔序、供体字、样本 ID、源笔画 ID、来源哈希、变换及来源类别：完整部件、关键笔替换保留部分、替换关键笔、作者单笔。无可靠作者来源则为明确缺口。

图册用橙色虚线显示缺口的诊断参考位置，不能视为作者笔形或完整可交付的全作者字体。每字显示缺口笔序，可展开逐笔来源，下载完整诊断轨迹与拒绝日志。诊断 JSON 含参考点时显式标记，不静默伪装作者输出。

## 正确性及加速

批量作者单笔检索仅缓存/向量化等比仿射下等价的检索描述符，输出仍使用完整原轨迹；候选桶、排序规则、32 个候选上限、映射/端点/长度/边界以及真实笔段接触准入不变。生产不导入该加速模块。

小批次 60 份回归/扩展案例及 200 份分散目标完成，无生成失败。48 份已有人工审查案例来源几何重建一致。四作者各 120 次真实笔画查询，共 480 次：加速与原检索供体一致、拒绝计数一致、输出坐标最大差为 0，压力/笔内时间一致。必要单元测试 39 项通过。

新结果逐字检查协议、源点/压力/笔内时间保真、退化及相对旧全库的真实笔段交叉和三档笔宽接触。共同变换的原作者完整部件内部关系单独标为继承关系，不作为新增跨部件损伤报警。其余变化仍是人工复核提示，不能自动当成字形缺陷。

“群”的穿头验收按人工澄清：两横穿过长撇，不要求长撇伸过顶横。本轮不重新打开该已确认问题。

全库浏览不属于新留出验证；全作者覆盖率、指标通过均不等于字形或风格质量合格。
