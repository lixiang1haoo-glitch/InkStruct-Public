## 1. 结论

已实际完成92个档案—字组合的A/B/C/D/E对照、完整轨迹来源核验、真实笔段/端点间隙与笔宽接触检查，以及整字、折角、短钩、自然圆弯图文报告。

局部结果有限：固定供体的小幅整体平移能解除wsq、user_001“儒”的雨部与下部接触；候选重排也有减少接触的案例。但C/E的原稿几何均差相对B仅降低约0.053%，D反而增加约0.024%，有效原稿变化来自wsq“宵”一个组合，不能声称整体风格提高。候选重排还有加粗笔宽的新增粘连反例。

因此：保留分阶段接口、距离诊断和负面结果；固定供体布局值得继续小范围人工预览；不扩大当前候选重排权重，不将E默认上线。

## 3. 实际重设计的阶段和旧层去留

实现于 `src/inkstruct/v61_exp.py`，精确接触工具在 `src/inkstruct/v61_contacts.py`。这是基于v6的实验适配层；仍通过v6取得冻结基线及原候选提案，没有另建重复档案库，也没有宣称生产核心已全部替换。

| 阶段 | 本轮接口与职责 | 保留、替换或绕过的层 |
| --- | --- | --- |
| 内容结构 | `prepare()`复用已验证的修正层、ID/笔顺和0.85共同等比参考框 | 保留v6版本桥接；不增加结构修复规则，不重新对齐 |
| 作者实例库 | `source()`按采样哈希和标准ID读取冻结的完整实例 | 保留完整整字/部件数据；整字同字复用与整字→部件跨上下文准入不在本轮扩展 |
| 候选提案 | `Placement`记录完整部件ID、供体、原共同变换和原分数；`prepare()`冻结最多16个原合格提案 | 保留旧检索池和拟合方法；不以重建档案改变基线 |
| 候选选择 | `select()`只重排提案，不重新拟合 | 把旧边检索边装配的选择职责显式拆出；用作者末向特征和跨部件接触提示作研究性补充 |
| 统一布局 | `layout()`只调整冻结供体的完整部件平移，最终参数进入同一计划 | 平移集中在一个阶段；不恢复旧全局/部件/单笔多层残差，不改端点或逐笔缩放 |
| 轨迹输出 | `emit()`从原始来源按最终计划装配一次；复用既有`assemble()`重排输出时间 | 保留完整几何、压力和笔内时间；原参考回退另作明确标签；不再叠加一次输出后形变 |
| 验收回退 | `validate()`分列协议、严格交叉、笔宽接触、原有参考支持接触和退化；`finish()`返回计划及证据 | 复用协议检查，新增实际笔段验收；旧包围盒关系不作为接触判据；风格仍待人工，不合格提案保留B或参考 |

旧8点、实例形状平均、全笔B-Spline和多层残差仍被绕过，但这是沿用v6，不是本轮删除的新层。原v4及v6模块未改；没有新风险分类器、随机模型或神经网络。

## 4. 候选和布局的固定规则

### 候选C

保持B的候选池、每个候选的原等比拟合变换、目标参考和档案不变。原形态/位置匹配分数之外加入：

- 同作者、相同当前部件上下文池内的末向特征距离；每个供体字符一票，重复样本不会增加该字符权重。末向取笔内最后10%弧长方向，特征权重0.01。仅比较特征，不平均输出形状。
- 对参考中明确分离的跨部件笔段，惩罚输出在0.028笔宽内的覆盖量。参考距离大于0.035才进入这一软提示；不追求把输出间距拉到参考的精确数值。

只考虑比保留B分数更低的候选，再做安全检查。保持原长度比0.4–2.5限制，拒绝相对B新增严格交叉/笔宽接触，以及破坏B已有且参考也支持的接触。所有重排分数、未验候选和已拒原因有日志。该规则偏保守，会拒绝作者可能合理的新接触，不能解释为通用风格判别器。

### 布局D

固定B的供体；只将整个作者部件平移，最多一个显示笔宽0.028，步长0.014，欧氏平移量受限。每个部件以冻结初始变换为起点，一次固定顺序搜索；没有旋转、异比缩放、笔内形变或逐笔独立操作。

目标为减少参考分离而输出粘连的跨部件覆盖，加小量位移惩罚0.02。不修改供体内部间距、不主动闭合开口、不移动参考回退笔来伪装个性化。采用同一安全门槛。是有界、固定顺序的一遍搜索，不是全局最优布局求解。

E先冻结C选定的供体，再用与D完全相同的方法布局。C与D的贡献不能简单相加：C如果已消除某处接触，E不会再做D的平移。

参数由开发阶段的笔宽尺度与已有安全边界确定，一次冻结；没有搜索目标原稿最优参数。看到评价结果和0.05笔宽反例后没有继续调参来掩盖负面结果。

### 新增损伤：笔宽改变后候选重排失效

追加0.014、0.028、0.05笔宽敏感性检查，不用于重新调参。前两档C/D/E没有相对B新增接触对；0.05时wsq“宵”的C/E新增第1、3笔粘连：

- 原稿中心线间距0.07219；B为0.05119；C/E只有0.03027。
- 0.028细笔显示时仍分离，0.05时两笔覆盖；原稿在同一显示条件下不接触。
- 这是只优化外部间隙/平均几何未充分保护部件内部笔宽关系的反例。D无这一新增粘连，但其原稿几何距离仍退步。

所以“0.028门槛通过”不能写成“没有新增损伤”；现阶段C/E不具备不受笔刷条件限制的正式试用证据。

## 9. 继续范围与默认替换前的证据

1. **已完成的迭代**：候选/布局职责可独立对照；实际笔段接触与笔刷敏感性可复核；保留了正面、小幅无效和负面案例。不是全面解决相、儒、mjb、饿、叵。
2. **可小范围试用**：显式研究预览中提供B/D切换、限定笔宽与来源/回退提示，人工复评儒等少数间距案例；距离诊断可用于审阅。不是默认批量生成升级，当前C/E更不宜无条件接入。
3. **值得继续但需改变问题切入点**：优先审计“同名完整整字/其他上下文实例存在、当前候选池却空”的目、我、口。先验证角色和形态适配再谈放宽，固定其他因素另做准入实验。不要盲目提高重排权重或把平均末向当作者风格。
4. **验收改进优先于增加模型**：区分供体已有内部交叉与放置产生的跨部件碰撞；将实际渲染笔宽作为明确输入，保护内部与外部间隙，不能只在细笔刷下优化接触数量。
5. **距离默认替换仍缺**：独立人工A/B、新且真正未参与开发的留出、参考回退个性化不足的解决证据、mjb等作者反例的改善，以及实际笔刷/输出设备一致性。当前微小均差收益不足以支持扩大或默认替换。
