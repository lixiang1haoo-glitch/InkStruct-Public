# InkStruct 0.1.66 · Windows

解压完整的 `InkStruct-0.1.66-Windows-x64.zip` 后运行 `InkStruct.exe`。

- Windows 11 可用时加载 Qt `windows11` 样式。侧栏、生成页、正文设置和制包清单随系统深浅色切换。标题和主操作用少量 QSS 强调，输入框、步进按钮和表格由原生样式绘制。样式插件不可用时使用原有 Fusion 外观。
- 主窗口继续使用系统标题栏。侧栏图标随系统调色板更新，选中图标在系统强调色上保持辨识度。
- 正文设置中的数值框按 Enter 会保留草稿。「恢复本分类初始值」可显式选择。
- 制包仍按当前勾选核对清单，清单失效时禁用制作。完整验证通过后，新包才原子入库。
