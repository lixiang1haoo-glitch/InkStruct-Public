## 实际改变了什么

在原模块增加可关闭的 `expand` 路径，默认不填充任何新来源；已有 `probe` 有限人工复核路径仍可重现。生产入口没有导入新扩展。

1. **先验证来源，不为覆盖降低映射可靠性。** 重查来源身份/哈希、完整标准 ID 序列、已声明或已纠正的笔顺、部件完整所有权、源部件置信度、单笔至少 0.30 与部件均值至少 0.55 的原映射门槛。原候选必须属于冻结的同作者、同角色可靠池；完整整字进入部件须通过原有显式角色桥和有序参考对应验证。
2. **以实际来源判断内部几何是否受损。** 源内部严格交叉集合与变换后集合必须相同。完整来源里已经存在并原样保留的交叉，记作“来源继承”，不再仅因字体参考没有该交叉而拒绝。它不是“每个内部交叉都天然好看”的质量标签。
3. **新增外部关系仍需拦截。** 正等比变换、笔数、标准 ID/笔顺、有限坐标、压力、全局非递减时间、最终边界和非退化检查保留；新增跨部件严格交叉或固定 0.028 显示笔宽下的新接触仍拒绝。接触按真实折线距离计算，不看包围盒重叠。既有接触不因此自动判为错误。
4. **参考差异作为诊断。** 作者笔画弧长与参考的比例超出旧 0.4–2.5 界限、原有且参考支持的边界接触消失，在独立 C 路径中仅记录，不单独否决。目标原稿完全不参与准入。内容/标准映射验证仍需参考，不是删除全部参考依赖。
5. **只填回退位置。** 原已接入来源及变换不动；已有候选的排序和拟合不改，整部件共用一个等比变换，所有原始点、压力、笔内时间差原样保留，再按最终笔顺安排输出时间。没有固定点数压缩、平均轨迹、平滑或逐笔混搭。

## 冻结四路对照

选定既有 100 个档案—目标组合：user_001 的 31 字，以及 scx、mjb、wsq 各 23 字。均为已经观察的开发/回归案例，不冒充新留出。所有目标及其重复采样按字符整组排除来源；46 组具有 56 份合格原稿，全部输出及哈希冻结后才用于本次评价。

| 路径 | 改变因素 | 与前一路的实际区别 |
| --- | --- | --- |
| A | 当前冻结结果；user_001 已含上一轮铜/伯 | 逐笔重现基线 |
| B | 固定原候选池/拟合，区分源内部交叉与新外部交叉；旧参考差异门槛保留 | 新增震的辰部 7 笔 |
| C | 同池/拟合，再将参考弧长与接触差异降为诊断 | 100 例均与 B 相同，无额外实测覆盖收益 |
| D | 固定 C 的已接入来源，扩展完整整字→部件的可靠角色桥 | 新增叵的口部 3 笔 |

D 是角色/来源池扩展；B 是准入解释修正，均不应描述成候选排序或布局优化。C 在本批只证明修改未产生额外输出变化；边界测试验证了参考长度差异不再独立硬拒，但不能据此声称有质量收益。

- **100×4** 输出的笔数、标准 ID/笔顺、有限坐标、压力范围、非递减时间、越界和退化检查通过；全部来源点、压力和笔内时间差精确核对。所有原已接入来源及其变换保持不变。
- **98/100** 组合的全部笔画内容不变，包括铜、伯、而、相、儒、荡、饿，以及三个其他档案的全部案例。叵原来也是保护字，本轮为有明确来源证据的预期改变，不伪称它仍不变。
- “不变”比较坐标、压力、时间、标准 ID/笔顺及置信度；沿用 v61 输出器会更新部分来源描述标签，不将标签词汇变化计入字形变化。
- 新增严格交叉 **6 对**：震 4 对、叵 2 对，均在新部件内部且逐对追溯到源。新增跨部件严格交叉 **0**。不能笼统报告“零新增交叉”。
- 显示笔宽 **0.014、0.028** 下，新增跨部件接触 **0**。笔宽 **0.05** 下，震第 **4/9** 笔出现一处新接触：最小中心线间隙 **0.038451**。这是放置后的跨部件风险，区别于作者原有内部交叉；未删去反例或看完原稿再调参。
- 本次实际准入器使用固定 0.028 诊断笔刷；**不能把新震直接用于 0.05 粗笔宽并声称已经通过验收**。该场景保留原结果或另做针对布局的独立验证，尚未实现根据渲染笔宽自动回退。真实压力笔刷、设备实写仍是不同验收范围。
