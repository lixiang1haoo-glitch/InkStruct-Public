# InkStruct Markdown 生成规范（供 AI 读取）

当前主应用版本为 InkStruct 0.1.43；Markdown 命令协议为 `break-commands-v2`。当前预览源码更新已合入主项目，独立目录和历史产物保留。

## 输入与输出约定

预期工作流：用户给 AI 本规范、内容要求和模板信息，AI 生成可复制粘贴或导入 InkStruct 的 Markdown，用户预览并导出。无需用户逐字编辑或通过界面插入控制符。

生成前需知道用户要写的内容，以及使用普通页面还是连续正文流模板。若用户要求指定正文框，需知道每页正文框顺序；若涉及固定字段，需得到实际字段 ID。未提供的信息不编造。未要求手动定位时依靠自动续排，不插入多余控制符。

最终只输出 Markdown 源码；不要加解释性前言、聊天数学分隔符或包裹整篇的代码围栏。只有文档内容本来是代码时才使用围栏。用户另有输出要求时按用户要求处理。

## 正文和结构

可使用段落、空行分段、`#` 至 `######` 标题、`**强调**` / `*强调*`、有序和无序列表、引用、分隔线、行内代码和围栏代码。链接排可见标签，不自动读取目标。任务列表使用 `- [ ]` / `- [x]`。

表格使用标准管道表；复杂合并表格须遵循 [复杂表格支持](COMPLEX_TABLE_PAGINATION.md)，不要凭一般浏览器支持推断任意 HTML/CSS 可用。表格单元格内使用 `\newline` 换行。

## 换行、分页、换框

| 用户意图 | 必须生成的语法 | 适用范围 |
| --- | --- | --- |
| 新段落 | 空行 | Markdown 正文。 |
| 段内强制换行 | `\newline` 或 `\linebreak` | 正文、表格单元格、脚注、固定字段。 |
| 下一张纸 | `\newpage` 或 `\pagebreak` | 普通页面或模板正文；跳过同页剩余正文框。 |
| 分页并清空浮动图表 | `\clearpage` | 当前没有浮动队列，可见效果等同下一张纸。 |
| 下一个正文文本框 | `\framebreak` | 仅连续正文流模板；下一框可能仍在同一张纸。 |

不要用分页命令表达换框。不要在固定字段、表格单元格、脚注、图片说明或公式内插入分页/换框命令；这些位置不能推进正文。普通页面的 `\framebreak` 不生效。强制断开使用默认强度或 `[4]`；不要用 `\linebreak[0..3]` / `\pagebreak[0..3]` 承诺确定位置。

推荐让分页/换框命令独占一行；紧接英文单词时用 `{}` 终止，如 `\newpage{}Next`。字面命令按 Markdown 反斜杠规则转义或放在代码中。命令名区分大小写。

例子（假定每页两个按顺序续排的正文框）：

```markdown
# 测量记录

第一框的首行。\newline{}
第一框的第二行。

\framebreak

同一张纸的第二框。

\newpage

下一张纸的第一框。
```

## 数学

文件中的行内数学使用 `$...$`，独立数学使用单独成行的 `$$...$$`。不是完整 TeX：只生成 [数学语法清单](MATH_SYNTAX.md) 明确列出的命令和环境。不得生成任意宏、`\usepackage`、`\documentclass` 或完整 LaTeX 文档。

常用形式：`$x^2$`、`$a_{ij}$`、`$\frac{a}{b}$`、`$\sqrt{6}$`、`$\left(\frac{a}{b}\right)$`、`$\overline{AB}$`、`$\hbar$`。统一使用花括号包住参数和上下标，减少边界歧义；`\frac1` 缺分母，是错误。多行公式使用 `aligned`、矩阵、`cases` 或 `array` 等受控环境中的 `\\` / `\newline`，单个公式盒不会自动跨页、跨框或折行。需要分页时先结束公式，再在正文中写控制命令。

## 字段、资源和方言

模板明确提供字段 ID 时，可按 [连续正文流规范](TEMPLATE_SINGLE_FLOW.md) 使用 `:::field 实际ID` … `:::`；其他内容作为唯一正文流。字段 ID 不是框的显示名称，不自行发明字段或把正文拆成多个固定字段。

字符可解析不等于手写字形齐全。内置单线资源只覆盖数字和小数点；中文、英文、物理符号等需要对应资源或已支持的合成规则，缺字不能靠写入系统字体名称解决。`\hbar` 由已有 h 和减号合成；全角 `．` 可复用英文点。图片和单线 SVG 需走实际资源导入流程，不虚构可用文件路径。Obsidian 扩展只在选定对应方言时使用，详见 [支持矩阵](MARKDOWN_SUPPORT_MATRIX.md)。

生成后检查：命令在清单内；数学分隔符和环境配对；分数有分子和分母；“下一页”与“下一框”匹配用户要求；字段 ID 存在；没有把解释文字、占位路径或代码围栏误作正文。

完整边界、弱强度及旧项目迁移见 [换行、分页与换框](TEXT_FLOW_BREAK_COMMANDS.md)。

## 排版设置与问题反馈

两端对齐、自然书写的笔画/倾斜、大小、字距、基线变化均在正文设置中配置，不是 Markdown 命令。不要插入随机空格、替换字形或发明控制符；自然书写默认关闭，旧项目不自动切换算法。详见 [自然书写说明](LAYOUT_JUSTIFY_HAN_VARIATION.md)。

问题面板可按原因分组、逐处定位并复制完整报告。显式“强制导出 SVG…”仅输出已有有效笔迹，缺口留空并报告；不意味着原文档已完整通过常规导出校验。
