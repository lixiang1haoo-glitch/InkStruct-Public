# 符号目录与复用

采集与制包共用类别。正体和斜体分别采集。旧英文样本没有写法标注时，单独显示「写法未标注」。目录之外的已有字符列出实际编码，按自己的有效录制使用。

| 类别 | 收录字符 |
| --- | --- |
| 英文正体、英文斜体 | 各含 `A–Z`、`a–z` |
| 数字 | `0–9` |
| 希腊字母 | `Α Β Γ Δ Ε Ζ Η Θ Ι Κ Λ Μ Ν Ξ Ο Π Ρ Σ Τ Υ Φ Χ Ψ Ω α β γ δ ε ζ η θ ι κ λ μ ν ξ ο π ρ σ τ υ φ χ ψ ω` |
| 希腊字母 · 变体 | `ϐ ϑ ϕ ϖ ϱ ϵ ϰ ς` |
| 括号、书名号与定界符 | `() [] {} （） ［］ ｛｝ 【】 《》 〈〉 「」 『』` 及竖线 |
| 标点与连接符 | `.,:;?! ．，：；？！。、 "' “” ‘’ - – — … ～` |
| 单位与量值符号 | `% ％ ‰ ° ′ ″ ℃` |
| 数学符号 | `+ − × ÷ = ≠ ≈ ≡ ± ∓ < > ≤ ≥ ∞ ∑ ∏ ∫ ∮ √ ∂ ∇ ∈ ∉ ∋ ⊂ ⊃ ⊆ ⊇ ∪ ∩ ∅ ∀ ∃ ¬ ∧ ∨ ⇒ ⇔ → ← ↔ ↑ ↓ ∝ ∠ ⊥ ∥ · ⋅ / * ∗ ∶ ∘ ℏ` |

同一目标和写法的有效独立录制优先。

- **同形共用**默认启用，共 13 对。半角与全角分别保留编码和排版宽度。只有一边有有效录制时，其笔迹可以供另一边使用。白名单为 `，↔,`、`．↔.`、`；↔;`、`：↔:`、`！↔!`、`？↔?`、`（↔(`、`）↔)`、`［↔[`、`］↔]`、`｛↔{`、`｝↔}`、`％↔%`。
- **英文正体与斜体共用**只用正体补缺录的同字斜体，笔迹保持原样。**拉丁正体与希腊大写共用**限白名单。希腊大写 `Α Β Ε Ζ Η Ι Κ Μ Ν Ο Ρ Τ Υ Χ` 可分别使用正体 `A B E Z H I K M N O P T Y X`。供体样本的类别可以不勾选入包。两组默认关闭自动补缺，采集任务中已有的单项供体默认沿用。可整组启停，也可逐字覆盖。规则启用后自动使用有效供体。指定具体笔迹时可预览并选用，指定来源失效后须重新选择。
- **规则合成**默认启用。目标和合格来源都须属于本次选择。规则为 `– ← −`、`～ ← 双笔 ≈`、`℃ ← 。+ 正体 C`、`* / ∗ ← 单笔 −`、`∶ ← ：或 :`、`∘ ← 。`、`ℏ ← 录制 h + 单笔 − 或 -`。来源不足时，规则表会给出实际原因。

在制作字体包中展开类别可以查看每个字符。打开「复用与合成规则」可按字符、规则类型或本次状态筛选。逐条设置「本次启用」，另外查看供体确认和当前核对结果。全半角共用与规则合成默认启用，仍可在本次停用。应用后自动核对，关闭制包窗口后恢复默认和任务确认。全角与半角的同形对在采集任务中只占一个录制项。历史任务保留创建时的目录协议和逐字索引。
