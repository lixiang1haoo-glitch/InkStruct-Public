# 脚注：源码语义与分页实现状态

目前完成定义/引用解析、稳定来源关系、手写上标编号及基础页底协同分页。正文、标题、列表、任务、引用、代码、公式、表格、单线图形和分隔线可以与脚注共同生成页面及写字机 SVG；普通位图仍仅能生成参考页面。已提供“脚注设置…”和项目参数保存。脚注定义内部已支持表格行组、图片/图形与分隔线。已支持固定填写区引用，以及直接以标题、列表、任务、代码、公式、表格、图形和分隔线开头的定义。Windows 与真实纸面验收仍待完成。

## 已实现的语法契约

```markdown
正文[^测量]，再次引用[^测量]。

[^测量]: 脚注第一段。
    同段续行。

    脚注第二段。
```

- 标签区分大小写，长度 1–64 个 Unicode 字符，不含空白、方括号、反斜线或控制字符。
- 定义只能是顶层块；允许置于首次引用前或后。续行缩进至少四列，制表符按解析器的四列制表位计算；空行后的缩进段落仍属于同一定义。
- 按正文首次引用顺序编号。重复引用共用定义与编号，各引用保留自己的源码身份；定义顺序不决定显示编号。
- 定义正文保留普通 Markdown 结构和精确来源，可解析强调、链接、列表、任务、代码及公式；首块可为已支持的文字或结构块。结构块开头使用独立编号栏，原列表序号、任务框和表头保留。空代码或空引用块也保留编号与高度。
- 代码、转义、数学及原始 HTML 内的字面脚注文本不被重解释。管道表格中的普通 Markdown 引用可识别。受控 HTML 表格内文本继续遵守原有 HTML 语法，不额外解释 Markdown 脚注。
- 缺失定义、重复定义、未引用定义、空定义、嵌套定义及定义内再次引用均给出源区间错误。当前没有静默忽略未引用内容，也不允许递归引用。
- 单文档上限为 128 个定义、1024 次引用，定义解析深度上限 16；超预算终止解析。

## 身份与显示

原始标签和定义内容不会因编号写回而改变。定义和引用节点基于源原子建立身份；数字实例基于源标记、数字槽位及显示数字建立身份。插入更早的引用后，正文及已有节点身份保留，需要重编号的数字获得新的选样身份，避免将原先数字 1 的资产误用于数字 2。撤销与项目重开恢复原始来源关系。

引用标记使用项目中的实际数字轨迹，字号默认是所在文字的 70%，基线抬高所在文字 em 的 45%；不使用普通字体轮廓，也不依赖独立的公式字号。一个多位编号为不可拆分的排版盒，且不与前一文字之间断行。过小字号和缺少数字样本明确报错。这些比例可在脚注设置中修改，对正文、标题、表格和图题引用共同生效。

## 页底区域与前进性

正文试排一行时，同时检查它所引入的脚注开头是否放得下，确认后才画入页面；后续正文不能压缩已预留的注释内容。放不下则先换页，不需要在已输出的两种布局之间反复回退。多个同线引用为各自定义保留至少一行。重复正文引用不重复整条定义。

脚注文本默认使用正文 70% 字号、75% 最小行高，分隔线默认位于左侧 30 mm 范围内，线两侧各留约 2 mm 净距。有正文继续排版时，脚注通常使用正文区不超过约 40% 的高度；同线多个必要开头可扩展占位。正文结束后，剩余脚注可以使用当前页及续页的可用高度，不再受这个比例限制。脚注整体靠有效正文区底边放置。

长脚注逐行续页，页首续注重复原编号，重复实例携带相同来源和选样并标为 repeated；注释正文不重复。标题与下段的同页检查纳入脚注占位。若引用行及必要注释开头无法同时放入空页，或单行脚注超过整页高度，保留调试几何并报错；每次换页必须消费正文或脚注行，不无限循环。

预印纸/空白纸模板使用各页有效正文边界。固定字段可带引用，在首次显示的首页预留注释开头；重复字段继续显示原引用编号，定义正文只输出一次，必要时续页。编号按源码首次引用顺序，同页注释按编号排序，不因字段移到页面顶部而重编号。固定字段与正文可共用同一定义；无法在首页容纳时明确报错。定义本身仍属于页底区域，直接绑定定义会诊断并保留原来源。脚注路径使用独立执行区间，严格沿用 path/M/L 导出与排序/反转保真，不跨页重排。

## 表格、图形与分隔线

管道表格的表头和单元格可放置引用。表格逐个原子行组试排，将表头、合并单元格连接的完整行组、框线笔宽和该组引用的注释开头一起计入容量；正文已有的脚注也会挤占表格空间。重复表头的引用编号沿用原身份和选样，标为 repeated；同一注释不因表头重现而重新输出。受控 HTML 表格可以与正文脚注共存并保留 rowspan 行组，其文本仍不额外解析 Markdown 脚注语法。

独占一段的图形及图题整体试排，图题引用的注释开头必须与图形同页，多行图题的引用全部纳入检查。单线 SVG 沿用机器导出能力；位图可与脚注共同生成参考页面，但实际 RasterOp 继续阻止机器导出。源码中行内嵌图本身仍是未支持组合，其引用无法放置时明确报错，保留注释调试内容，不产生内部覆盖异常。

正文分隔线使用原来的毫米规则线，并参与脚注空间检查。无法容纳的空页图形/行组与必要脚注会给出错误，仍只输出一次调试实例，不反复换空页。

## 定义内部的表格、图形与分隔线

定义可以直接以结构块开头，也可在首段之后按四列缩进加入管道表格、受控 HTML 表格、独占段落的图片/单线 SVG 和分隔线。分页内核 `page-footnotes-v3` 从共享渲染器收集这些块的完整测量记录，不将表格单元格误当成连续文字行，也不丢弃没有文字实例的规则线。

表格沿 rowspan 连接的行组切分，首个表头与首个数据行组保持整体。续页按该表的重复表头开关绘制；重复表头共用源实例和字形并标记 repeated。分页预留包括表头高度，同行组/相邻行组共用边框只计算一次笔宽，最终合并重复或共线的规则线；不会合并或改变字形笔画。空单元格、纯表头、无表头表格和注释内多个表格均保留可绘制框线。

图片与完整图题作为原子单元。位图的 RasterOp 随注释位置平移，只允许参考导出；单线 SVG 继续使用 path/M/L。没有后续文字的分隔线也有独立单元，续页重复编号的最小高度独立计入预留，避免短规则线使编号越界。无法容纳的原子单元消耗一次并报告 `footnote-line-height-overflow`，包括没有字形的空行组，不进入空页循环。

结构块开头的注释，每段分页分配末尾另预留脚注最小行高的四分之一，避免相邻定义的表格框线贴合；原文字开头的注释不增加此间距。此高度参与试排，不挤压原单元。

表格和图片保留各自的物理尺寸，不随脚注字号自动缩小。脚注编号栏会占用正文宽度；表宽不足时需定位到该表，在“表格设置…”中设置单表覆盖。全局新表仍默认 160 mm。当前四页样张的两张脚注表显式使用 140 mm，正文表宽仍为 160 mm；这不是产品默认值变更。点击脚注内的重复表头或图形可以定位原始源码，单表参数修改和原生保存重开已通过实际 Qt 检查。

## 脚注设置

编辑器“脚注设置…”对话框提供九个参数，修改后点击确定，正文按新配置重新排版；取消不改变项目。恢复默认仅作用于此对话框的脚注参数。未修改直接确定不标记项目为已更改，也不会将高精度存储值舍入到控件显示精度。纯文本模式下禁用此入口。

| 参数 | 默认值 | 含义 |
| --- | --- | --- |
| 引用编号字号 | 70% | 相对于引用所在正文、标题、表格或图题的文字字号 |
| 引用编号上移 | 45% | 相对于同一处文字字号 |
| 脚注字号 | 70% | 相对于正文字号；脚注内公式、代码也使用此缩放比例 |
| 脚注最小行高 | 75% | 相对于正文行高；实际笔迹过高时扩展 |
| 正文到分隔线净距 | 2 mm | 分隔线笔迹上边缘前的最小留白 |
| 分隔线到脚注净距 | 2 mm | 分隔线笔迹下边缘后的最小留白 |
| 分隔线长度范围 | 30 mm | 自正文左边界计，起点内缩半笔宽；终点不能越过正文右边界内半笔宽 |
| 常规脚注区高度比例 | 40% | 正文持续排版时的常规预留，必要头行可超出；正文结束后的续注可用满剩余空间 |
| 编号栏最小宽度 | 6 mm | 数字较宽时按实际编号宽度加 1.5 mm 扩展 |

配置以 `inkstruct_footnote_style_v1` 保存于 `.inkdoc` 的 `flow.footnote`；旧项目缺少此字段时使用上表默认值。改变参数不改写 Markdown、不改变源原子身份或原始字形轨迹，也不改变正文/表格/公式独立设置。默认值保持旧页面几何。

字号过小、短分隔线与粗笔不相容、引用与必要注释开头无法同时容纳时明确诊断，成品导出被阻止。参数范围校验不替代实际页面检查，不会为满足输入值而挤压字形。脚注设置当前为整篇文档配置，尚无单条注释局部覆盖。
