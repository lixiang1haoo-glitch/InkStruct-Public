# 已知字形缺陷第一批定向修复

2026-10-10。这是基于已标记字的开发与回归结论，不是盲测统计，不代表全部坏字已修复。

## 实现

新增可关闭的 `ControlRepairGenerator`；生产 `DeterministicGenerator`、结构库、作者档案和默认参数不变。

1. **端点位置只施加一次。** 建档的 start/end delta 已包含相对于原参考笔画的总位移。旧路径在包围盒变换之后再次叠加，并只移动首尾控制点。新路径以原控制点端点加 delta 定义目标端点：近直笔（弦长/弧长至少 0.97）使用端点间等比旋转变换，避免细小包围盒高度被放大；复杂笔画沿弧长连续分配剩余端点修正。倒转或塌缩的近直笔提案拒绝。
2. **稀疏折笔残差单独开关。** 少于 4 个样本的折笔原型只收缩非仿射残差，保留学习到的两端残差及其线性趋势。权重为样本数除以 4。该项是需要复评的正则化，并非低样本自动等于错误；样本数也不等于独立字种数。
3. **整字回退。** 与同一档案、同一参数的旧结果比较，若出现新增严格中心线交叉、零长度退化或协议失败，返回完整旧结果。记录原型键、提案改动笔画、回退原因。此保护不检测所有粗笔接触或视觉缺陷。

## 实测

- 已反复查看的 14 字用于开发/回归。正文全部 632 字的基线对象与冻结旧输出完全一致。
- 短横缺陷：传第 3 笔、砖第 6 笔、桂第 5 笔、生第 3 笔的弦线最大偏离分别从 0.0766、0.0755、0.0742、0.0855 降至 0.0095、0.0095、0.0106、0.0222（字框单位）。同尺度图确认碗形弯曲明显减轻；这不是风格综合得分。
- 而、相、儒的圆拱局部收敛；相的闭合缺口、儒的拥挤未解决。后、子、七、团、已仍需具体连接/比例修复或偏好复评。荡无变化。
- 14 字没有该作者目标原稿；相关稀疏原型成员已从哈希匹配的完整原始索引逐个追溯，成员计数与旧档案一致。不能声称更像目标原稿。

## 复现与产物

个人数据、图文、逐字指标、来源清单和候选项目均保存在 Git 忽略的 `artifacts/review_repairs_20261010/`。`development_v1` 为独立开关对照，`validation_v1` 包含协议、输入/代码哈希、统计、复评项目和资产哈希。最终图文报告在 `validation_v1/report_v2/报告.html`；旧版报告亦保留。

```sh
python scripts/repair_review_project.py \
  --project /path/to/original.inkreview \
  --profile /path/to/frozen-profile.json \
  --db /path/to/frozen-characters.sqlite3 \
  --additional-profiles /path/to/author-A.json /path/to/author-B.json /path/to/author-C.json \
  --output artifacts/review_repairs/new-run
```

输出目录必须不存在。脚本若发现任意正文基线不匹配则中止，不可直接对不同版本旧输出迁移标记。图文脚本 `report_review_repairs.py` 的结论文本专用于本次 14 字回归集。
