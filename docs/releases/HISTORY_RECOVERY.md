# 旧 Windows 版本的恢复证据

Windows 开发迁移保留了原 Git bundle、当时的工作树补丁和状态。Windows 旧版本还留下发布记录、构建输入哈希、部分源码 ZIP 和本地 Codex 检查点。构建清单可验证已找到的文件。尚未提交过的发布版本只能新增重建快照提交，历史提交身份无法由发布包推导。

| 版本 | 已核对的内容 | 恢复状态 |
| --- | --- | --- |
| 0.1.59 | 最终构建记录列出 340 项输入。源码与配置纳入发布基线，结构库和参考数据按归档哈希恢复。 | 见 [Windows Git 基线](../WINDOWS_GIT_BASELINE.md)。 |
| 0.1.58 | 340 项中确认 337 项。证据来自后续工作树、0.1.58 发布包内的明文源码、两个本地检查点，以及版本文件的内容哈希。 | 缺少与最终构建逐字节匹配的 `fonts/importer.py`、`fonts/publication.py`、`fonts/ui.py`。暂未创建 0.1.58 重建提交或标签。 |
| 0.1.46 | 抽查交接前源码 ZIP，与 0.1.46 构建记录有 265 项交集，其中 259 项匹配。 | 部分验证。 |
| 0.1.43 | 抽查归档中的 258 个源码文件，均匹配 0.1.43 构建记录。完整构建记录共有 326 项。 | 源码归档已验证，其他构建输入未逐项恢复。 |

0.1.58 的审计比对了最终构建清单、当前源码、发布包明文、7 个不同的本地 Codex 树对象和本地源码 ZIP。三个待确认的模块在正式包内以 Python 编译模块存在。需要找回源码副本并匹配发布哈希后，才可据此标记准确的源码快照。可对照 [0.1.58 发布记录](../RELEASE_0_1_58_WINDOWS.md) 与 [迁移说明](../WINDOWS_DEVELOPMENT_HANDOFF.md)。
