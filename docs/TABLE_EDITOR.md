# 数字表格排版工具（第一版）

2026-10-12。本版在本机独立提供“左侧 HTML、右侧页面预览”的数字表格工具。默认使用内置单线数字，也可导入 Windows 符号采集器的手写数字 ZIP，导出适合按轨迹书写的 SVG。

## 启动和操作

macOS 双击仓库根目录 `run_inkstruct_table.command`；Windows 对应 `run_inkstruct_table.cmd`。也可运行：

```bash
.venv/bin/python -m inkstruct.table_editor.app
```

1. 左侧修改 HTML 表格，停顿约 220 ms 后更新预览。内置示例同时包含跨行、跨列及小数。
2. 在上方调整纸宽/纸高、页边距、表宽、行高、数字高度、留白与笔宽，单位均为 mm。默认表总宽 160 mm、行高 8 mm、数字高度 3.8 mm、格内留白 0.3 mm。界面新建表格与命令行默认转换均使用这组参数；打开已有项目时使用项目保存的尺寸。
3. “列宽比例”留空时等宽，也可输入 `1, 2, 2`。比例数量必须与展开合并关系后的列数一致。
4. “保存项目”输出 `.inktable`，包含 HTML、全部排版尺寸与路径优化选项；“保存 HTML”只保存源码，不包含面板设置。预览缩放不影响导出物理尺寸。
5. 点击“导出写字机 SVG”。输入无效、数字放不下、越过纸边或超过单页高度时禁止导出，并给出错误位置；不静默截断、缩小或导出旧预览。

命令行转换使用默认 A4 参数：

```bash
.venv/bin/python -m inkstruct.table_editor.app \
  --input examples/numeric_table.html --output outputs/table.svg
```

## HTML 范围

这是明确限定的 HTML 表格子集，不是浏览器的完整 HTML/CSS 渲染器：

- 每次一个 `<table>`，支持 `<thead>` / `<tbody>` / `<tfoot>`、`<tr>`、`<td>`、`<th>`；行组按源码顺序排列。必须显式闭合标签。
- 支持 `rowspan` / `colspan` 正整数；上限 100 行、50 列。不支持 `rowspan="0"`、嵌套表格或不规则空洞。
- 单元格内容为空，或一组 ASCII 数字及至多一个小数点，例如 `001`、`12.50`、`.25`、`1.`。首尾空白被去除。暂不支持负号、千分位、科学计数法、单位、汉字、公式或单元格多行。
- 对齐支持 `align="left|center|right"` 或 `style="text-align: right"` 等同类声明，默认水平居中、垂直居中。右对齐不是独立的小数点对齐。
- 可接受 `border="1"`、`cellspacing="0"`、`style="border-collapse: collapse"`。框线始终按统一实线绘制，宽度在面板设置。
- 列宽、行高、字号、边距等由排版设置控制，尚不解析 HTML 尺寸属性或其他 CSS。外部样式、脚本、图片等会明确报错，不联网、不执行输入。

## 写字机 SVG 契约

- 根元素为必需的 `<svg>`，它的所有子元素均为 `<path>`。
- 每条路径由一个绝对 `M` 和一个或多个绝对 `L` 指令组成。无 `C/Q/A/Z/H/V` 或小写相对指令。
- 没有 `text`、`rect`、`line`、`polyline`、`circle`、`g`、`defs`、字体引用或 `transform`。所有坐标已转换到最终纸面坐标。
- `width` / `height` 带 `mm`，`viewBox` 数值与毫米尺寸相同，左上角为原点，x 向右、y 向下。
- 统一 `fill="none"`、黑色描边。未启用优化时先输出框线，再输出数字笔画；启用优化后按空行程安排路径顺序。公共边框合并，只走一次；合并单元格内部不画多余分隔线。
- 数字是人工定义的单线折线，不是字体轮廓。小数点使用有实际长度的短线，避免零长度路径被写字机忽略。
- 预览渲染未排序 SVG，优化导出仅改变路径顺序及可选方向，几何图形保持一致。预览纸张白底由界面提供，不写入 SVG。

本地结构校验不代表已在具体写字机上验收。实际机型的坐标原点、软件对 mm 的处理、抬笔策略和最小可画线长仍需试写确认。本版不生成 G-code，也不控制硬件。

## 导出路径优化

勾选“优化路径（减少空行程）”后，导出时重新安排完整路径的执行顺序；默认关闭，未启用时保留原输出。导出完成后状态栏显示优化前后空行程、减少比例和反转路径数。预览不显示运动顺序。

开启“优化路径”即自动允许整条路径反转，不再提供单独取消反转的开关。用户在本次机器试写中观察到反转几乎不影响效果，因此将其作为默认优化策略。优化仍不连接、拆分、简化、移动或重采样笔画，也不减少重复路径；只改变路径顺序及整条路径的方向。关闭优化则保留原始顺序和方向。

空行程采用毫米坐标下的直线距离，包含从纸张左上角 `(0, 0)` 到第一笔的移动，以及相邻路径之间的移动，不包含最后回零，也不估算加速度和抬落笔耗时。写字机起点不同，实际节省比例也会不同。下游写字机软件须按 SVG 中的路径顺序执行，才能保留此排序效果。

算法保留旧版的原始顺序、最近邻排序和固定顺序方向动态规划候选，再加入横向/纵向空间排序。对最多三种不同初始路线执行两轮“2-opt 整段翻转 + 方向动态规划”：整段翻转同时反转段内每条笔画，使段内空行程长度不变，只需比较两端连接；它可以消除最近邻排序留下的绕行。起点到第一笔计入优化，末笔无需返回起点。最终仅接受比旧版最好方案更短的候选，所以同一输入不会比旧算法更差。

这是启发式优化，不承诺全局最短。512 条以内搜索全部区间；更长路线对局部搜索采用 128 条窗口，并增加空间排序后的分块最近邻候选，减少原始分块边界的影响。每次局部搜索最多 4 遍、100 万次区间评估，使用确定性计算预算；相同输入与种子可复现相同输出。

命令行只需 `--optimize-paths`，自动允许反转。旧的 `--allow-reverse` 参数仍兼容但已无须指定；单独使用它仍报错。底层显式 `allow_reverse=False` 仅保留给算法对照实验，界面和命令行的优化入口始终启用反转。

```bash
.venv/bin/python -m inkstruct.table_editor.app \
  --input examples/numeric_table.html --output outputs/table_optimized.svg \
  --optimize-paths
```

默认示例共 39 条路径：原始空行程 1377.6 mm，新算法优化为 256.7 mm（减少 81.4%）。这些是按上述起点计算的几何估值，尚未实机测时。

旧版 `.inktable` 未包含优化选项时，读取为优化关闭；已有项目只要启用优化，即使旧字段 `allow_reverse` 为 false，也按新策略允许反转。新保存的项目会同步写入该策略。

## 手写数字样本试用与接口

表格解析、几何布局、数字字形和 SVG 序列化相互独立。`NumericGlyph(strokes, advance)` 描述一个数字字形；`compile_html(..., glyphs=...)` 可注入另一套数字和小数点。

接口坐标以数字区域高度为 1、y 轴向下；内置数字基线 y=1。笔画使用有限坐标折线，字宽独立保存。

点击“导入手写数字 ZIP”，读取 `inkstruct_symbol_sample_v1`，要求压缩包只含一位书写者且 0–9 均有样本。当前接入数字与小数点；包内存在小数点样本时使用手写小数点，否则明确使用内置短线，其余数学符号不参与表格排版。ZIP 直接读取，不提取或改写原样本；可用“使用内置数字”切回默认。

选样按随机种子、字符出现位置和字符值确定，样本 ID 排序后通过 SHA-256 取样。保持源码、样本包和种子不变，反复预览和导出使用相同样本；改变种子可观察另一组混排。路径优化在选样和排版完成后执行，因此不改变选样。

转换先依据每份样本的 `em_px`、原点和基线换算到 em；再对全部数字使用共同的纵向范围（包含参考字高、基线以及实际墨迹）和同一等比例尺度。保留相对字高、基线偏移、原始点、笔画分段与笔顺，不平滑或重采样。横向去除采集位置偏移，按墨迹宽估计字距：间距 0.16 个数字区域高度，数字最小字宽 0.45、小数点最小字宽 0.2，以免数字 1 过窄；这些字距仍是初始估计。手写小数点保持采集时相对基线的位置与大小，不单独放大到数字字高；无手写小数点时，将内置小数点放到这套样本的公共基线附近。

`.inktable` 保存 ZIP 路径、SHA-256 和种子；读取时检查文件是否变化，缺失或变化不会静默切换字形。移动项目时需保留可访问的样本 ZIP。原始压力、时间和采集元数据仍保存在 ZIP；SVG 使用统一笔宽，仅保留轨迹，不模拟压力。尚未接入人工筛选和独立字距校准。

```bash
.venv/bin/python -m inkstruct.table_editor.app \
  --samples /path/to/user_001.zip --sample-seed 42
```

可复现的对比页、50 份样本图和三种排序 SVG 试用脚本：

```bash
.venv/bin/python scripts/try_table_samples.py /path/to/user_001.zip \
  --output artifacts/table_samples_trial --seed 42
```

试用产物保存在 Git 忽略目录，原 ZIP 保持不变。`verification.json` 记录原包哈希、逐字符样本 ID、逐路径排序/反转、距离和 SVG 契约校验；`trial.inktable` 可从工具“打开项目”继续编辑。
