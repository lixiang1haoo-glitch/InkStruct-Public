# InkStruct 文档编辑交互性能可行性验证

2026-10-20，Windows 实测。应用保持 **0.1.33**，没有正式构建、发布、升级、提交或推送。生产源码和默认运行路径未修改。实验代码位于 `scripts/editor_architecture/`，实际数据位于 `artifacts/editor_architecture_20261020/`。已核查 AGENTS.md、完整未提交工作树及两轮 GPU 记录；历史记录只作对照，以下数字来自本轮新测。

## 结论

值得继续改善现有 Qt 编辑器，现阶段没有数据支持更换框架或预览控件。优先处理**界面线程的发布工作、无效缓存记账和滚动期间的预取竞争**。这三项已有独立对照；不能把它们归功于 GPU。

独立计算进程明显改善计算期间的滚动，但把整份 Python 几何返回界面，代价超过收益。无损紧凑坐标缓解了问题，仍不能直接接入。后续应验证“工作进程持有权威快照、界面接收必要元数据和可见画面”，再决定进程方案。

共享内存有可测收益，但量级为几毫秒至十毫秒，不足以解决数百毫秒的发布/计算停顿。Qt 路径复用能减少 SVG 中转，当前实验只证明阶段收益，不能声称整窗已经提速。没有实现 GPU 常驻几何、直接纹理呈现、Qt Quick 或新的场景图。

暖页面且没有后台竞争时可以接近单帧预算；后台重排、发布和冷页跳转仍有长尾，**本轮没有达到整条交互链的成熟编辑器目标，也没有与 Word 做同机对照**。

## A：增量处理与缓存准入

现有测量缓存会检查所有输入及资源依赖，续排仍先测量整文档，再比较包含源码范围、身份、字形、公式/表格等的输入和分页状态。插入导致源码偏移后，很多后缀键失效；不能用“只重排当前页”替代。脚注预留、列表编号、不同宽度正文框和循环布局均可能改变后续结果。

1. **无效缓存准入原型**：不扩大任何容量。对本轮已经确定不能存入的续排记录，避免重复生成必定被拒绝的记账结果；原有测量和完整布局语义保留。单独关闭该无效路径后，三次数字编辑后台计算中位数约 **447 ms，当前约 527 ms**。单独全布局准入没有明显收益。原生数字编辑 **837→763 ms**、插段 **981→882 ms**；公式基本不变，脚注反而波动变慢。它有适用范围，不能全局关闭续排缓存。
2. **受保护的局部解析**：只接受同长度数字替换、独立普通段落及可证明不改变语法边界的情况，保留局部节点的原标量身份并重定位准确 span。列表、字段、引用/脚注、围栏、公式、HTML、表格和结构变化走完整解析。真实混合主文档的五种修改均回退，不能声称它们已增量化。
3. 在复用真实字体的纯数字多页派生输入中，段落解析约 **13.3–13.7→0.6–1.0 ms**；后续五次真正命中的完整构建中位数约 **89→76 ms**，存在一次负收益。几何、AST、诊断和选样与无缓存完整重算相同。该正例不是主文档或所有 Markdown 的收益承诺。

值得正式做的是不可变资源目录的共享记账及准入预判，而不是增加缓存容量。通用增量解析/测量/分页仍需明确依赖图、源码偏移重映射、脚注协调状态和布局收敛证明；当前最小原型未完成这些通用能力。

## 下一轮最小实施计划

1. **先接入等价提示成员判断**，保持全部警告/接受状态和正式导出 gate。成本低，已有端到端收益；同时把当前布局状态/旧快照状态明确显示，继续禁止旧画面映射新源码。
2. **独立接入空闲预取调度**，可见内容始终优先、停止滚动后按方向预取，保留预算与取消。不把每批 4 块作为默认。成本低至中；验收同时考察冷跳转、暖滚动和重排阶段最大停顿。
3. **重做不可变资源的共享记账与缓存准入**，证明某条目不会存入后避免重复深度计量；资源目录、样式、协议/限制变化必须失效。不要按一次超限永久禁用通用续排，也不要简单加容量。成本中等。
4. **再做工作进程持有权威快照的细化原型**：GUI 不再每次反序列化整份几何，先传可见页与选字所需元数据，页面图像逐批发布；导出明确请求已经完成校验的 snapshot/revision 并冻结。错误、取消、过期、崩溃必须回退现有 CPU 路径。成本中至高，先证明没有 200 ms 以上的接收/发布长停顿，再考虑正式接入。
5. 在同一权威坐标下为显示增加有限 Qt 路径/绘制列表缓存，随后才评估是否能让排版也引用共享样本几何。当前身份、度量、笔宽和校正键均须保留。与共享图像传输分别验证后再组合，不能把独立收益直接相加。
6. 通用增量解析、测量和分页放在依赖图建立之后：处理字段、引用、列表序号、公式、表格续排、脚注预留和循环模板，只有状态收敛才复用后缀，否则完整回退。维护成本高，当前受限数字快路径不足以替代它。

目前**不需要替换预览画布，也不建议立即增加本地原生模块**：已有页面实际 paint 中位数约 1 ms，真正空闲暖滚动已接近预算；优先消除界面线程和传输的大块工作。若上述改造后逐点展开/扫描仍主导，再用同样输入验证一个释放 GIL 的局部批量几何/计量模块；保留 Python 权威对照与 CPU 回退。数据不支持直接重写编辑器或把 GPU 设成所有机器默认。
