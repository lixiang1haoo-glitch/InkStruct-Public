# 代码块排版

日期：2026-10-13。围栏代码块和缩进代码块已接入源码身份、资源检查、分页预览及严格机器 SVG。它们只呈现字面内容，不执行代码、不解析公式/强调/实体/HTML，也不输出语法高亮的多色笔迹。围栏语言标签保留在源码中，不作为正文绘制。

## 字格与分页

“代码设置…”提供字形大小、固定字格宽度、最小行高、制表位列数；默认分别为 **4 mm、5 mm、6 mm、4 列**，独立于正文、数学和表格数字样式。配置写入 `.inkdoc`，取消对话框不修改项目，未编辑的高精度尺寸不被显示精度截断。

每个显示字符簇占一个字格；空格也占格。制表符移动到下一个配置的列边界，不是固定追加四个空格。字形只做等比变换，不为填充格宽横向拉伸。选中字形的度量宽度超过格宽时报告 `code-cell-overflow`，需要调整字形大小或字格宽度。

代码块默认只在原始行之间分页，不在行内自动换行。行宽超过页面可用宽度时报 `code-line-width-overflow`，诊断指向对应源码行；尾随空格和制表位同样计入宽度。可显式启用“允许宽行换行并绘制续行标记”：按字符簇边界拆成可容纳的显示行，左侧预留 4 mm 标记区，所有续行绘制折线箭头。源码和字符实例不插入换行，原制表符占据的列数也不重新解释；单个制表跨度或字格仍超宽时继续报错。

空行保持，实际末尾换行保持，但不额外制造一个空白末行。最小行高不足以容纳字形时按墨迹增高，避免裁切；超出整页高度则报错。

## 源码保真

权威源码始终原样保存在项目中。解析显示视图把 CRLF/CR 作为一个换行，并保留回到原始区间的映射；不会改写磁盘源码。Markdown 围栏、引用/列表前缀和缩进代码的语法缩进不作为代码内容绘制。缩进部分消耗制表符时，按固定版本 Markdown 规则保留余下的显示空格，它们共享源区间但有不同实例身份。

美元符号、星号、实体拼写和尖括号在代码内保持字面字符。NUL 等无法忠实书写的控制字符明确报错，不能静默丢弃或替换后当作成品导出。可见内容缺字时继续按统一资源检查阻止导出；英文字母和标点仍需要实际样本。

## 证据与边界

公开源码为 `examples/markdown_code_m4.md`。本机 `artifacts/markdown_mixed_m4_20261013/code/` 保存两页真实数字笔迹预览、机器 SVG、可移植 `code.inkdoc`、编辑器/设置截图和验证清单。复现脚本为上级 `verify_code.py`。

自动化覆盖精确源码范围、CRLF、围栏与缩进代码、制表位、空行、尾随空格、控制字符、超宽/超格诊断、跨页实例覆盖、编辑身份保持及项目重开。实际英文代码的书写质量仍依赖未同步样本和后续写字机验收，不能由数字样张推断完成。
