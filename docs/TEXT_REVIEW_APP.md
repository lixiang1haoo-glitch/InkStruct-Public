# 纯文本字形检查应用

这个应用用于在正文中检查已经生成的手写字形，并记录哪些字好、哪些字不好。左侧是可编辑纯文本和字形列表，右侧是实时分页预览、单字放大与评价工具。本页说明纯文本检查模式；新入口默认使用 Markdown 混排，可从“内容模式”切换。两种模式均不自动修改或重新训练生成器。Markdown 功能和边界见 [混排实施记录](MARKDOWN_MIXED_LAYOUT_PROGRESS_20261013.md)。

## 启动与首次使用

macOS 双击仓库根目录的 `run_inkstruct_editor.command`；Windows 运行 `run_inkstruct_editor.cmd`。也可在原生成器中点击 **文本检查…**；如果刚刚完成生成，会自动带入本次生成目录与输入文字。

命令行入口如下，从仓库根目录运行：

```bash
.venv/bin/python -m inkstruct.editor.app --mode plain-text

.venv/bin/inkstruct document edit --mode plain-text \
  --source /path/to/source.txt \
  --run /path/to/generated-run
```

安装更新后的包也会提供 `inkstruct-editor` 入口。桌面运行需要项目已有的 PySide6 6.9.2 依赖。

1. 点击 **选择字形目录…**，选择包含 `trajectories/` 的生成结果目录。
2. 输入、粘贴或打开 UTF-8 纯文本。若想逐字筛查整个生成批次，点击 **载入全部字**。
3. 停止输入约 280 毫秒后启动后台排版；右侧显示已生成字形。输入法预编辑不进入持久正文。
4. 点击右侧的字，左侧会选中对应文字，下方放大显示该字。也可点击字形列表跳转。
5. 点击 **好 / 不好 / 待复核**，按需填写备注。绿色、红色、黄色分别对应三种评价；可以关闭色标检查原始墨迹。
6. 使用列表筛选查看问题字，或点击 **下一未评字** 继续检查。

## 评价的含义

评价属于**具体字形资产的内容哈希**。同一资产在正文中出现多次时共享评价；重新生成、换作者、换档案或修改原资产产生新哈希后，不继承旧版本评价。

旧评价会保留在检查项目中，列表下方会显示有多少评价不属于当前正文或版本。它们仍会被保存、导出，不会因为删掉正文中的某个字而消失。

每项评价记录汉字、资产哈希、好坏状态、备注、生成目录、书写者、生成器、档案版本，以及标记当时的正文摘要、位置和上下文。这些位置表示**评价发生时的上下文**，不是后来每次编辑后自动迁移的当前位置。

评价是人工判断，不等于生成器置信度，也不会自动写回轨迹、改变训练集或触发质量修正。

## 实时编辑与检查

- 源码编辑使用记录实际编辑区间的事务撤销/重做；页面选择与放大不修改正文。
- 标记使用独立的 **撤销标记 / 重做标记**。备注更改也会记录为评价操作；首次给未评价字填写备注会自动设为“待复核”。
- 改字号、行高、笔宽会重新排版；缩放和评价色标只影响查看方式。
- 重排期间保留旧页面，但禁止对旧页面标记或导出。只发布当前请求的结果；旧任务的成功或失败不会覆盖新内容。
- 切页和缩放后点击定位仍按页面坐标转换。右侧最多显示一页，不为每个采样点创建界面对象。
- 同一目录的文件在外部被重新生成后，点击 **刷新字形**；本版不自动监听目录变化。
- 导入时保留 CR、LF、CRLF，编辑器内部用 LF 显示并维护边界映射。局部编辑保留未改动的原始换行；最近 128 个文本状态缓存原始换行供撤销恢复。非常长的混合换行编辑历史不保证字节级恢复。

## 保存与导出

**保存检查项目** 写入 `.inkreview` 文件，包含正文、生成目录引用、页面/样式设置和全部评价。再次打开后恢复检查状态；此文件不嵌入原轨迹，因此仍需要对应的本地生成目录。目录移动后重新选择即可；内容哈希未变的评价仍可使用。

项目采用同目录暂存后原子替换，写入失败保留旧文件。检测到已打开的项目被外部修改时拒绝覆盖；通过 **另存项目…** 保存副本。关闭窗口或切换检查项目时，会提示保存未保存的正文或评价。当前没有定时自动保存和崩溃恢复。

**保存文本…** 只另存正文，不保存评价。**导出评价 CSV…** 导出所有已记录评价及来源，含不在当前正文中的历史版本，便于筛选问题字。CSV 对可能被电子表格解释为公式的字段添加文本前缀，项目 JSON 保留原始备注。

**导出页面…** 输出同一快照的 SVG、PNG 和布局报告。选择框、放大窗口和评价色标不进入成品。缺字、坏资产或溢出时禁止成品导出，但已经载入的有效字形仍可评价。

## 当前限制

- 本版读取已有生成批次，不在编辑时自动补生成。生成器与检查器通过结果目录衔接。
- 当前默认支持汉字轨迹及空白。未提供字形或度量的标点、数字、拉丁文字显示红色占位及原字符，不能评价，也不能当成手写成品导出。
- 复杂脚本、emoji、Markdown、数学公式、表格和实验报告模板未接入。
- 使用固定笔宽绘制，保留源点、时间与压力，但不模拟压力笔刷或书写动画。
- 字形身份可以跨正文编辑保持评价；逐次出现的 occurrence 身份会在重排时重建。尚未实现通用文档编辑事务、版面覆盖迁移或完整 `.inkdoc` 包。
- 原型限制正文十万 scalar/导入文本 2 MiB、检查项目 16 MiB；当前字形/页图限制沿用页面内核。未完成大规模字库性能、真实输入法候选切换与 Windows 真机验收。
