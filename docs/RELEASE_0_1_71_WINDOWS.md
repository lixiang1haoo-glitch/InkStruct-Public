# InkStruct 0.1.71 Windows

发布构建取自公开源码提交 `c166a1c9f3d6c59bc24069a28446dd65dc219b49`。

- 字体库列表、标题和字形预览随深浅主题切换。
- 公式设置的手写预览同时显示当前示例的各项实测毫米值，选中项高亮。
- 汉字和标点采集的深色画布为深灰底、白色笔迹。浅色画布为白底、深色笔迹。
