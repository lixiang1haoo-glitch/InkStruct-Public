## 使用

列表项首段开头的 `[ ]` 为未勾选，`[x]` 或 `[X]` 为勾选；标记后应有空白或到段末。支持无序、有序、嵌套、引用内任务、空任务、后续段落及正文中已有的强调、链接、代码和公式。示例：

```markdown
- [x] 检查原始数据
- [ ] 复核计算结果
  - [ ] 保留小数点

1. [ ] 完成数据表格
```

标记内部的单个制表符也接受为未勾选；其他扩展状态以及内部跨行标记不属于当前支持范围。代码、转义、实体生成的括号、普通段落及同一列表项后续段落中的标记保持普通内容。

在页面预览中左键点击方框可切换状态，只修改源标记中间一个字符；源码是唯一权威状态。撤销会恢复原字符，包括大写 X、制表符及原换行。程序选中、源码定位或旧布局快照不会触发切换。固定模板中重复的同一任务共用源状态；更新后所有重复位置一致。

## 排版及写字机输出

方框边长为正文 em 的 55%，与正文间隔 1.5 mm；方框和勾线直接使用折线，无需符号字体或手写样本。有序任务保留序号，无序任务以方框替代项目符号。续行与正文对齐，跨页不会重复方框；字号过小且笔宽无法容纳方框时明确报错。

任务正文仍使用普通字形解析、选样、分页及评价。方框自身不进入字形评价。切换勾选不会重选其他字形或改变正文位置。导出沿用公共路径优化，开启优化即允许反转；最终 SVG 仅包含 path 元素和 M/L 指令。
