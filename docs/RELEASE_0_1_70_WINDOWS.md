# InkStruct 0.1.70 Windows

发布构建取自公开源码提交 `946931a92ce6c89af700c75c5134a2504402f451`。私有主线同步应用源码、采集器、构建脚本与手册。

- 采集页可选择允许汉字连笔，生成页显示 v6.3 是当前支持连笔的方法。
- v6.3 复用 v6.2 的分笔布局、多候选和回退，另行校验完整连笔整字与部件。同字回放由用户勾选。
- 安装向导、卸载界面及缺少 Microsoft Visual C++ x64 运行库的提示采用简体中文。
