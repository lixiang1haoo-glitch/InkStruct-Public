## 定界符和源范围

Markdown 行内使用 `$...$`；展示公式的起止 `$$` 分别独占一行。代码块、缩进代码和行内代码不解析数学。普通正文中的字面美元符号使用 `\$`。不自动猜测货币语义，不接受同一行的 `$$x$$`。

解析器在 Markdown 规则边界识别公式，保留 CRLF、缩进和非 BMP 字符的原始 scalar 区间。公式中的星号、下划线及反斜线由数学语法解释，不交给 Markdown 强调或转义规则。`document.source` 为原始权威文本；数学节点的 `raw_content` 是去除定界符后的解析视图，HTML 实体已解码，换行可能规范化。原始写法始终可以通过节点源区间取回。

管道表格中，字面竖线仍需遵循管道表格转义规则；公式定界符建议使用 `\vert`、`\Vert` 等命令，不能把未转义的竖线当作不分列的保障。受控 HTML 表格允许数学出现在文本或单个强调标签内部，HTML 实体如 `&lt;` 可以用于公式；公式不能跨 HTML 标签边界。HTML 的 `<code>` 内容保持字面文本。

## 已解析的结构

| 结构 | 示例源码 | 限制 |
| --- | --- | --- |
| 符号、分组、常用运算关系 | `x+1`、`\alpha`、`{x+y}` | 单个字形来自资源；不执行宏 |
| 上下标 | `x_1^2`、`x^{12}` | 单个原子或花括号组；重复同类脚本报错 |
| 分数 | `\frac{a}{b}`、`\dfrac{a}{b}`、`\tfrac{a}{b}` | 两个非空花括号参数 |
| 根式 | `\sqrt{x}`、`\sqrt[3]{x}` | 非空根内组；根指数可选 |
| 伸缩定界结构 | `\left( x \right)` | 必须成对；`.` 表示不可见一侧 |
| 运算符与上下限 | `\sum\limits_{i=1}^{n}`、`\int\nolimits_0^1` | limits 仅应用于运算符 |
| 单位与文字 | `\mathrm{m^2}`、`\text{电压}`、`\operatorname{rank}` | roman 组保留数学语义；text 不接受嵌套数学、任意命令或嵌套组 |
| 简单矩阵与分段 | `\begin{pmatrix}1&2\\3&4\end{pmatrix}` | 行列数一致，最多 8 行、8 列、64 格；cases 固定 2 列 |

多行对齐环境的完整列表与约束见后文 M5 小节。

每个公式最多 4096 个解析视图字符、4096 个节点、32 层递归。未知命令、不支持环境、缺失参数、未闭合分组和错误矩阵均给出定位诊断，保留源文，不输出不完整的数学树。源码可以继续编辑修复。

数学 ASCII 连字符与星号分别解释为数学减号和星形乘号；该解释只发生在数学上下文。普通正文的 ASCII 连字符与数学减号仍为不同字符。希腊变体保留独立 Unicode，例如 `\epsilon` 为 ϵ、`\varepsilon` 为 ε，`\phi` 为 ϕ、`\varphi` 为 φ；映射核对依据为 [KaTeX 官方符号表](https://katex.org/docs/supported.html#letters-and-unicode)。这仅用于核对符号语义，项目没有接入 KaTeX 渲染器，也不承诺其完整语法。

`Symbol / Row / Group / Scripts / Fraction / Radical / Delimited / Matrix / MatrixRow / Array / ArrayRow / ArrayRule / Accent / Alignment / AlignmentRow / Operator / Text / Space` 构成当前不可变数学树。脚本子节点保留原来的上下标出现次序，并用属性指示 sub/sup。符号源实例由原文字符锚点与同源命令内角色确定；修改公式外文本或在公式内插入其他符号不会重新选取未改符号。资源检查不把 `frac`、`alpha` 等命令名作为需要采集的字母。

## M4a 手写几何

`Symbol / Row / Group / Operator / Text / Space` 已实现测量。公式作为不可拆的数学盒参与正文换行、页高及表格测量；超宽报错，不静默缩小。数字、每个函数字母和单位字符仍各自保留源身份、选样、原笔画及评价入口。一元减号不添加二元间距；关系符、二元运算符和函数间距分别配置。

“公式设置…”提供公式字号（默认 6 mm）、数学轴（默认基线上方 0.25 em）、三类间距及独立公式对齐。配置保存在 `.inkdoc`，不改变表格数字高度 3.8 mm。标题中的公式沿用标题倍率。运算符依据样本记录的 `math_axis_em` 对齐，缺少参考线时报错；不根据墨迹包围盒中心猜测数学轴。所有采样点等比缩放和平移，原始笔压/时间/坐标不修改。

现阶段导出保留 `math-calibration-unreviewed` 警告，表示使用采集参考线且仍待书写者校准。缺字、单点适配未完成及尚未实现的结构则是阻止正式导出的错误；不会将未实现结构平铺为普通字符。内置资源只覆盖数字和小数点，其他符号需要导入实际样本。

真实算术样例为 `examples/markdown_math_m4a.md`。本机 `artifacts/markdown_mixed_m4_20261013/m4a/` 包含可独立重开的 `arithmetic.inkdoc`、PNG 预览、严格机器 SVG、界面截图和验证清单。7 个公式、64 个数学符号、4256 个点通过等比变换核对；英文、希腊和函数目前只有合成测试资源覆盖，不作为真实样本验收。较完整的 `markdown_math_m4.md` 继续用于尚未实现部分的资源和语法检查。

## M4b 上下标、分式和根式

普通基底的上下标使用 0.7 倍字号，保持原文中上下标的实例次序；脚本并排位于基底右侧，各自保持等比形状。上下脚本的包围盒之间留出至少 0.12 em 或 1.5 个笔宽（取较大者）的空隙。较高基底的上标会随基底高度移动到右上角，下标相应移向右下角；运算符脚本的特殊规则见 M4c。

`frac`、`tfrac` 子内容使用 0.8 倍字号；`dfrac` 保持当前字号。该受控实现不自动推断完整 TeX 的 display/text style。分数线位于数学轴，分子、分母分别居中，墨迹包围盒与线之间保留上述最小净空。默认几何模式的根号使用包含钩形与上横线的独立折线；带根指数时指数使用 0.7 倍字号并置于左上方。可在设置中选择录制模式，以采集根号分段适配钩部和横线，分数线也可用录制减号拉长；规则见 [录制公式结构](MATH_SAMPLED_CONSTRUCTIONS.md)。不修改根内字形或原始样本。

脚本和分式可嵌套；只要某个符号的 em 小于当前笔宽的 6 倍，就报告 `math-size-limit` 并阻止机器导出。此阈值是保守配置，不能证明实际纸张、速度和笔尖下的所有笔画间隙都可辨；实机校准仍待完成。增大公式字号或减小已校准笔宽后可重新检查，不会静默丢弃深层符号。

结构线有独立来源身份，只输出一次。公式的 ascent/descent 包含每条结构线的笔宽；正文和表格会按实际高盒布局，固定行高不足则报错。样例 `examples/markdown_math_m4b.md` 的本机项目、预览及机器 SVG 位于 `artifacts/markdown_mixed_m4_20261013/m4b/`，覆盖嵌套分式/根式、脚本次序和表内高公式。

## M4c 定界构件、上下限和矩阵

`left/right` 的圆括号、方括号、花括号、角括号、单竖线和双竖线由专门单线折线生成，根据内容高度留出净空。`.` 不绘制该侧。默认几何模式无需采集括号样本；录制模式使用对应括号样本按宽高缩放；源码中的普通 `(1)` 仍使用真实字符样本。每条构件保留源范围和独立路径身份。

`limits` 显式将上下限居中堆叠于运算符上方/下方，`nolimits` 显式侧置。无显式指令时，展示公式中的求和、乘积和 `lim/min/max` 采用堆叠，行内公式侧置；积分和环路积分默认侧置。分式子内容、矩阵单元格和脚本内部按行内样式处理，不继承外层展示公式的堆叠默认；显式指令仍有效。运算符当前保留与其他符号相同的 em，不自动放大。

`matrix/pmatrix/bmatrix/Bmatrix/vmatrix/Vmatrix/cases` 支持原语法上限的 8 行、8 列、64 格，行高包含每格的完整上下伸展。普通矩阵列内居中，分段结构两列左对齐；各列宽度取该列最宽内容。矩阵整体中心对齐数学轴，空格也保留行列几何。整块作为不可拆数学盒进入正文/表格，超页或超宽明确报错。

公开样例为 `examples/markdown_math_m4c.md`，本机 `artifacts/markdown_mixed_m4_20261013/m4c/` 包含项目、预览与严格 SVG。真实笔迹覆盖数字、求和与分段条件中的汉字；积分、环路积分及函数字母的行为只由合成资源测试验证，不能据此认定实际样本已齐备。M4c 当时未包含的编号与 align 已在后述 M5 接通；列格式数组和修饰符已在后述 M5 接通；任意宏仍未实现。

## M5 显式多行对齐

采用 [AMS 数学环境的对齐点约定](https://www.ams.org/arc/tex/amsmath/amsldoc.pdf)，以下是本工具的受控实现范围，不是完整 amsmath 替代。

| 环境 | 对齐规则 | 使用范围 |
| --- | --- | --- |
| `aligned` | 每对列分别右对齐和左对齐；`&` 位于关系符之前；额外的 `&` 开始下一组等式 | 行内、展示、表格、脚注及嵌套公式 |
| `gathered` | 每行按自身完整宽度居中，不接受 `&` | 同上 |
| `split` | 最多一对列，保持一个共同对齐点 | 当前只允许占据完整展示公式 |
| `align*` | 与 aligned 相同的列锚点和组间距，不产生编号 | 只允许占据完整展示公式 |
| `gather*` | 与 gathered 相同的逐行居中，不产生编号 | 只允许占据完整展示公式 |

`\\` 显式换行，允许最后一行尾部的换行标记；连续换行保留空行高度。aligned 的短行缺少的列按空列处理，保留已有对齐点；每个环境最多 32 行、8 列（4 对等式）、256 个实际单元格，split 最多 2 列，gathered/gather* 固定 1 列。公式总长度、节点数与递归预算仍同时生效。

```markdown
$$
\begin{aligned}
12.50+13.25&=25.75\\
\frac{25.75}{2}&=12.875\\
&=12.875
\end{aligned}
$$
```

aligned/gathered 支持紧随环境名的 `[t]`、`[c]`、`[b]`，分别把首行基线、整体数学轴中心、末行基线作为外部对齐参考。省略时使用 `[c]`。它们影响盒子与周围文字的基线关系，不改变内部行间距；表格垂直对齐仍遵守表格自己的设置。表达式开头的字面方括号需放在花括号组内，以免被当作环境选项。

每对列的左侧内容向共同锚点右对齐，右侧内容从共同锚点左对齐；关系符前的净距沿用公式关系符设置，右列开头的二元运算符保留续行运算语义。第二对及后续等式之间默认间距为 1.5 em，行间净距默认 0.5 em，两者都有两倍笔宽的下限。每行高度由该行最深的分式、上下限或嵌套结构决定。对齐单元格使用展示样式，分式子层仍沿用原有缩放和上下限规则。

“公式设置…”新增第九类“多行对齐”，行间净距与等式组间距独立于矩阵参数。两个比例随 `.inkdoc` 保存，旧项目没有字段时使用上述默认值。设置不更改原始样本，也不修改表格 160 / 8 / 3.8 / 0.3 mm 默认值。

当前所有多行环境作为一个不可拆数学盒进入正文、模板、表格或脚注。空页放不下时诊断并阻止成品导出；不跨页拆行，不静默缩小，不丢弃超长行。align*/gather* 使用内容宽度和配置间距，外层仍按项目的左对齐/居中规则放置，不模拟 TeX 的全页弹性列间距。

自动编号、显式标签和引用见下节。逐行间距选项、`\\*`、任意 array 列格式及复杂矩阵控制仍未实现。非法上下文、选项、列数、未闭合环境和预算超限都有源码区间诊断；继续保留在 M5 数学扩展待办中。

验证包括 `tests/test_math_alignment.py`、实际 Qt 分类预览及保存重开；样例为 `examples/markdown_math_alignment_m5.md`。本机项目 `artifacts/markdown_mixed_m5_20261013/math-alignment/aligned-report.inkdoc` 共五页，前四页原报告的预览及机器文件保持不变，第五页展示五个多行公式，含表内公式。`verify_alignment.py` 检查源码覆盖、等号列锚点、原始轨迹等比变换、整盒分页、页界、原生/CLI 一致、严格 path/M/L 和路径优化保真。窗口截图为 `editor.png`、`settings.png` 和 `settings-adjusted.png`。实际英文/希腊样本和实机校准仍待完成。

## M5 公式编号与标签引用

普通展示公式仍默认无编号。显式使用 equation 环境，为整块公式生成一个编号；非星号 align/gather 为每行编号。equation*/align*/gather* 保持无自动编号，但允许显式 tag。aligned/gathered 本身仍是内部结构，不能各行独立编号；可以放入 equation，为整块推导使用一个编号。

```markdown
$$
\begin{equation}
\frac{12.50+13.25}{2}=12.875\label{eq:mean}
\end{equation}
$$

计算结果见 $\eqref{eq:mean}$。

$$
\begin{align}
12+3&=15\label{eq:sum}\\
&=15\notag\\
25&=25\tag{12.3}\label{eq:manual}
\end{align}
$$
```

编号按公式在源码中的顺序从 1 递增，包括脚注定义中的公式。放入固定字段或字段每页重复不再分配新编号；正文、表格和脚注可以引用同一标签。显式 tag 和 notag/nonumber 不消耗自动序号，显式可见标签允许与其他标签文字相同；命名的 label 键必须全篇唯一。

| 命令 | 当前行为 |
| --- | --- |
| `\tag{12.3}` | 为完整展示公式或 align/gather 的当前行指定文字标签，自动添加单线括号 |
| `\tag*{12.3}` | 指定文字标签，不添加括号 |
| `\notag` / `\nonumber` | 取消当前公式/当前行编号，与显式 tag 冲突时诊断 |
| `\label{eq:mean}` | 将当前可见编号登记为标签目标，不生成文字；未编号行不能登记目标 |
| `\ref{eq:mean}` | 在数学定界符内输出目标标签文字 |
| `\eqref{eq:mean}` | 在数学定界符内输出带单线括号的目标标签文字 |

tag 参数当前为普通文字及受控转义标点，不接受嵌套数学、宏或文本样式命令；文字必须有实际字形资源。tag 须放在最终对齐单元格的末尾，后面可以有 label。label/notag 可在当前公式或行的直接内容中出现，不支持藏在分式、根式、上下标或嵌套 aligned 的内部。split 可以作为 equation 的完整内容并共享一个编号。

标签键区分大小写，长度 1–128 个字符，不含空白、反斜线、花括号或控制字符。允许前向引用；重名标签、引用不存在的标签、给无编号行登记标签、重复/冲突 tag 和非法嵌套均产生源码定位诊断，阻止成品导出。引用命令在 `$...$` 等数学定界符中使用；普通 Markdown 正文中的裸反斜杠命令不作为公式引用自动解释。

编号使用项目手写字形，括号遵循定界符来源设置：默认单线构件，可选择录制括号适配。“公式设置…”第十类“公式编号”提供编号字号（默认公式字号的 100%，允许 50–100%）和公式到编号的最小净距（默认 1 em，受两倍笔宽下限保护）。引用字号取所在公式的字号，不随右侧编号字号设置缩小。

编号靠当前有效公式区域右侧放置。内容尽量按原设置居中；若与编号争用宽度，则向左移动以保留净距，原笔迹不压缩。最小总宽度超过区域时明确报错。多行编号按各行基线放置，标签高度参与行高；整个公式及编号共同分页。脚注编号仍位于自己的左侧编号栏，脚注内的公式编号位于右侧，不混用两套编号。

自动编号实例以对应源码锚点、数字槽位和当前数字建立身份；显式标签保留真实字符区间，引用实例以引用命令及显示文字建立身份。插入更早公式后，不重新选取未改的公式正文；变化的编号和引用获得相应实例，避免错误沿用旧数字。撤销和项目重开可恢复原显示。点击自动编号定位对应公式/行源码，点击引用定位该引用命令，不把派生数字写回 Markdown。

测试见 `tests/test_equation_numbers.py`，涵盖自动序列、取消/手动标签、前向引用、标签诊断、两位编号/空行、右边界/碰撞/超宽、嵌套 split、表格和脚注、模板重复、编辑/撤销/保存重开以及长列表首块公式的单一列表序号。六页手写项目在 `artifacts/markdown_mixed_m5_20261013/math-numbering/numbered-report.inkdoc`，配套 `verify_numbering.py`、`capture_numbering.py`。当前未提供按章节重置、计数器命令、自动生成普通 Markdown 的公式引用文本或可跨页拆行公式；列格式数组见下一节，其余 M5 项继续推进。

## M5 列格式数组、小矩阵与修饰符

`array` 列格式支持 `l/c/r`（左/中/右对齐）和单/双竖线。可在列格式前加 `[t]`、`[c]` 或 `[b]`，分别以首行基线、整体数学轴或末行基线对齐。最多 32 行、8 列、256 格；短行补齐右侧空格，多出的格子报错。普通 matrix 等环境保留原 8×8 与等列规则。

```latex
\begin{array}{r|cc}
\hline
1&2&3\\
12&34&56\\
\cline{2-3}
123&4&5\\
\hline
\end{array}
```

`hline` 作用于整行，连续两次形成双横线；`cline{a-b}` 作用于从 1 起算的列区间。规则线只能在首行前或换行之后出现，最后一条规则线也须跟在换行之后。同一边界允许两条 hline，或不重叠的多个 cline；不混用两类，也不接受重叠 cline，避免意外重复描线。暂不支持 `p{}`、`@{}`、重复格式、multicolumn、逐行间距选项或带星号换行。未支持的写法会诊断，原文保留。

列宽由该列最宽数学盒决定，行高包含完整结构；规则线另占间距，不覆盖内容。框线净距默认 0.12 em，至少 1.5 个笔宽，双线中心间距至少两个笔宽。框线有自己的源码范围及路径身份，外框相交端点相接；不用闭合 path 或重复描边。数组整块分页，不能容纳时明确报错。

`smallmatrix` 使用普通矩阵布局并缩小到默认 70%，整体仍对齐父公式数学轴。字号比例可在“矩阵与向量”设置中调整到 50%–100%；过小字形仍受六倍笔宽门槛检查。

支持 `vec`、`overrightarrow`、`overleftarrow`、`overleftrightarrow`、`bar`、`overline`、`underline`、`hat`、`widehat`、`tilde`、`widetilde`、`dot`、`ddot`。每个命令取一个原子，多个字符应使用花括号分组；可与上下标、分式和其他修饰符嵌套。短标记在内容上方居中，宽标记覆盖内容宽度；长箭头、双向箭头会为箭头端保留最小宽度。

所有修饰符为独立折线路径，不改变内容字形。净距默认 12%、构件高度默认 18%，以当前层字号为参照且受笔宽下限保护。横线和点号不使用构件高度；点号是一个笔宽长的短线，双点由两条分离短线组成，不能据此推断真实点写法已经采集或校准。新增高度进入数学盒测量，表格和脚注共享同一实现。

管道表中的列格式竖线仍须在 Markdown 层转义，例如：

```markdown
|计算值|
|---|
|$\begin{array}{r\|l}12&3\\4&56\end{array}$|
```

真实数字样张见 `examples/markdown_math_constructions_m5.md`；本机七页项目及导出在 `artifacts/markdown_mixed_m5_20261013/math-constructions/`。`tests/test_math_constructions.py` 覆盖源区间、列锚点、双框线/局部线、笔宽净距、空行/短行、预算、嵌套、小矩阵、表格/脚注/编号组合、原生重开、编辑身份及路径保真。全量 951 项通过、4 项跳过，此前 50 页冻结机器 SVG 逐字节一致；纸面效果仍待实机验收。
