# InkStruct 0.1.60 · Windows

2026-11-08。解压 [InkStruct-0.1.60-Windows-x64.zip](../artifacts/handoff_0.1.60_20261108/release/InkStruct-0.1.60-Windows-x64.zip) 后，保留完整 `InkStruct` 目录并运行 `InkStruct.exe`。

- 选择书写者、样本目录和目标字后，点击「开始生成」。首次使用或样本变化时自动导入并建档。仅缺当前方法的档案时沿用有效索引。准备失败时停止生成，显示阶段及原因，并保留上一次成功的索引和档案。样本来源、待更新提示、有效供体数仍在生成页显示。
- 书写者及来源就绪后，待制包清单在后台自动核对。改批次、扩展来源、名称、勾选或磁盘上的源文件时自动更新，核对期间制包按钮禁用。展开类别可查看缺字、复用及合成来源。用户仍选择批次和类别，并决定是否按当前覆盖制包。完整验证通过后才原子入库。
- 本次未生成字形时，如上一批仍可制作，按钮显示「制作上次批次…」，旁边显示上一批的书写者、日期和完成字数。取消后留下的部分批次显示已完成范围。

使用方式见 [统一应用说明](INKSTRUCT_0_1.md) 与 [LaTeX 手册源码](user_manual/chapters/10-generation.tex)。应用字体的额外确认、复制未录任务后的导航留待后续。
