# Markdown 混排编辑器

当前可排版版本：M0–M3、M4a–M4c 手写公式及 M5 受控文档扩展，2026-10-13。支持正文、标题、列表、引用、基本强调、链接、行内代码、围栏/缩进代码块、分隔线、管道表格和受控 HTML 表格。基础公式已接入正文与表格，支持范围见 [数学清单](MATH_SYNTAX.md)；模板已支持固定字段，图片与图题可以生成参考页面。外部后端已完成独立参考试验，实样校准和文档扩展继续推进；缺字及尚未支持内容会定位并阻止完整成品导出。

## 启动与保存

```sh
.venv/bin/python -m inkstruct.editor.app --source examples/markdown_tables_m3.md
```

使用“选择字形目录…”和“导入符号样本…”载入同一书写者的资源。数字和小数点可先用内置单线字形；真实汉字、英文及其他符号需要对应轨迹。左侧修改 Markdown，右侧显示实际毫米页面。点选页面字形可回选源码和评价具体样本。

主界面以左侧源码和右侧预览为主，顶部仅保留常用操作。“排版”打开右侧正文/元素/字形/问题设置，“字形评价”展开底部评价面板。启动时源码获得焦点，源码标题旁另有“粘贴”按钮；原生编辑菜单提供剪切、复制、粘贴与撤销。面板在 1000 × 700 窗口中可打开/关闭，切换不改变分页、选样和导出毫米坐标；平台证据及新版应用见 [界面更新](EDITOR_WORKSPACE_UPDATE.md)。

通用模板入口是“排版”→“元素”→“页面模板…”→“新建 / 设计模板…”。用户通过画布与属性编辑，Agent 通过相同模板 JSON 和检查/绑定命令设计布局，参见[通用模板方案](TEMPLATE_AUTHORING_PLAN.md)。华科 PDF 只作为参考底图和兼容性验证材料，不决定程序默认栏位。

“保存项目”生成可移植 `.inkdoc`，包含源码、样式、源身份、已选样本和资源。“保存源码”只保存 Markdown。可通过 `--project path/to/file.inkdoc` 重开项目。

重复预览会自动复用匹配的解析和完整布局结果；实际编辑时，未变化且字形依赖一致的正文、公式、表格和代码度量也可复用。普通文档能保留已核对的前部页面，从变化块开始续排，后部输入和分页状态重新一致时也可复用后部页面；模板正文也支持续排，固定字段继续重新合成。翻页可复用已解析的页面 SVG，重复导出可复用路径排序和反转决定。评价标记实时显示，缓存不写入项目文件。具体范围与验证见 [内容缓存](MARKDOWN_CACHE.md)。

自动恢复副本位于启动目录的 `artifacts/editor_recovery/`。每个编辑会话使用独立文件，同一项目在多个窗口或重开后产生的草稿不会互相覆盖。“打开恢复副本…”会恢复为未保存项目，正式保存时选择新位置。读取损坏项目失败会保留当前编辑内容；保存发现外部修改时会报告冲突。详细验证与限制见 [项目迁移与恢复](PROJECT_RECOVERY.md)。

## 表格设置

打开“表格设置…”，应用范围可选择文档默认或正文中的任一表格，无需先选中表格源码。已有独立设置的表格不受文档默认变更影响；勾选恢复沿用默认可取消当前表格的独立设置。

新表默认总宽 **160 mm**、最小行高 **8 mm**、数字高度 **3.8 mm**、四边留白各 **0.3 mm**。列宽可按内容、等宽、比例或固定毫米值分配；固定列宽合计须等于总宽。逐列对齐接受“沿用、左、中、右、小数点”，以逗号分隔。

普通行高允许内容撑高；启用固定行高后放不下会报错。跨页保持 rowspan 行组完整，表头可重复。字形不会为填满单元格而单独拉伸，也不会在内容过多时自动缩小整表。

HTML 采用受控标签与属性，需要显式闭合。支持 `rowspan`、`colspan`、单元格 `align`/`valign` 和受控行内内容；不支持任意 CSS、脚本及嵌套表格。

文档超出总量限制时会明确停止排版，旧快照不能正式导出；源码、身份和有效的现有资源仍可保存为草稿并恢复。请拆分文档或简化路径后重排，阈值与计数范围见 [文档总量限制](DOCUMENT_LIMITS.md)。

## 公式设置

“公式设置…”已改为参考 AxMath 第 4.1 节的分类界面：左侧选择字号、间距、上下标、分式、根式、积分/大运算符、矩阵、括号、多行对齐、公式编号、修饰与向量，中间实时显示当前项目手写预览，右侧调节参数。字号可用 mm/pt，比例以百分比显示；辅助基线、数学轴和尺寸箭头不进入机器文件。equation/align/gather 可自动编号，tag 指定标签，数学内 label/ref/eqref 保留引用关系。操作、默认值及支持边界见 [图形化公式设置](MATH_GRAPHICAL_SETTINGS.md)。

“公式设置…”单独配置公式字号、数学轴、运算符间距和独立公式对齐，保存进项目。默认公式字号 6 mm，不随表格数字高度改变。数字、分组、单位文字、函数、希腊及常用运算关系在有对应轨迹时可排版；公式不会在中间断行，超宽会报错。

普通上下标、分式、平方根及带根指数的根式可以嵌套排版。过小的脚本会报错，避免无限缩小。已支持运算符上下限、伸缩定界构件、简单矩阵和分段表达式，具体默认行为见数学清单。受控 align/gather、编号与标签引用、array 列格式/框线、smallmatrix 及向量/横线等修饰符已接通；任意宏不支持。英文/希腊需要 Windows 实样；内置单线资源只提供数字和小数点。数学轴仍有待校准警告，离屏样张不代替写字机实测。

## 任务列表

支持列表首段的 `[ ]`、`[x]` 和 `[X]`。左键点击预览方框会修改源码状态，可撤销/重做；正文位置与已选字形保持稳定。方框和勾线直接导出为可书写折线，支持嵌套、有序、空任务及重复模板。详见 [任务列表](TASK_LISTS.md)。


## 代码块设置

“代码设置…”独立配置字号、字格宽度、最小行高和制表位列数，默认 4 mm、5 mm、6 mm、4 列。保留空行、尾随空格和字面符号；缺字、超格及默认的超宽行会阻止导出。可明确开启宽行换行，续行会绘制标记。详见 [代码块排版](CODE_LAYOUT.md)。

## 导出

独占一段的图片可在“图片设置…”中导入 PNG/JPEG，设置毫米尺寸和对齐；替代文字作为图题，随图片整体分页。资源随项目保存。含图文档允许“导出页面…”生成带明显标识的参考 SVG/PNG，但禁止写字机导出；详细范围见 [图片块与图题](IMAGE_LAYOUT.md)。

同一窗口也可导入受控 [单线 SVG](LINE_SVG_LAYOUT.md)，设置最终毫米曲线容差。校验通过后，图形可与正文共同导出机器路径；这与上述普通位图参考页面的能力不同。

“导出写字机 SVG…”导出完整文档。选择一个尚不存在的输出目录；每页机器文件只有 path 元素与绝对 M/L 指令，清单记录路径来源和优化距离。勾选“优化路径”即固定允许路径反转。

表格与图片设置均提供“应用范围”：文档默认或具体元素。默认影响沿用默认的元素及后续新增元素，已有独立设置保持不变。每个元素可恢复沿用文档默认；设置随项目保存。表格设置确定后应用于所选范围，切换范围会重新载入该范围的设置。

## 迁移旧表格项目

“打开项目…”可选择 `.inktable`。所引用样本 ZIP 必须仍在记录位置且内容未变；如果缺失或变化，先恢复旧资源。导入保留旧尺寸、列比例、种子和每次选样，随后保存为新的 `.inkdoc`。原项目保持不变，新项目包含资源，可独立迁移。

命令行也可导入和导出：

```sh
.venv/bin/inkstruct document render table.inktable \
  --plotter --output artifacts/imported-table \
  --save-project artifacts/imported-table.inkdoc
```

旧项目在新引擎中使用统一基线，因此不保证迁移后整页坐标与旧工具完全相同。既有独立表格工具仍可打开原项目复现旧排版。

阶段证据与资源边界见 [实施记录](MARKDOWN_MIXED_LAYOUT_PROGRESS_20261013.md)。

## 页面模板

“页面模板…”可导入显式 JSON，选择预印纸/空白纸并设置毫米校准偏移；设置和底图随项目保存。首页与续页正文区独立，模板固定框线与正文分开优化。模板对话框可将顶层源码块绑定到固定填写区域，支持首字基线锚点和每页重复；超出区域或绑定失效会阻止导出。测量依据、CLI 用法及能力边界见 [页面模板](PAGE_TEMPLATES.md)。

## Obsidian 静态扩展

“内容模式”旁可选择“普通 Markdown”或“Obsidian 静态扩展”，默认普通 Markdown。新方言显示双链标签、展开 Callout，并将有显式标签的嵌入作为静态引用；不读取目标内容。缺少标签的嵌入明确报错，带标签的嵌入保留提示。切换不改源码，方言与项目保存，旧项目仍使用普通 Markdown。语法、管道表转义、默认标题资源及 CLI 入口见 [Obsidian 静态排版](OBSIDIAN_STATIC.md)。

## 超高表格与诊断定位

跨行合并的连接行组必须完整放在一页；当前不拆分单元格内部内容。超高时，诊断列出具体行组、所需和可用高度，选择诊断可定位该段源码。可以保存 `.inkdoc` 草稿继续修改，但成品页面和写字机出口均拒绝；问题预览不能作为成品。脚注中的表格采用相同原子规则，详见 [复杂表格评估](COMPLEX_TABLE_PAGINATION.md)。

完整功能边界见 [支持矩阵](MARKDOWN_SUPPORT_MATRIX.md)，启动与复现见 [交接说明](MARKDOWN_DELIVERY_HANDOFF.md)。
