# 页面模板与预印纸

应用 0.1.21 的新模板为 **简单模板 / 自定义模板 v3**，支持起始／多布局循环、有序正文框和单份 Markdown 命名字段。操作与协议以 [模板单正文说明](TEMPLATE_SINGLE_FLOW.md) 为准，Windows 实际结果见 [0.1.21 交付](RELEASE_0_1_21_WINDOWS.md)。下面的 v1/v2 首页／续页、固定区和历史 macOS 验收记录保留，作为旧模板兼容说明。

当前支持显式物理尺寸、首页/续页正文区、固定框线、定位锚点、源码绑定的固定字段、预览底图及校准平移。段落、表格、公式和代码继续使用同一排版内核，源身份和选样不随模板变化。几何模板版本为 `inkstruct_page_template_v1`，带可复用语义字段的版本为 `inkstruct_page_template_v2`，详见 [内容字段](TEMPLATE_SLOTS.md)。旧版读取与序列化保持兼容。

## 使用

通用设计入口为“页面模板…”→“新建 / 设计模板…”，支持毫米数值编辑、画布多选/对齐/等距、拖动/四角缩放/绘制、网格吸附、毫米标尺/视图缩放、PNG/JPEG/PDF 页码底图及透明度、首页/续页预览、JSON 往返与撤销。用户和 Agent 使用相同的模板模型；Agent 可通过 `template inspect-content / bind / validate-document` 对原生项目检查、绑定并试排，源内容不写入模板；架构、命令与后续画布设计见 [通用模板设计方案](TEMPLATE_AUTHORING_PLAN.md)。本文中的华科样例只验证兼容性与坐标行为，不是产品限定的表单。

混排编辑器中点击“页面模板…”导入 JSON，选择预印纸或空白纸，调整横向/纵向偏移。取消不修改项目，超出纸面时不接受配置。“使用普通页面”移除模板，恢复普通页面配置。模板和嵌入的 PNG 底图随 `.inkdoc` 保存，可脱离原 PDF 重开。预览和机器导出分别使用同一份书写几何。

CLI 示例：

```bash
.venv/bin/inkstruct document render examples/markdown_template_m5.md \
  --mode markdown \
  --template configs/templates/hust-physics-scan-v1.json \
  --run outputs/full_library_20261010/user_001/all_supported_v4_adaptive_20261010 \
  --symbols 'artifacts/markdown_mixed_m0_20261013/private_tables/user_001含小数点.zip' \
  --save-project /tmp/hust-template.inkdoc \
  --plotter --optimize-paths --output /tmp/hust-template-machine
```

此命令中的真实资源路径属于本机已有产物，其他设备需指定自己的资源。输出目录必须尚不存在。省略 `--plotter --optimize-paths` 会生成预览 SVG/PNG。模板拥有页面尺寸与正文区，不允许同时通过 CLI 覆盖页宽、页高或页边距。

- **预印纸**：PNG 底图只在预览中显示，不转换为路径。无 PNG 时以灰色显示配置框线；这些灰线也不进入机器 SVG。校准偏移只移动书写内容，纸面参考保持不动。
- **空白纸**：不显示底图，只绘制明确配置的框线及正文。框线与正文都受校准偏移影响；先完成模板框线，再书写正文。路径优化尊重两个执行区间，区间内仍自动允许反转。
- 两种模式的机器 SVG 仍只有 `path` 元素与绝对 `M/L` 指令。原始采样资源不变。扫描标题、签字、条码不会被描摹或当作手写资产输出。

## 华科扫描模板的数字测量

来源：用户提供的 `华科物理实验报告模板.pdf`；SHA-256 为 `766c3b33db0696382be609e2e8ceb09085ee1ab6cbf2bfdb97cd30d35f085045`。

4 页均为单张扫描图片，无可提取的文字或矢量框线。每页为 552.84 × 765.48 pt，换算为 **195.029667 × 270.044333 mm**。这不是 A4；按原 PDF 点数尺寸建模，没有自动放大。早期进度口述中的约 270.6 mm 是换算错误，以此精确换算为准。

测量在 1012 × 1400 像素的渲染图上进行：人工选择四条外框的局部区域，取灰度小于 110 的线心中位数，记录 ROI、支持像素数量和 5%/95% 分位。结果是理想化矩形，不把扫描歪斜、噪点和线条起伏转换为书写路径。已检查叠加图。第 2–4 页框线测量一致，当前续页重复使用第 2 页的参考。

## 当前限制与验收范围

模板 v1 在首页和续页使用相同正文宽度，续页高度不得小于首页；不支持不同宽度重新断行。坐标原点是纸张左上角，单位为 mm；仅支持平移，旋转和缩放尚未实现。过高的首行或原子表格行组可以移到更高的续页，不能容纳的内容仍阻止正式导出。

固定字段已接通完整顶层 Markdown 块与保留区的绑定，具体限制见下文。当前空白纸只绘制显式框线、字段下划线及内容，没有复刻扫描标题、栏位标签或条码，因此不是完整的学校空白表单。[图片块与图题](IMAGE_LAYOUT.md) 已支持参考预览和项目内保存；含正文图片的项目禁止写字机导出。[单线 SVG](LINE_SVG_LAYOUT.md) 已接通可书写图形；通用设计交互和物理纸面校准继续按 M5 推进。

数字坐标验证不等于纸面校准。没有测量打印机缩放、进纸偏差或写字机落笔位置，因此默认保留 `template-calibration-unreviewed` 警告。英文和希腊新采集样本仍未同步。

本机验收目录为 `artifacts/markdown_mixed_m5_20261013/template/`，包含测量叠加图、两种模式各 2 页的 PNG/机器 SVG、两个可移植 `.inkdoc` 与 `verification.json`。复现脚本位于上级 `measure_template.py`、`verify_template.py`。实例覆盖、模式间正文几何一致、原资源未变、保存重开一致、优化不增加空行程、路径排序/反转保真以及严格 SVG 格式均有断言；实际纸面测试尚未进行。


## 固定字段绑定

导入 `configs/templates/hust-physics-fields-v1.json` 后，在“页面模板…”中选填写区域和源码块（支持多选），设置倍率、首页/所有页及可选基线锚点，然后点击“绑定所选源码块”，最后确认整个对话框。解除绑定后内容恢复到正文流；使用普通页面会清除所有字段绑定。整个对话框取消不改变项目。

每个字段存储 `TemplateBinding(region, node_ids, pages, scale, anchor)`，版本为 `inkstruct_template_binding_v1`。只引用顶层语义块，不复制字段文字，不把坐标写入 Markdown。多个块按照原源码顺序填写，不能将同一块同时绑定给两个字段。字段在纸面的顺序由模板配置决定，字符的 occurrence、源范围和选样仍保留。点击预览中的字段字符可以回到其源码。

`first` 只在首页填写，`all` 在所有页填写；后者要求首页与续页均有同名保留区和所用锚点。续页重复实例保留相同源码身份并标为 repeated，不能算作新增源字。各页可有不同字段宽高，分别测量；不允许通过缩小、截断或丢弃字符来塞入栏位。

倍率缩放字段内正文的 em/行高，以及公式 em、代码 em/字格/行高；段距、缩进、笔宽和表格独立尺寸保持既定毫米值。设置锚点时，它定义首个逻辑字符的横坐标和基线，原字形边距不变，不按墨迹包围盒猜测位置。未设锚点则从区域左上角正常排版。无论哪种定位方式，越框和需要跨页的字段都会阻止成品导出，调试场景保留全部内容供检查。

绑定采用当前源码节点身份。段落内部编辑通常保持绑定；删除/替换整个节点或破坏其起始身份时，会出现 `template-binding-source-missing`，需要重新绑定或解除。导入不兼容模板导致区域/锚点缺失也会报错。失效绑定不静默删除仍存在的源码内容，不会输出一份缺字段却标为完成的成品。

绘制顺序为配置框线（仅空白纸）、各固定字段、正文。每个字段有独立执行区间；优化在区间内自动允许反转，不跨区间改写顺序。项目保存包括绑定关系，首次排版后立即保存重开的完整快照也已验证一致。

### 四字段实样

`examples/markdown_template_fields_m5.md` 前四段分别为示例姓名“张三”、示例学号、实验名称、实验编号；它们绑定到首页的对应栏位，正文中不再重复出现。源码由本项目自编，用于布局验证，不表示真实学生信息。

公开四字段配置含理想化外框及四条下划线，不含扫描背景；本机 `artifacts/markdown_mixed_m5_20261013/fields/reference-template.json` 嵌入经过哈希校验的原页 PNG。四个可写区按原渲染图手动选取，基线设计在印刷下划线上方 0.9 mm；这些是数字布局参数，尚未经纸面试写校准。

两种模式各 2 页、473 个绘制实例，其中固定字段为 21 个字符。3547 个字段采样点逐点核对原始轨迹的等比缩放与平移；原 JSON 未改变。预印模式共 1184 条机器路径，空白纸为 1190 条，多出的 6 条为两页外框及四条字段下划线。源码覆盖、重复标记、两模式内容几何一致、严格 M/L、路径排序/反转、执行区间和可移植重开均有断言。

实样项目为上述本机目录下的 `preprinted.inkdoc` 和 `blank.inkdoc`，最终样张/机器文件在 `preprinted-preview`、`blank-preview`、`preprinted-machine`、`blank-machine`；复现脚本为上级 `verify_fields.py`。名称含 `before-snapshot-key-fix` 的目录只保存早期元数据供对照，不作为当前交付。


## 从诊断定位填写区（2026-10-14）

混排编辑器的诊断列表旁新增“修正模板…”。选择带模板目标的诊断后，按钮进入页面模板设置，选中对应已有绑定，或定位到尚未填写的区域并清空旧内容选择。未绑定的必填字段没有真实源码范围，选择该诊断不会把光标跳到正文开头。有源范围的问题继续选中源码及实际字形。

修正窗口显示本次构建的问题、字段编号、首页/续页和适用的实际页码。再点击“新建 / 设计模板…”会选择对应页型和填写区；区域不存在时明确提示恢复对象或解除绑定，不代选其他区域。锚点不存在但填写区存在时，选中区域并提示缺少的锚点。定位只改当前选中状态，不改毫米几何、不增加撤销记录。确认设置后重新排版，取消保持原项目不变。构建尚未完成或内容已改变时，不能使用旧诊断的修正按钮。

字段诊断通过结构化 `target` 记录 `region`、可选 `slot_id`、`face`、`node_ids`、可选 `anchor` 和 `page_index`。`page_index` 从 0 开始，尚未进入真实页面布局的配置/缺填问题为 null；界面显示页码时加 1。该目标随 CLI 验证与布局报告输出，Agent 无需解析中英文提示文字来猜字段名。普通诊断的结构保持原样，原生项目不保存这批构建结果。

已覆盖必填/类型/策略、失效绑定、首页/续页缺少区域或锚点、固定区配置、字段内部缺字和溢出。构造阶段的几何重叠/越界与 JSON 草稿定位现已接通，见下一节；几何检查与实际内容适配仍是两个独立出口。

重新添加被解除的绑定仍沿用既有规则：追加到绑定列表末尾。这可能改变字段执行次序和路径排序，即使每条笔画的形状与位置完全相同。真实验证分别检查几何保真和新项目保存重开后的 SVG 一致性，不把原 SVG 的字节差异当作笔迹变化，也不宣称恢复了原绑定次序。


## 无效几何草稿的定位与修正（2026-10-14）

模板设计器在错误提示下方提供问题对象选择框和“定位问题对象 / JSON”按钮。列表使用首页/续页、对象类型、名称与属性标签；选择冲突的一方即可跳到对应页型和属性表。重叠会列出两个区域，重名会列出同名对象，首页/续页正文宽度或高度不兼容会列出双方属性。越界会列出出界对象（折线还包含具体顶点）及横纵校准偏移；校验计入线宽半径。

定位只改变选择、页型和焦点，同时在 JSON 页签中选择对应值，不修改草稿或添加撤销事务。没有数字属性编辑器的目标（例如字段声明中的无效区域引用、底图对象或模式错误）会转到 JSON。修改属性未写入时禁用定位，避免切换对象丢失当前编辑。无效草稿继续隐藏旧画布、禁止确认/导出；修正并写入后重新执行原有模型校验，通过才恢复预览。取消窗口不改变外层项目。

JSON 语法错误定位到解析器给出的字符位置；中文/emoji 使用正确的 Qt UTF-16 光标转换。嵌套过深的 JSON 返回明确错误并转到源码页签，不尝试猜测某个几何对象。其他尚无具体对象信息的格式错误仍回退到整份 JSON 草稿。

同一构造校验器向 Agent 返回稳定错误代码及 `targets`。例如区域重叠的两个目标是 `path: ["first", "body"]` 和 `path: ["first", "reserved", 0]`，并附对应 JSON Pointer `/first/body` 与 `/first/reserved/0`。语法错误另有 `source_offset`，使用原始 JSON 的 Unicode 标量偏移；界面自行转换为 UTF-16，Agent 不应把它当作 UTF-8 字节位置。输入文件不修改，失败不生成预览目录。

每次返回最先触发的模型错误及其相关对象，修复后再检查下一项；当前不是一次穷举全部错误的检查器。新异常仍继承 ValueError，原 v1/v2 模板结构、几何约束和旧异常消息匹配保持兼容。有效模板不会增加诊断字段或改变其保存格式。

## 联动重命名填写区和锚点（2026-10-14）

在“页面模板…”中点击“联动重命名填写区 / 锚点…”，选择对象类型、原名称与新名称。确认后同步更新首页和续页中的同名对象、语义字段声明的区域/锚点引用及当前项目的内容绑定。字段编号、显示名称、绑定次序、源身份、选样、毫米坐标、校准参数和底图来源均保持不变。最后确认页面模板设置才应用到项目；任一级取消均保留原项目。

名称被视为跨页型的同一个标识。新名称不得为空或超过 256 个字符，不得占用其他同类对象或正文区标识，也不得接管现有失效绑定引用的名称。已有的较长旧名称可原样确认，不会截断。操作先构造完整候选再校验，不会留下只改对象、未改引用的半成品。

Agent 使用相同操作，可处理独立模板或带内容的原生项目：

```bash
.venv/bin/inkstruct document template rename template.json \
  --kind region --from-name observation --to-name observations \
  --output template-renamed.json

.venv/bin/inkstruct document template rename record.inkdoc \
  --kind anchor --from-name baseline --to-name entry-baseline \
  --expect-sha256 INPUT_SHA256 \
  --output record-renamed.inkdoc
```

输出必须为尚不存在的新文件，类型与输入一致。可选输入 SHA-256 防止覆盖检查后已改变的状态。独立模板只验证模板几何及声明；原生项目还执行完整内容试排，有错误时返回诊断且不保存输出。报告区分内容适配、可导出能力和是否保存；成功改名本身不代表完成严格机器 SVG 检查或物理纸面校准。

只有此显式操作联动引用。直接编辑设计器属性或 JSON 中的名称仍须自行维护引用；模板文件另存也不会扫描修改其他项目。当前不提供正文区、字段编号或显示名称的批量改名迁移。

## 查看并保存内容适配报告（2026-10-14）

配置页面模板并等待混排预览更新后，点击诊断栏的“适配报告…”。报告使用这次真实排版的结果，列出页数、错误和提醒、每个填写区的绑定状态，以及正文和全局问题。缺填必填字段、内容类型不符、失效绑定、缺字、越框等不会被成功预览掩盖；有错误的快照仍可打开报告以便修正。没有模板、纯文本模式或预览尚未更新时，入口禁用。

字段的“未发现字段内错误”只表示没有指向该字段的错误，不代表整个项目通过；未绑定的可选区单独显示为“未绑定”。同名跨页区域合并为一项，其问题保留首页/续页及实际页码。选择问题后点击“定位所选问题…”，模板问题进入已有修正窗口，普通正文问题定位源码。报告关闭或保存不会改变内容和选样；若报告打开期间项目已变化，旧问题不能用于定位修正。

“另存报告 JSON…”保存 `inkstruct_template_fit_report_v1` 到新文件，不覆盖已有文件。报告包含文档身份、构建 revision、源码哈希、模板哈希、布局/资源键、字段绑定和结构化诊断；不附整份源码或笔迹资源。Agent 的 `template validate-document` 和 `template bind` 返回同一结构的 `fit_report`（无模板时不提供）。GUI revision 记录界面重建轮次，CLI revision 来自已保存源码会话，两者可不同；核对同份内容还应比较其哈希和布局键。

报告基于已经完成的实时试排，不另起一套同步排版计算。`exportable` 表示没有阻断导出的内容错误，`plotter_exportable` 还要求没有不可书写的位图；严格机器 SVG 检验与物理纸面校准不由此报告执行，`machine_svg_verified` 和 `physical_alignment_verified` 均为 false。后续调整内容、模板或资源后，应等待新的预览并重新查看报告。

## PDF 导入的取消与超时（2026-10-14）

PDF 读取和渲染在独立进程完成。向导打开后先显示等待状态，读取完成后提供页码选择；切换页码期间清空旧预览与候选，禁用确认和页码/方式控件，取消按钮仍可用。取消、关闭向导、超时或子进程异常都会停止子进程，原模板保持不变。确认成功候选后同样回收进程，外层设计器仍可撤销应用。

每次读取和单页渲染分别限时 30 秒；超时后显示错误，请关闭向导并重新尝试或使用更简单的 PDF。文件只在子进程打开时读取一次，后续换页使用同一字节快照，即使磁盘文件被外部程序改写也不会混入不同版本。程序化页码变化也会丢弃不匹配的旧页结果。

Agent 的 `template from-pdf` 使用同一子进程后端，一次完整导入限时 30 秒。只有完整解析、渲染和模板校验通过后才创建新的输出 JSON；存在的文件不会被覆盖。原有 50 MiB 文件、1000 页、1600 px 参考图与 2 MiB 模板限制保持。Python 安装版使用模块入口；独立编辑器应用使用同目录的 InkStructTool 工作程序，缺失时拒绝导入，详见 [独立应用](EDITOR_STANDALONE.md)。此改动未完成 Windows 原生交互或写字机纸面验证。
