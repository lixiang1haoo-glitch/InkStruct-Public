# 复杂表格分页评估（M5-05）

日期：2026-10-13。结论：继续使用已实现的“完整行组分页”。合并单元格内部、单个超高单元格内部的跨页拆分尚未实现，不能容纳时必须阻止成品输出。M5-05 的评估与明确诊断出口已完成；这不表示内部拆分功能已经实现。

## 已定义并执行的规则

`TableModel.row_groups` 对 rowspan 连接关系取传递闭包。若第 1 行的格跨到第 2 行、第 2 行另一格跨到第 3 行、第 3 行另一格跨到第 4 行，则四行属于一个原子行组；不能因为每个格都只跨两行就只保留两行。colspan 只影响列约束，不连接不同的行。

表头与首个数据组共同排版。后续页按“重复表头”配置添加表头；关闭重复只影响后续页，不允许将首次表头单独留在前页。表头边界不能被 rowspan 跨越，源解析阶段直接诊断。

| 内容状态 | 当前行为 | 输出状态 |
| --- | --- | --- |
| 行组放不进当前剩余空间，但能放进空页 | 完整行组移到下一页；需要时重复表头 | 可正常导出 |
| 多行由直接或传递 rowspan 连接 | 连接的所有行保持在同一页 | 能容纳时可导出 |
| 单个普通单元格有多行文字 | 内容在格内换行，整行仍不可跨页拆分 | 超高则阻止导出 |
| 行组加必要表头超过空页 | 消费该组一次，保留问题几何和来源 | 阻止成品页面与机器导出 |
| 仅表头的表格超过空页 | 表头整体保留一次并报告高度不足 | 阻止导出 |
| 脚注表格的行组超过可用注释页 | 保留一次问题单元，游标继续前进 | 阻止导出，避免无限续页 |
| 固定行高不足 | 保留 `table-fixed-row-overflow` 单元格诊断 | 阻止导出，不压缩笔迹 |

长公式、字形或其他不可拆盒不会按几何边界裁断；自动字号缩小也不是分页策略。原文字、选择的字形与原始笔画保留。跨页只对完整单元平移，框线按当前页重建，共用边只描一次，笔画不跨页面连接。

## 本轮诊断改进

`table-group-height-overflow` 的代码保持兼容，消息增加行号、是否由 rowspan 连接、含必要表头的所需高度、实际可用高度和调整建议。源码范围缩小为问题行组的单元格区间，不再选择整张表。普通分页与存在脚注时的正文表格分页都使用同一诊断构造器。

脚注内部的 `NoteUnit` 同样记录具体行组的源范围；超高表格单元的 `footnote-line-height-overflow` 不再泛称“脚注行”，会说明是原子表格行组，以及所需与空注释页可供高度。诊断定位、草稿保存和重开可用；机器按钮禁用。正式页面出口也会拒绝，只有显式问题预览允许显示带标记的几何。

建议操作是增大可用页面高度、调整表格尺寸，或由作者在保留合并关系的前提下拆分源表。不能用关闭诊断、裁掉页外内容或把成品出口改成 debug 来通过验收。

## 内部拆分为何仍未启用

内部拆分会改变当前 `TableChunk.rows`（完整源行集合）与 `paint_table` 的契约。单纯切 SVG 会截断字形、公式或合并框线，也无法正确处理脚注首次引用。若后续实现，须先确定并验证以下规则：

1. 每个单元格使用独立内容游标，但一页只在所有相关列均合法的行盒边界结束；数学盒与字形笔画不可裁切。
2. 明确合并格续页的内容分配、空白续格、首次与续页垂直对齐政策；不能自动复制单个居中文字到多页。
3. 区分源单元格与派生分页片段。续页边框有明确来源和身份，每页独立闭合，共用边去重，所有原内容恰好出现一次。
4. 首次/重复表头、序号/列头与脚注引用共同参与容量试探。重复表头不再次分配脚注内容；新片段的首次引用必须与必要注释开头同页。
5. 保留源实例、选样、评价、点击定位及撤销/重开。页面片段变化不能被当作重新生成原字形的理由。
6. 为无可行切点、单个盒大于空页、交错 rowspan、重复表头过高、空单元及脚注竞争提供单调前进证明与明确失败出口。

这是一份后续设计输入，不是已经接受或启用的配置。当前没有新增“允许裁切单元格”开关，也不静默将 middle/bottom 改成 top。M5-05 按原计划完成的是评估与阻断边界验证，而非承诺任意复杂表格都可写出。

## 验证与实样

新增 `tests/test_table_pagination_policy.py` 8 项和实际 Qt 测试 1 项，覆盖传递 rowspan、精确行组范围、正文两类分页器、两个成品出口拒绝、仅表头/超高普通格、重复表头开关、colspan、超高脚注单元单次消费、成功整组分页、源码覆盖、诊断跳转及草稿重开。全量 **987 passed、4 skipped，35.43 秒**，相关 Ruff 通过。

此前 **64 页机器 SVG** 回放逐字节一致。本轮没有改变表格默认 160 mm 总宽、8 mm 行高、3.8 mm 数字高度、0.3 mm 留白或优化自动反转策略。脚注行组来源范围与错误消息的改进不改变可导出样张的几何。

可复现证据位于 `artifacts/markdown_mixed_m5_20261013/table-pagination-assessment/`：

| 用例 | 页数 / 实例 | 结果 |
| --- | --- | --- |
| `valid-chain` | 3 / 13 | 真实数字，传递连接的四行同页，后页重复表头；30 条严格 M/L 路径 |
| `blocked-chain` | 2 / 11 | 含表头需要 40.000 mm，可用 27.700 mm；定位第 2–5 行，阻止成品输出 |

这些是为分页边界设置的小页高测试，数字来自既有手写资源；不是新的实验测量数据，也不是写字机纸面测试。实例数包含换行和重复表头，完整源码覆盖按非重复实例核对。失败用例目录仅有 `.inkdoc` 草稿及 `debug-preview/`，没有机器文件；成功用例有 `preview/` 与 `machine/`。

脚本 `build.py` 生成四个独立项目与 `cases.json`，复跑须通过 `--output` 指定新目录，脚本拒绝覆盖已有用例；`replay.py` 和同目录 `frozen_base.py` 只读回放过去输出，不覆盖旧报告；`capture.py` 验证实际 Qt 行组定位与机器按钮禁用，截图 `blocked-group-editor.png`。每个草稿原生重开得到相同布局；有效项目验证严格 path/M/L 和排序反转保真，失败项目分别调用两个成品出口确认拒绝。Windows、纸面及写字机校准仍属于后续实机验收。
