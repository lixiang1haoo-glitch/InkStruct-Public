# 字集研究第一版说明

建议以累计 **100 字**作为推荐录入清单，每字一份。已有起步 32 字时，使用追加 68 字任务。scx 和 wsq 均有这 100 字的已准入原稿。历史 400 字用已有原稿评估更大录入量的收益。

| 清单 | 每位作者的标准笔画数 | 用途 |
| --- | ---: | --- |
| [起步 32 字](../../configs/collection/research_v1/starter32/characters.csv) | 285 | 起步录入 |
| [追加 68 字](../../configs/collection/research_v1/add68/characters.csv) | 676 | 已完成起步任务后补录 |
| [累计 100 字](../../configs/collection/research_v1/total100/characters.csv) | 961 | 从零完成推荐清单 |
| [历史 400 字](../../configs/collection/research_v1/historical400.csv) | 4,178 | 已实测的对照清单，含 159 个一级表外字 |
| [一级 400 字候选](../../configs/collection/research_v1/primary400_candidates.csv) | 3,801 | 后续补录候选，两位作者各缺 271 字原稿 |

目标取仓库《通用规范汉字表》一级前 3,500 字。本次所用结构库支持全部目标。累计 100 字保留起步 32 字，从两位作者都已录且通过检查的一级字中，按新增部件、笔形和连笔匹配机会及录入笔画成本挑出 68 字。一级 400 字候选在同一目标范围内继续补覆盖。

| 作者 | 录入档 | 本人笔位 | 来源分 | 识字 Top-1 | 轨迹 DTW |
| --- | --- | ---: | ---: | ---: | ---: |
| scx | 32 字 | 89.52% | 58.76 | 98.92% | 0.06013 |
| scx | 100 字 | 95.19% | 66.57 | 99.16% | 0.05851 |
| scx | 历史 400 字 | 98.65% | 73.46 | 99.07% | 0.05678 |
| wsq | 32 字 | 90.16% | 59.67 | 98.98% | 0.04271 |
| wsq | 100 字 | 95.72% | 67.22 | 99.01% | 0.04786 |
| wsq | 历史 400 字 | 98.97% | 74.11 | 99.13% | 0.04666 |

本人笔位和来源分采用三个方案共同未录的 3,259 字，每位作者与方案各有 31,513 个标准笔位。来源分按完整本人部件 80、本人单笔 60、标准骨架 0 计算字内均值，再对各字等权平均。整字原样回放可计 100，本次实验关闭同字复用。识字 Top-1 固定渲染线宽，以模型覆盖的 3,233 字为分母。DTW 按每位作者 50 个同字原稿计算，距离越小越接近。三种指标保留各自量纲。

累计 100 字让两位作者的标准骨架补笔约减半。识字率在各档接近。与 32 字相比，scx 的平均轨迹距离略降，wsq 上升。推荐 100 字的依据是笔迹复用与录制成本的平衡。详细计算、逐字结果和按字形结构排列的图册见队内第一版研究包。

实验使用提交 `1250437`、桌面应用 `0.1.74` 和 `v6.3 exp`。两位作者各生成三个预算的完整一级字表，共 21,000 个结果，生成失败 0 个。重建数据库逻辑哈希与锁定值一致，SQLite 文件字节哈希有差异。项目任务书指定的 v6.2 正式对照与 Android 真机联调另有验收条件。

指标设计参考 [Dai 等，CVPR 2023](https://arxiv.org/abs/2303.14736) 和 [Ren 等，ICLR 2025](https://proceedings.iclr.cc/paper_files/paper/2025/file/0e0df370cd1ce52c09bb5c1aa584625d-Paper-Conference.pdf) 对识字和轨迹距离的使用。见[交接文档](交接.md)了解采集、复核和提交步骤。
