# 排版计划评审与首批构建记录

评审日期：2026-10-09。依据用户提供的《InkStruct 排版编辑与预览构建计划》v0.1，以及本地基线提交 `7a1178c`。结论是总体架构可用，可以开始增量实现；本文记录首批代码、实测结果与尚未验收的范围。

后续已新增双栏纯文本编辑和人工字形检查；最新使用范围见 [检查应用说明](TEXT_REVIEW_APP.md)。下文保留首批只读页面原型的验收记录。

## 计划需要收紧的地方

1. **工程起点需要更新。** 提案固定的是 `2b4f681`，本地已有高保真轨迹、原稿优先重建、局部几何修正等入口。页面适配必须保留扩展字段，不能只反序列化旧模型中列出的字段。首批适配器保存原资产 JSON 字节，并另外冻结绘制所需的点。
2. **中英混排依赖实际资产和度量。** 现有字库主要提供汉字，不自带整套拉丁、数字、标点及其基线。不能把缺字悄悄交给系统字体。首批默认只为汉字定义中文 em 校准；其他可用轨迹需要显式提供外部度量。缺少资产或度量时给出阻塞诊断。
3. **阶段前置要按能力理解。** 原计划要求完成全部 P0 才验收 P1。其中公式 SVG 和 IME 试验分别约束数学与交互编辑。当前只构建 P0 契约基础及 P1 纯文本原型，没有宣称 P0/P1 整阶段通过，也没有绕过这些试验开放对应能力。
4. **Unicode 版本号不等于符合规范。** Python 3.12 与 3.13 的内置 Unicode 数据不同。首批使用有版本标识的保守分段与中文禁则子集，将实际 `unicodedata.unidata_version` 纳入任务键；不声明完整 UAX 14、UAX 29 或 CLReq 合规。进入交互编辑前仍需选择、锁定实现并运行官方对应版本测试集。
5. **文档包与编辑器不是序列化快照就能完成。** 跨编辑身份迁移、孤立覆盖、撤销分支、保存冲突、包内哈希与异常恢复需要独立实现。首批的 `layout.json` 是可审计的派生输出，不能当作 `.inkdoc` 文档包或可靠编辑存档。
6. **预览与导出需要实测后端差异。** 本次实际发现 Qt 6.9.2 对纸张背景 SVG 百分比尺寸的显示不符合页面预期。改用明确的页面尺寸，并添加 Qt 四角及中间像素检查。数学 SVG 后续也必须运行基线、资源内联和安全清理试验。

普通矢量数学回退、受控 Markdown、流式文档三个默认建议可作为后续实现方向；当前没有安装新数学后端，也没有把这些建议当作已实现功能。

## 首批已经实现

| 部分 | 当前行为 |
| --- | --- |
| 文档与源码 | 不可变 Document、Node、Occurrence；不透明 ID；半开 Unicode scalar 源范围；原样保留重复字、空白、CR/LF/CRLF |
| 边界转换 | scalar 与 UTF-16 边界往返，拒绝拆开 surrogate pair；组合附标、emoji ZWJ、旗帜等保留为保守集群并明确拒绝不支持的绘制 |
| 字形适配 | 只读加载既有 `personal_trajectory_v1`，内容哈希身份，原始 JSON 字节，冻结全部点、笔画顺序、累计时间、压力、up/end 端点 |
| 度量 | 毫米页面坐标；中文 em 基线 0.88；由实际几何和固定笔宽计算墨迹包络；非汉字外部校准 |
| 断行分页 | 可替换的贪心算法、中文禁则子集、拉丁词组不拆分、硬换行、内容驱动行高、多页前进、空白及尾换行占位 |
| 快照 | 一次排版冻结页面、实例片段、源码范围、资产身份、毫米绘制指令、诊断及完整的当前已实现输入键 |
| 输出 | SVG/PNG 消费同一快照；PNG 的 DPI 不参与断行；失败时清理暂存目录；只向新目录发布完整页面组 |
| 桌面 | 生成器新增“页面预览…”按钮，后台读取纯文本和已有生成目录；预览按页切换；同一快照可导出 |
| 导出门槛 | 缺字、坏资产、未知集群、不合法硬边界、超宽、超高、墨迹越界阻止正式导出；调试输出带显式水印且返回失败状态 |

没有修改生成算法、旧单字 JSON、原单字 renderer，也没有新增运行依赖。预览使用项目已有的 PySide6 6.9.2。

资产笔压和时间被完整保留，但当前笔刷是固定毫米宽度，未实现压力笔刷或书写动画。布局缩放不会改变原资产点。多个重复实例可共享同一确定性字形，没有随机扰动。

## 使用方式

桌面生成器中点击 **页面预览…**，先选择 UTF-8 `.txt` 正文，再选择包含 `trajectories/` 的生成结果目录。页面窗口可以切换页码并导出。默认 A4、20 mm 页边距、6 mm em、9 mm 最小行高、0.3 mm 笔宽。

这一路径只读取已有字形，不自动补生成。正文中每个可见字符都需要对应资产；首批默认不会借用系统字体显示标点或数字。

命令行可以调整页面及笔刷参数：

```bash
.venv/bin/inkstruct document preview /path/to/source.txt \
  --run /path/to/generated-run

.venv/bin/inkstruct document render /path/to/source.txt \
  --run /path/to/generated-run \
  --output /path/to/new-page-output \
  --page-width 210 --page-height 297 --margin 20 \
  --em 6 --line-height 9 --stroke-width 0.3 --dpi 144
```

输出目录必须尚不存在。结果包括 `page-001.svg`、`page-001.png` 等页面文件和 `layout.json`。`--no-png` 只导出矢量页及布局报告。遇到正文问题时，默认不创建输出目录；`--debug` 可生成带水印的 `debug-page-*.svg/png`，退出状态仍为 2，不能当作成品成功。

CLI 的 `--metrics /path/to/metrics.json` 可以提供非汉字轨迹的外部度量。例如已有拉丁 `a` 的真实资产时，校准文件结构为：

```json
{
  "schema_version": "inkstruct_glyph_metrics_v1",
  "characters": {
    "a": {"advance": 0.6, "baseline": 0.88, "ascent": 0.88, "descent": 0.12}
  }
}
```

数值以资产 em 为单位，必须根据真实资产校准；示例数值不是字体测量结果。该文件只定义度量，不提供字形。桌面快捷入口目前没有外部校准选择器。

## 规则与边界

- 当前输入模式明确为纯文本，Markdown 定界符不会被解释。每个 CR、LF 或 CRLF 是一个硬换行，末尾换行保留额外空行。
- 空格与 NBSP 占半 em，全角空格占一个 em，Tab 暂为固定两个 em，不是制表位。行末空白保留逻辑宽度和源映射，不自动删除。NBSP 两侧不可断。
- 中文禁则覆盖实现中明确列出的开启、闭合及句读标点。长词或受禁则约束的超宽组合不强行拆开或缩小，而是保留并诊断。没有两端对齐、中文标点压缩、孤行寡行控制或断词连字符。
- 复杂连写脚本、RTL、组合字形和 emoji 未提供排版/字形后端，保留原内容并阻止成品导出。保守集群不是完整字素算法。
- ID 在同一个不可变 Document 内保持一致；重新读取文本会建立新 Document，尚无跨编辑、跨会话身份持久化。
- 任务键覆盖当前全部权威输入、身份、页面、样式、资产/校准、解析与布局版本及 request ID。尚无异步编辑发布协调器，未来加入字体、数学、覆盖或变体时必须扩展任务键。
- Qt 仅显示当前一页，并至多显示前 100 项诊断，完整诊断保存在调试导出中。没有页面拖拽、源码反向选择或输入法编辑面板。
- 原型 CLI/桌面入口限制正文 2 MiB/十万 scalar；每个资产最多 16 MiB；PNG 每页最多四千万像素。尚未完成复杂文档、总资源预算和跨平台性能验收。
- 页面导出采用同目录暂存后发布新目录；这不能代替计划中的文档包原子保存、外部修改检测、掉电持久性及自动恢复。

## 本次验证

本地环境：Python 3.13.8、Unicode 数据 15.1.0、Qt/PySide6 6.9.2。测试结果以本次运行记录为准，不沿用提案历史数字。

- 新增核心与可选 Qt 测试覆盖保真适配、源映射、Unicode 边界、换行分页、禁则、超大内容前进、导出门槛、任务键失效、失败导出及纸张背景。
- 完整测试：**192 passed，4 skipped**。4 项因本地未安装 PyTorch 而跳过，不计作通过。
- `ruff check src tests scripts packaging` 和 `git diff --check` 通过。
- 使用本地已有“侈、徼、劓、岛”四个真实资产构建 612 个 occurrence 的两页样例，诊断为空，原资产不变。两页 PNG 和 Qt 页面窗口已检查；这只是排版保真验证，不是字形自然度结论。
- Qt 预览、SVG 渲染及原生成器窗口均完成离屏启动检查。真实 macOS/Windows 输入法、交互编辑和压力渲染没有在本阶段验收。

本地样例位于 Git 忽略的 `artifacts/document_preview_20261009/verified-pages/`；样例源码为同目录上一级的 `source.txt`，窗口截图为 `verified-preview.png`。这些含本地用户轨迹的产物不纳入源码提交。

## 后续验收顺序

1. 固定 Unicode 分段/断行依赖及官方测试数据；补充当前子集规则和混排资产校准，再决定 P1 完整验收。
2. P2 前先实现源码补丁事务、ID 与覆盖迁移、单调 revision、undo/redo、IME preedit/commit 试验，以及完整任务键发布检查。
3. 实现 `.inkdoc` 的版本、哈希、资源预算、路径验证、冲突检测、原子保存与恢复，不把输出快照升级冒充文档包。
4. 以固定版本、离线资源和金样执行 MathJax SVG 试验，再实现受控 Markdown 源映射、数学盒子和简单表格。Qt 原生可以消费 SVG 并不能保证任意 MathJax 输出都兼容。
5. 最后逐项开放自然变体、手写数学、复杂表格和自由页面，并在参考机上测量性能。

本次外部机制核对仅用于确定试验边界：[Qt QTextBoundaryFinder](https://doc.qt.io/qt-6/qtextboundaryfinder.html) 区分 grapheme 与 line 边界；[MathJax SVG 输出设置](https://docs.mathjax.org/en/v4.0/options/output/svg.html) 允许表达式内的 local 字体路径缓存。上述文档不作为本项目已集成或完整兼容这些能力的证据。
