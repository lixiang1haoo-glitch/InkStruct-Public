# 排版问题面板（主应用 0.1.43）

已合入主应用 0.1.43。范围为排版页的问题提示，导入、保存等全应用错误弹窗不在本次重设计范围。独立预览旧 ZIP 和历史记录保留，本次验收见 [Windows 合并交付记录](RELEASE_0_1_43_WINDOWS.md)。

点击“查看问题”打开侧栏。顶部展示需处理/提醒数量与常规 SVG 状态；列表按原因归并，相同缺字只列一组，仍可逐处定位。公式语法错误产生的附带“不支持内容”占位提示归入同一原因，原始诊断全部保留。

- 可筛选“需处理/提醒”并搜索字符、说明或错误代码。
- 选中问题后查看中文原因和建议；“上一处/下一处”循环浏览该组来源，“定位到源码”选中对应内容并联动预览。
- 缺字显示字体设置入口；带有模板目标的问题显示模板修正入口；没有源码的模板问题不会跳到虚假的正文开头。
- 原始代码和消息折叠在“技术详情”；可复制完整问题报告，交给 AI 连同 Markdown 修正。
- 文档或设置正在重排时标记上次结果并禁用过期定位；新的检查结果会替换旧列表，修复后清除相应问题。
- 正文流停止时明确提示后续内容尚未排版。常规 SVG 的严格检查保持；强制 SVG 仍从导出下拉菜单进入，保留已有笔迹，缺失留空并附问题清单。
