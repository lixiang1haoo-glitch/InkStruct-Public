## 用户可见变化

- 保留“汉字样本 / 标点与扩展”两个采集标签，不设置字符快捷预设。两页共用书写者登记，启动不自动打开旧任务、不预填 user_001。新建填写中文显示名称，内部身份为 `w_` 加完整 UUID；同名可存在，短身份码辅助区分。
- 旧任务和样本中的 user_001、user_002 等 ID 原样发现，不自动改名或重建。修改显示名称只改管理登记；选择作者会带入另一空闲采集页，并在生成页空闲时同步内部 ID。生成页仍使用现有 ID 字段，跨工作区作者合并未在本轮实现。
- 汉字导入先集中确认作者、名称、CSV 份数、字符清单和保存目录。CSV 明确份数保留，空值默认五份；同字符同份数重复行明确列出并合并，份数冲突、超限或非法字表阻止创建。默认值可设 1–100；单任务上限 50,000 份，字表文件上限 2 MB。汉字任务按字表份数执行，不隐式抵扣其他任务。
- 扩展任务沿用逐字选择正斜体、自由组合类别、补差额及明确复用规则，创建窗口接入同一作者选择，并可直接新建作者。
- 零样本且没有历史采样/复用关系的任务可确认更换作者。已有样本不直接改归属，可暂停关闭后另建，或把未录部分复制给另一个作者。复制生成新任务与份次身份，不改变原任务；符号复用确认不跨作者继承。
- “暂停并关闭”解除当前任务；“取消任务”停止剩余采集、保留全部已保存样本和进度；在任务列表可恢复。归档也是独立管理状态，不删除文件。
- 统一任务列表展示汉字、扩展、已完成、已取消、已归档及损坏记录，可搜索任务、作者、类别、状态和 ID，支持打开、恢复、取消、归档、修改任务名称及复制未录部分。损坏记录显示原路径和错误，不悄悄消失。归档目前在统一列表保留显示，可通过搜索筛选。
- 两类采集均可查看已保存笔迹，选择单份或同字符/写法多份重录。重录会保存带哈希的旧样本备份并退回待录；汉字的旧 NPY/TXT 活动导出副本也一起退役，失败可以恢复。已生成结果、字体与冻结文档不自动更新。
- 未保存笔迹统一提供保存并继续、放弃当前笔迹、返回采集；笔画数、边缘和正斜体等校验保留。正在落笔时禁止切换/保存，重复保存有重入保护。

## 数据与维护模型

采集目录新增独立的 `capture-management.json`，使用 `inkstruct_capture_management_v1`：保存显示名称及任务管理状态，不把新字段塞入旧 `handwriting_task_v1`。旧任务只在用户明确保存样本、改名、零样本更换作者等操作时更新。启动和枚举不迁移旧任务。

汉字与扩展通过共享生命周期适配层统一保护、固定数据根目录、保存及任务列表。任务文件保存前比较磁盘哈希，在任务锁下写入；外部更新会阻止过期写入并保留当前笔迹。打开/对账也使用任务锁。显示查找可能只改变内存游标，重录比较保留全部样本、状态和身份检查，忽略这种纯游标差异；GUI 仍额外检查完整文件哈希。

复制任务旁写入 `copy-origin.json`（`inkstruct_capture_task_copy_v1`），保留原任务 ID、源状态哈希和源份次 ID。汉字重录使用 `inkstruct_capture_revision_v1`，包含 JSON 及 NPY/TXT 导出副本的哈希与备份位置；旧符号重录记录继续读取。

Windows 文件发布使用扩展路径。当前仍对正常采集目录进行可读路径预算检查，目录过深时在创建/保存前提示改选较短路径，避免写出其他读取环节无法访问的样本；不声称支持任意深度目录。切换采集目录先保护笔迹并关闭原任务，不把原任务写入新目录。独立新工作区不再继承另一工作区的采集路径。
