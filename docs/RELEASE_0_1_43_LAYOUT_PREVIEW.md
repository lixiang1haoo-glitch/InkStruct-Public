## 运行与数据隔离

完整解压到新的可写短路径，保留 `_internal`，双击 `InkStruct.exe`。`InkStructTool.exe` 是同版本控制台及预览/导出辅助程序。包内包含运行时，无需另装 Python；不要只移动 EXE。

窗口标题含 `Layout Preview`，默认工作区/设置在包目录下 `preview-data`，与常用应用分开。未附用户历史字体、采集样本、工作区或开发缓存；需要时导入副本。

## 本次新增与修复

- **两端对齐**：设置 → 正文与段落 → 正文对齐。自动折行余量分配到合法间隙，段尾和手动换行靠左；公式、英文单词内部不拉伸。
- **中文微扰（实验性）**：同页可启用并设置强度/种子，默认关闭。每个普通汉字实例获得可复现的小幅变化；不改字体包、采集样本、字距、笔宽或冻结选样，随项目保存。
- **强制导出 SVG**：排版页打开“导出 SVG…”旁的下拉菜单，选择“强制导出 SVG…”，选择页码/比例等选项后指定新目录。仅导出当前已排出的有效笔迹，缺字和错误占位留空；不改变原文档，也不自动补排未排出的内容。
- **设置保留当前模板**：应用正文、公式等默认参数或右侧“应用全局默认”时，保留本文模板、纸张及旧模板绑定。仅在设置中明确改动对应纸张/模板并勾选应用到本文时，才应用该项变化；只浏览纸张设置不算替换。

统一设置的“同时将默认排版参数应用到当前文档”仍需明确勾选；未勾选时只更新新文档默认。本文模板也可继续通过右侧文档资源明确替换。

## 强制导出的输出范围

常规写字机 SVG 导出继续严格检查完整性。强制导出是显式的部分内容出口，使用同一份冻结几何：

- 保留有效黑色中心线路径、表格线及已载入的合法单线 SVG，保留原坐标和纸张尺寸（用户选定的导出比例除外）。
- 不输出错误占位框、位图或缺失图片。合法图题仍保留。
- 无效/单点/零长度路径及越出物理纸张的笔画跳过；内容区溢出但仍在纸内的有效笔画可保留。路径不裁切、不缩字以掩盖错误。
- 同时生成 `issues.txt`、`issues.json` 和 `plotter.json`，列出源文档诊断、跳过的笔画/图片及所选页码；报告明确标记强制、非完整文档出口。
- 已有输出目录不覆盖；取消或失败不发布半成品目录。页码、表内内容筛选、导出缩放及后台路径优化仍可使用。

强制导出不能恢复未生成的笔迹，也不绕过坐标有效性、资源预算或画布尺寸限制。SVG 文件保持 path/M/L 中心线格式，无系统字体缺字回退。
