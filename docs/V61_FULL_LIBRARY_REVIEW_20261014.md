## 运行与交付

```bash
MPLCONFIGDIR=/private/tmp/inkstruct-mpl .venv/bin/python scripts/generate_v61_library.py \
  --output artifacts/v61_full_library_20261014/run_v1
.venv/bin/python scripts/verify_v61_library.py artifacts/v61_full_library_20261014/run_v1
```

新批次必须使用独立目录。`--resume` 只允许同一输入和代码哈希下恢复，并核对已完成产物哈希；已有失败记录也保留，不自动以另一条生成路径顶替。

私有交付入口为 `artifacts/v61_full_library_20261014/run_v1/index.html`，无需网络或外部资源，可直接本地浏览；支持汉字搜索、四作者并排、来源覆盖筛选、分页、局部 SVG 放大、备注及问题清单导出。未使用浏览器原生弹窗，兼容内嵌浏览器。

每字记录包括标准 ID 与笔顺检查、坐标/压力/时间检查、退化、来源逐点保真、相对旧 v6 新增的跨部件严格交叉及 0.028 笔宽接触。检查通过只表明满足这些有限条件，不代表作者风格、所有自交、原有布局问题或任意笔宽均无缺陷。用户认可的作者内部自然交叉继续保留。

输入与生成时的代码哈希见 `protocol.json`，逐字来源/变换/拒绝原因见同名 JSON.gz，文件哈希及检查见同名 JSON，最终逐份存储校验见 `verification.json`。所有个人数据、图册与问题备注位于 Git 忽略目录；仅提交运行器、图册工具、验收测试和本文。
