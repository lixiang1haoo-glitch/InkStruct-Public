# InkStruct 0.1.59 · Windows

2026-11-08。基于 0.1.58，更新采集、生成和制作字体包之间的交接。解压 [InkStruct-0.1.59-Windows-x64.zip](../artifacts/handoff_0.1.59_20261108/release/InkStruct-0.1.59-Windows-x64.zip)，保留完整的 `InkStruct` 目录，运行 `InkStruct.exe`。

- 生成页显示当前书写者、自动或手选来源、实际样本目录、上次导入时间、导入份数和所选方法的有效供体份数。后台按作者和目录核对样本身份、路径与内容。使用「更新样本并建档」同时切换索引和档案，两步都成功后才生效。
- 制作字体包显示批次时间、方法、完成与目标字数和状态。部分批次可选用已完成范围。勾选后重新计算独立录制、共用、确认复用与合成的覆盖，可展开缺字和来源诊断。确认复用可依照任务绑定读取未勾选入包的原样本，规则合成则取自当前候选池。输入变化后须重新核对。
- 制包依次经过准备字形、封装、完整验证和入库。暂存包在字体库列表之外，完整验证通过后以无覆盖的原子操作入库。成功后选中新包并报告实际覆盖和差异。

## Windows 实窗

使用 Windows Qt 窗口和真实采集样本副本，验收工作区单独保存。

1. `user_001` 补录并移动样本后出现待更新提示。注入建档失败，当前索引和档案仍可读取。重试后导入份数从 39 增至 40，有效供体从 31 增至 32。旧批次仍读取原档案。
2. 切换到 `scx` 时自动目录随之切换。手选 `user_001` 外部目录时界面拦截作者错配，切回对应作者后继续使用手选目录。
3. 取消 12 字的 v6.2 批次，保留「中国」2 字。从生成页带入该批次，再从字体库选择同一部分批次，成功发布时只纳入这两个生成汉字。
4. 从真实正体样本确认复用希腊字母 Α。取消英文正体后，℃ 缺少合成来源，明确确认的 Α 复用继续有效。修改复用配置文件后，旧清单失效。最终入包 184 字、939 份候选，与当时的勾选清单一致。
5. 注入最终验证失败和原子入库失败，两次均只看到原有同名字体。重试成功后出现并选中新包。核对旧字体、原始样本和既有文档的哈希，并复查文档内嵌模板、资源池及 5,129 条冻结选样。
