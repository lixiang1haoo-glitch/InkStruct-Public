# user_001 部件级补采任务

本任务只关注几何字形，不训练压力、速度、时间或连笔。

## 任务规模

- 已有：68份样本，54个唯一字符。
- 新字符：60个，每字采集1遍。
- 稳定性锚点：20个；其中17字补2遍、3字补1遍，使其达到每字3份样本。
- 本轮总书写次数：97次。
- 完成后预计：114个唯一字符、165份样本。

## 新字符

```text
满茶休金信我哭花森林班目田在鸡鸭石池雪雷明阴队朋阳易回困四晚和利秋初补被别品话轮转总亮高火问间闪同言船香名狂猪狗兄只条果
```

这些字符用于补齐氵、艹、亻、木、口、犬、鸟、雨、日、月、阝、囗、衣、言、车、火、门等常用部件在不同位置和整字结构中的实例。

## 稳定性锚点

```text
谷鸣认轻唤珠挂星映柳拂河晨地中讥大夜露微
```

锚点重复次数已经写入 CSV，不需要在采集器中统一设置为3遍。CSV中的 `repeats` 表示本轮还要补写的次数。

## 文件

- `artifacts/collection/user_001/component_collection.csv`：直接导入单字采集器，包含60个新字和20个锚点。
- `artifacts/collection/user_001/component_characters.txt`：只含60个新字，适合快速查看。
- `artifacts/collection/user_001/recommendations.json`：完整评分、部件、结构、推荐原因及覆盖率变化。

## 采集步骤

1. 双击 `run_inkstruct_collector.cmd`，或运行 `.\.venv\Scripts\inkstruct.exe collector`。
2. 在“单字任务采集”中导入 `component_collection.csv`。
3. 用户保持自然楷书或行楷书写，但不要主动连写或省笔。
4. 采集器实时显示“当前笔数/标准笔数”，不一致时不能保存；无需刻意模仿标准字体的比例。
5. 完成后重新运行样本导入和建档。

```powershell
.\.venv\Scripts\inkstruct.exe samples import "<包含旧样本和本轮新样本的目录>" --writer user_001
.\.venv\Scripts\inkstruct.exe profile build --writer user_001
```

不要只导入新样本目录后覆盖当前索引；导入目录应同时包含旧样本和本轮新增样本，或者先将两者组织到同一个只读来源根目录。

## 覆盖变化

推荐器的目标不是尽可能增加不同部件，而是让常用部件在不同字符中形成可统计的重复实例。预计完成后：

- 达到3实例的部件身份：7种提升至31种；
- 达到3实例的部件位置上下文：3种提升至31种；
- 达到2实例的部件变体：2种提升至8种；
- 预计唯一字符数：54提升至114。

这是第一轮部件级补采。完成后应根据实际对齐质量重新运行推荐器，而不是直接追加另一份固定字表。
