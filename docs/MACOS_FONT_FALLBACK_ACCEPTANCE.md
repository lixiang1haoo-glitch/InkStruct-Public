# macOS 界面字体回退验证

2026-10-14。对应 M6-01 的部分验收，未修改产品代码或系统字体。Windows 实机结果及英文、希腊手写样本仍未就绪，用户已再次确认。

## 操作与结果

使用当前源码运行实际 Cocoa 窗口，Fusion 样式、1000 × 700 窗口，载入固定四页综合项目。给应用和源码编辑器指定经字体库查询确认不存在的字体名称，验证 Qt 使用现有字体回退。测试结束关闭临时窗口；恢复写入已禁用，原项目未保存或修改。

- macOS 27.0.1 arm64，Qt 6.9.2，当前屏幕 DPR 2，逻辑 DPI 72。
- 编辑器字体解析到 `.AppleSystemUIFont`；包含中文、数字、英文、希腊字符和数学符号的独立文字整形检查使用 `.AppleSystemUIFont` 与 `PingFang SC`，所有字形编号非零。
- 回退前后同一个排版快照、修订号、源码和选样记录保持不变。四页未优化机器 SVG 的 SHA-256 全部一致。
- 已人工查看回退后的窗口抓图：中文控件和源码正常显示，预览仍为手写轨迹，1000 × 700 窗口中的控件可见。
- Qt 输出一次字体别名解析耗时 130 ms 的提示；这是首次请求不存在字体的初始化观测，不是持续输入延迟或翻页性能测量。

## 证据与复现

证据目录：`artifacts/font_fallback_20261014/`。`probe.py` 为此次本机验证脚本，`verification.json` 包含输入/源码哈希、实际字体、屏幕参数及各页 SVG 哈希，`before.png`、`after.png` 为 QWidget 抓图。

```sh
.venv/bin/python artifacts/font_fallback_20261014/probe.py
```

需在有窗口服务访问权限的 macOS 桌面运行；脚本断言 Qt 平台为 Cocoa。复现会覆盖该证据目录的 JSON 和截图，应先复制脚本到新证据目录。私有固定项目需已存在，不属于干净克隆中必然具备的输入。

## 适用边界

这是应用请求不存在字体时，使用本机现有字体的回退验证，没有卸载字体，也没有模拟所有系统字体均缺失。文字整形中的英文、希腊字符只用于界面字体检查，不能充当用户手写样本或证明相应手写公式已验收。机器出口继续只使用轨迹资源，不允许系统字体掩盖缺少手写字形。

本次使用源码运行环境，未重新构建独立应用。DPR 2 是当前屏幕环境记录；未改变操作系统缩放、跨屏移动或验证原生输入法组合输入。抓图不是操作系统合成器呈现计时，Windows 和写字机纸面测试继续待办。
