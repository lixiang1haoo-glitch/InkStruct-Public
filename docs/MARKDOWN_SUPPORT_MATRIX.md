# Markdown 混排支持矩阵

核对日期：2026-10-14。本表面向当前工作区实现，不代表已发布安装包或完整 TeX/Obsidian 支持。所有“可写字机导出”均以字形资源齐全、尺寸校验通过且无错误诊断为前提；实际机器效果另需纸面验收。

## 资源与默认值

新表默认总宽 160 mm、最小行高 8 mm、数字高度 3.8 mm、四边留白各 0.3 mm。公式字号独立，默认 6 mm。路径优化默认关闭；开启即允许反转，原始轨迹不改写。

内置单线资源仅数字和小数点。新同步 user_001 包含 80 字符、405 份录制符号，其他各 5 份、小数点 10 份；英文和希腊未同步。采集 guides 已用于 em/baseline/math-axis，人工轴校准尚未完成。CLI `document resources` 已支持原生项目的方言/来源/选样，并检查录制根号、减号分数线、伸缩及编号括号的需求，生成各 5 次采集 CSV。该检查只证明资源存在，几何和就绪状态仍由实际布局判断，见 [资源检查](RESOURCE_INSPECTION.md)。

## 验证状态

M5-04 的四类扩展及组合验收见 [M5 验收单](MARKDOWN_M5_ACCEPTANCE.md)。功能测试、真实样本与严格导出已具备；Windows 输入法/缩放/文件对话框、完整离线安装包及写字机试写尚无完成证据。macOS 已新增从固定 wheelhouse 到全新虚拟环境的离线安装和已安装包验证，见 [离线材料](EDITOR_OFFLINE_KIT.md)；仍需预装 Python，Windows 仅做材料校验与离线依赖解析。不能将 macOS 离屏结果称为原生交互全部通过。性能记录限已固定负载和版本，见 [性能记录](MARKDOWN_PERFORMANCE.md)。

旧独立文本检查和数字表格入口继续保留：它们承担既有项目、评价流程和旧排版复现，暂不合并或删除。统一 Markdown 编辑器是混排主入口。启动、复现和下一步见 [交接说明](MARKDOWN_DELIVERY_HANDOFF.md)。

macOS 界面请求不存在字体的回退验证已通过，四页手写机器 SVG 不受影响，见 [字体回退验收](MACOS_FONT_FALLBACK_ACCEPTANCE.md)。这不替代英文/希腊手写资源，也不代表 Windows、系统缩放切换或原生输入法已通过。

macOS 系统拼音的原生组合、取消、提交和键盘撤销/重做已完成一次短文档闭环，字符身份及恢复后的机器 SVG 不变，见 [原生输入法验收](MACOS_NATIVE_IME_ACCEPTANCE.md)。其他输入法/复杂编辑情形、系统缩放切换和 Windows 仍待验证。
