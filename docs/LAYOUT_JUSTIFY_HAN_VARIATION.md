## 新版自然书写

入口：设置 → 正文与段落 → 自然书写（中文 · 实验性）。默认关闭，种子范围仍为 0–2147483647。四项可单独调节：

| 选项 | 默认强度 | 作用 |
| --- | --- | --- |
| 笔画与倾斜变化 | 55% | 连贯的局部形变、笔画弯曲与整体倾斜；提高强度后变化明显增大 |
| 字形大小变化 | 30% | 每个汉字的宽高作小幅变化 |
| 字距变化 | 35% | 相邻普通汉字的间距变化，在断行前参与测量；与两端对齐共存 |
| 基线上下变化 | 20% | 每个汉字有独立的上下偏移，并预留测量空间 |

百分比表示各分量的算法强度，100% 不代表把字放大一倍。四项为零时保持原有几何。启用后可能重新断行、分页；字形运动限制在已测量的空间内，保留最小笔迹间距和笔宽。公式、代码与西文词内几何不施加这些中文变化。

固定种子与同一来源实例可重复得到相同轨迹。字体包、样本、压力/时间、笔画顺序和冻结选样不改写；变化只保存在项目的排版设置中。

旧 `inkstruct_han_variation_v1` 项目保持旧效果。设置中点击“使用新版自然书写”，或改动任一自然书写选项，即可选择 v2；勾选底部应用到当前文档后生效。仅调整其他正文参数不会偷偷切换算法。

项目仍使用 flow style v5，内部自然书写记录为 `inkstruct_han_variation_v2`，包含三个新增分量。旧 v1 记录另存仍保持旧字段格式。旧独立 0.1.43 Layout Preview ZIP 及更早应用不认识 v2；v2 项目应使用本次主应用包打开。

## 正文两端对齐

在 Markdown 混排模式下，于“设置 → 正文与段落 → 正文对齐”选择“两端对齐（段尾靠左）”。自动折行时，将剩余宽度平均加到合法间隙中；行内公式被移到下一行时，上一行也会这样处理。

- 汉字间隙、已有词间空格、文字与行内公式边界可以扩展；英文单词、行内代码及公式内部不拆开或拉宽。
- 段落最后一行和 `\newline`、`\linebreak` 等显式换行保持原间距；标题、代码块及表格独立对齐不强制改成正文对齐。
- 计算使用实际页面/当前正文框宽度，并保留首行缩进、列表、引用和分页边界。
- 没有合法间隙（如单个不可分英文单词）的行保留左对齐，不缩放字形。

新文档默认使用两端对齐；旧 `.inkdoc` 缺少新设置时继续左对齐。旧的全局默认可在内存中升级新文档默认，不直接改写设置文件；明确保存过左对齐后，重启仍保留该选择。

统一设置沿用既有工作流：只保存全局默认不会改变当前文稿；要让已有文稿采用新设置，勾选底部“同时将默认排版参数应用到当前文档”。

## 中文微扰（实验性）

同页提供“启用中文微扰（实验性）”、强度和随机种子。默认关闭；默认强度 35%，种子 0，可设 0–2147483647。强度指实验算法的作用比例，不是把字形缩放到该百分比；即使 100% 也限制为小幅变化。

每个汉字实例根据“项目中稳定的文字身份 + 种子”确定轻微倾斜、收缩和平滑形变；同一汉字重复出现时可有不同轨迹。同一项目、文字实例、种子和强度会得到相同结果，重排、保存重开、缓存命中或撤销不会重新抽取随机数。改变种子才会系统地更换形变。

微扰在排版轨迹上执行，保留字距、行距、逻辑位置、笔宽、笔画数量及点序，并把新轨迹限制在原笔迹中心线边界以内。原字体包、采集样本、来源、压力/时间记录和冻结选样不改写。微扰不是新的采集样本，也不会写回字体。关闭或将强度设为 0 后恢复不含微扰的排版；既有人工字符校正仍保留。

适用于 Markdown 混排的普通文字汉字（纯文本检查仍沿用原逻辑），包括表格、脚注和固定字段里的普通文字；西文、标点、数学内部汉字和代码不施加微扰。重复的同一个来源实例（例如重复表头或同一固定字段跨页重现）保持同一种微扰，避免重复内容漂移。字符校正预览以微扰后的字形为基准，与应用后、页面预览和写字机 SVG 共用几何。

## 项目与兼容

新功能使用文档样式 `inkstruct_flow_style_v5`，独立保存 `paragraph_align` 和 `han_variation`（开关、强度、种子、算法版本）。继续读取 v1–v4，旧样式没有新参数时默认左对齐、微扰关闭；保存未启用新设置的旧样式时不夹带新字段。使用新设置的项目需要当前支持 v5 的源码打开；这不更改字体格式、模板格式或 Python 库版本。

AI 仍按 Markdown 规范生成内容；这两项是排版设置，不是新的 Markdown 命令。不要为了微扰替换异体字、插入随机空格或改写正文。可向用户另行建议种子/强度，但不要将这些建议作为伪命令放进文档。
