# InkStruct 0.1.63 · Windows

2026-11-08。完整解压 `InkStruct-0.1.63-Windows-x64.zip` 后运行 `InkStruct.exe`。

- 生成页「作者」使用可编辑下拉框，从当前采集目录加载作者。选择时显示名称，建档与生成仍使用原作者 ID。外部来源可以填写已有 ID，样本归属仍会核对。
- 「同形共用」分为全角与半角、英文正体与斜体、拉丁正体与希腊大写三组。可整组启停，也可逐字覆盖。全半角默认开启，后两组默认关闭自动补缺，已有单项供体仍可沿用。整组操作会更新组内开关，保留已指定的供体关系。
- 同形规则只补缺录。启用后可自动使用同作者的有效供体。有效独立录制优先，其次是本次或采集任务中指定的供体。指定供体失效时会提示重新选择。英文笔迹保持原样，希腊目标保留独立编码和现有白名单。需要指定某一份时才打开预览。清单与实际制包使用同一规则设置。
