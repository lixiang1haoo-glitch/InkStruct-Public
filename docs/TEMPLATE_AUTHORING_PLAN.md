# 通用书写模板设计方案

2026-10-19：新模型已在 0.1.21 实现为模板 v3，见 [最终协议与使用](TEMPLATE_SINGLE_FLOW.md)。以下记录 v1/v2 的设计与历史阶段，不能代替新的 Windows 验收；新项目使用一个连续正文流及显式命名字段，旧项目继续按原版读取。

2026-10-13 建立，2026-10-14 更新。目标是让用户和 Agent 创建、修改、复用排版方式。华科物理实验报告 PDF 是验证材料；它的栏位名称、坐标和页数不能成为程序的固定逻辑，也不要求先补齐这份表单才算产品完成。本方案修正原计划中“继续完成华科其余栏位”的方向。

## 一、产品模型：模板、内容、绑定分开

模板回答“哪里可以写、如何流动、哪些线需要画”；Markdown 回答“写什么”；绑定回答“这份文档的哪段内容进入哪个区域”。改变纸张布局无需改写正文，替换报告内容也无需复制一份模板程序。

| 层 | 职责 | 当前状态 |
| --- | --- | --- |
| 可复用模板 | 纸张尺寸、首页/续页、正文区、固定区、锚点、框线、参考底图 | 已有 `inkstruct_page_template_v1`，本轮补编辑入口 |
| 文档内容 | 原始 Markdown、源节点身份、字形资源与选样 | 已有；仍是正文权威来源 |
| 文档绑定 | 源节点 ID → 区域 ID、首页/所有页、倍率、基线锚点 | 已有 `inkstruct_template_binding_v1`，保存在项目内 |
| 排版样式 | 正文字号、表格、数学、代码、脚注等参数 | 已有 FlowStyle；模板不私自改写全局样式 |
| 输出与校准 | 预印纸/空白纸、整体偏移、机器路径 | 已有；校准与实际内容适配分别检查 |

模板 JSON 不含用户姓名、实验内容或生成的最终字符坐标。最终坐标由排版器生成。模板可以嵌入参考 PNG，但底图永远不转换为写字机轨迹。Agent 使用同一份声明式 JSON，无需生成或执行 Python/JavaScript 布局脚本。

## 二、设计界面与使用过程

入口为混排编辑器的“页面模板…”→“新建 / 设计模板…”。模板编辑与报告编辑是两个工作状态：设计模板时突出区域、坐标、约束；使用模板时突出源码、实际书写预览和诊断。

1. 新建纸张，或导入已有模板。无特定学校默认值；首版起点为普通 A4。
2. 分别设计首页和续页：放置正文流区域、固定填写区、基线锚点和折线框线。全部使用纸张左上角为原点的毫米坐标。
3. 检查几何预览及校验信息；保存可复用 JSON。该预览只展示布局结构，不代表文字已经放得下。
4. 回到“页面模板…”将完整 Markdown 块绑定到固定区。未绑定块继续进入正文流；删除绑定后恢复到正文，不能静默丢弃文字。
5. 用实际字形生成分页预览，检查溢出、缺字和分页，再保存 `.inkdoc` 或导出机器 SVG。

### 本轮第一版已实现

- 纸张属性与首页/续页切换；正文区、填写区、锚点、任意折线框线的毫米数值编辑。
- 新增/删除固定元素；正文宽度同步按钮；内置重叠、边界、尺寸与版本校验。
- 同步几何预览、JSON 编辑、导入/导出及草稿撤销/重做。属性先点击“写入”，未写入时禁止切换与确认，避免接受旧值。
- 非法几何保留为可修改草稿，隐藏旧预览并阻止确认；窗口取消不修改项目。合法模板应用后仍由正常文档构建检查内容适配。
- 保留 JSON 浮点精度、已有底图、校准偏移和未改的其他页面元素；通过属性修改布局会将校准状态恢复为 `unreviewed`。

现已接通基础画布交互，具体操作见下节。多选框选、对齐分布、标尺、视图缩放和底图透明度也已接通；PDF 页码选择与导入也已接通。内容诊断已可定位绑定与几何对象，常见几何草稿错误也可定位对象或 JSON；后续使用体验仍需完善，不能将当前版本称为完整模板设计器。

### 已实现的画布交互及后续项

- “选择 / 移动”：点击元素与属性表联动，拖动移动正文区、固定区、锚点或整条折线。区域四角有缩放手柄，选中的折线各顶点可独立移动。
- “绘制填写区”与“绘制直线”：从起点拖到终点创建；“放置锚点”点击即可。创建后回到选择工具，区域名称可在属性表修改。
- 吸附间距可设 0.1–20 mm，默认 1 mm；可关闭吸附或按住 Alt 临时关闭。网格可关闭；线距自适应显示为至少 5 mm，避免低倍率预览过密，吸附仍按设置的毫米步长进行。
- 拖动候选与原布局同时显示。每次松开只产生一个撤销事务，Esc 取消本次操作；重叠、越界、非法尺寸或不符合页型约束时不接受拖动，原 JSON 保持不变。
- “联动首页 / 续页正文宽度”默认开启，仅联动宽度，不移动另一页正文或改变其高度；关闭后违反 v1 等宽要求的缩放会被拒绝。数字属性编辑仍可暂存非法草稿，供协调修改。
- 导入/移除当前页 PNG/JPEG 底图，作为可撤销修改。导入前明确纸张尺寸；底图按整张纸铺满，仅供参考。原图只读，转换副本保存在模板内；底图不随内容校准偏移移动。更换底图会清空旧的整体来源哈希并保留新 PNG 哈希、将校准恢复为待审，避免将新参考图误称为原 PDF。

画布、数值属性、JSON 共用一个模板模型和校验出口。单位转换包含页面居中留白与校准偏移，不根据屏幕像素假设实际纸张大小。鼠标操作不能改变正文、选样、既有元素名称或固定区绑定；新增固定区仍需回到外层显式绑定内容。

PDF 页码选择与尺寸导入见下节，内容诊断已接通字段/区域/页型定位，几何草稿也已支持重叠、越界、重名、页型约束和 JSON 定位。导入扫描材料不会自动认定所有填写区域。

### PDF 页码与物理尺寸导入

“导入当前页底图…”可以选择 PDF。向导显示页数、从 1 开始的页码、所选页预览，以及 PDF 本页和当前模板的毫米尺寸。PDF 的页面旋转会反映在预览和尺寸中。选择的是导入到当前“首页”或“续页”的哪一张 PDF 页面，不会把整份 PDF 自动转换为多种模板页型。

两种导入方式有明确区别：

- **仅替换当前页底图，保留纸张与布局**：默认方式，保留正文区、固定区、锚点、框线和校准偏移，只替换当前页型的底图。尺寸不一致时提示将按现有纸张铺满，可能改变参考图比例；需要原尺寸时可先调整模板，或选下一种方式。
- **按本页纸张尺寸新建布局**：使用 PDF 尺寸创建一个通用正文区，替换旧几何、两页底图及校准偏移。边距取 10 mm 和页面短边 10% 中较小值；没有任何学校专属栏位。操作可以在外层撤销，已有文档绑定保留原关系、需重新检查，不能把失效绑定当作已填写。

取消向导不改变模板。导入从只读字节快照渲染，不修改 PDF，不自动描摹框线、推断字段或提取文字作为正文。新参考页嵌入为受限 PNG，随 JSON / `.inkdoc` 保存；原 PDF 不打包。模板保留适用的整体 PDF 哈希和各 PNG 哈希，混合不同来源时清空不能代表所有页的整体哈希。v1 模板自身尚不保存 PDF 页码映射；CLI 返回的导入报告包含页码、页数、来源哈希和页面尺寸，可作为复现记录保留。

依赖桌面版已有的 PySide6 QtPdf，不新增 PDF 第三方包。首版限制 50 MiB、1–1000 页、单边不超过 10000 mm；参考渲染最长边不超过 1600 px，并按嵌入预算压缩。需要密码或特殊加密的 PDF 暂不支持。读取与渲染现位于独立子进程，GUI 在读取或换页时可取消；每次读取/渲染请求限时 30 秒，超时、崩溃或取消会终止并回收子进程。CLI 的一次完整导入同样限时 30 秒，失败不创建输出。向导等待期间清空旧候选并禁用确认，成功后才恢复；不使用线程放弃结果来假装停止渲染。Python 安装版使用模块工作进程，独立应用使用包内 InkStructTool，缺失配套程序会明确拒绝；本机验证不代表 M6 的 Windows/native 全项交互验收完成。

### 视图缩放、标尺和底图显示

视图可设为 50–600%，100% 表示适合当前窗口，不是屏幕上的实际打印比例。“适合窗口”恢复完整页面并清零滚动位置。Ctrl（macOS 也可用 ⌘）+ 滚轮以指针附近为中心缩放；放大后可用滚动条或中键拖动平移，Esc 撤销正在进行的中键平移。缩放或窗口尺寸改变会取消尚未提交的画布拖动，避免在新倍率下误用旧的拖动起点。

上下文中的毫米标尺使用真实纸张原点，跟随缩放和滚动；刻度密度自动调整，可以关闭。属性表坐标仍是校准前的布局坐标，纸面显示位置包含横纵校准偏移，因此两者可能相差已设置的偏移量。视图比例只影响屏幕显示，毫米坐标、吸附间距和输入字段不随放大改变。

底图显示可设为 0–100%，默认 40%。这是当前模板设计窗口的查看设置，不写入模板 JSON、不形成布局撤销记录、不改变原 PNG 或文档正式预览/机器导出。视图缩放、滚动位置、标尺开关同样不存入模板。设计模板的撤销/重做保持正在使用的视图倍率和底图显示比例。

### 多选与批量排列

Shift 点击可以加入或移出选区；“框选元素”可从任意位置拖框，也可以在选择工具下从纸面空白处开始框选。只选中完全包含的元素，反方向拖框同样有效，Shift 框选追加到原选区。空白点击清空选择，Esc 取消正在进行的框选。

点击已选元素并拖动可以整体移动选区。所有元素采用同一平移量，吸附以整个选区左上角为基准，不逐个吸附而改变相对位置。要使填写区与基线锚点/下划线一起移动，需同时选中它们；目前没有隐含分组关系。多选状态不提供整体缩放，单选仍可拖动四角或折线顶点。

提供左/右/顶/底对齐、水平/垂直居中，以及水平/垂直等距分布。对齐参考整个选区的包围范围；等距分布按位置排序、固定最前和最后的元素、均分中间净空。区域使用矩形边界，锚点使用定位点，折线使用中心线点集的包围范围。排列采用准确毫米值，不再次吸附到网格，以保持真正的居中或等间隔。

对齐至少选择两个元素，等距至少三个；空间不足、最终内容区重叠或超出纸面时整次拒绝。批量修改一次性校验最终布局，允许元素经过彼此的旧位置；一次撤销恢复所有改变。保持尺寸、名称、源码绑定、未选元素和另一页型不变。属性表只编辑最后选中的元素，工具提示明确区分属性编辑与批量排列。

选择区域后显示“区域 ID、显示名称、类型、位置、尺寸、内容策略”。语义字段 v2 已分离稳定字段 ID 与显示名称；几何对象的 `name` 仍兼作区域 ID。“页面模板…”已提供显式联动重命名，Agent 使用相同的 `template rename` 操作，同时更新首页/续页同名对象、字段声明和当前项目绑定，保留几何与绑定次序。直接修改属性或 JSON 不推断改名关系；模板另存也不会修改其他引用该模板的外部项目。见 [页面模板说明](PAGE_TEMPLATES.md)。

## 三、布局能力分层

首版保留已有可靠约束：每种页型一个正文流区域；首页与续页正文等宽；续页正文高度不少于首页；区域不可重叠；固定区不跨页，内容超出时报错。固定区可放完整段落、公式、表格等已支持块，内容按源顺序排版。倍率沿用既有样式规则，不能为了塞入框中自动压缩轨迹或截断内容。

以下能力按独立版本推进，不能直接往 v1 JSON 添加字段；当前 v2 已接通语义字段，其余仍属后续设计：

| 能力 | 建议契约 | 实施前验收重点 |
| --- | --- | --- |
| 多正文区域/多栏 | 区域稳定 ID、明确的流向链与下一页目标 | 无循环、不同栏宽重新度量、跨栏表格政策 |
| 可复用插槽（v2 已实现） | 模板声明稳定编号、显示名、类型和必填规则；文档提供 slot→节点映射 | 模板不含某份文档节点 ID；不同文档显式重绑；不做模糊自动匹配 |
| 固定区排版样式 | 内边距、水平/垂直对齐、显式样式覆盖 | 保留真实基线/数学轴；不按墨迹包围盒随意缩放 |
| 重复与条件页型 | 首页、续页、末页、奇偶页等确定规则 | 页数变化的重新求解和稳定性；不隐式执行表达式 |
| 页眉页脚/页码 | 区分重复源码与系统生成内容 | 身份、引用、脚注、页码和执行域一致 |
| 位置约束 | 毫米坐标和显式对齐/间距约束，求解后仍为毫米 | 不可解约束给出具体对象和原因 |
| 校准配置 | 模板设计几何与设备/纸张偏移分离 | 不把一台设备偏移当作通用模板坐标；旋转需单独实现 |

升级时使用新 schema 版本和明确迁移器；旧模板仍按旧规则读取，未知版本拒绝，不能读取后丢掉不认识的配置再保存。

## 四、Agent 接口

人和 Agent 的最小交换物是一份受校验的模板 JSON，运行时以 `document/template.py` 的数据模型与校验为准。当前命令如下：

```sh
.venv/bin/inkstruct document template new --output artifacts/my-template.json
.venv/bin/inkstruct document template validate artifacts/my-template.json
.venv/bin/inkstruct document template preview artifacts/my-template.json --output artifacts/my-template-preview
```

`new` 创建中性 A4 模板。Agent 编辑副本后运行 `validate`，通过后生成首页/续页的几何 SVG 供查看，再在编辑器导入并绑定内容。新建文件及预览目录必须不存在；命令不会覆盖已有产物。返回 JSON 明确区分 `valid`、`content_fit_checked` 与 `machine_export_ready`：几何校验通过时后两者仍为 false。预览 SVG 含矩形、文字等辅助元素，只作设计参考，不能作为机器导出。

Agent 可使用相同 PDF 导入逻辑（需要桌面额外依赖）：

```sh
.venv/bin/inkstruct document template from-pdf input.pdf --page 1 --output artifacts/pdf-template.json
.venv/bin/inkstruct document template from-pdf input.pdf --page 2 --face continuation --template artifacts/pdf-template.json --output artifacts/pdf-template-both.json
```

无 `--template` 时默认按 PDF 尺寸新建；提供模板时默认保留其纸张和布局，只替换目标页型底图。可用 `--layout new` 或 `--layout background` 显式指定。输出文件必须不存在，失败不会覆盖输入 PDF 或旧模板。选择 `--face continuation` 不表示 PDF 第 2 页，仍需显式指定 `--page`。几何校验通过仍不代表内容已绑定或具备机器导出条件。

已有实际内容验证入口保持兼容：

```sh
.venv/bin/inkstruct document render examples/template_authoring_demo.md --mode markdown --template configs/templates/generic-record-v1.json --output artifacts/generic-content-check
```

这个入口验证普通正文在模板中的布局。固定区绑定可通过 GUI、Python `TemplateBinding` 或下面的 Agent 命令配置，并随 `.inkdoc` 保存。模板 JSON 自身不包含某份文档的内容身份，仍须显式指定绑定。

`inspect-content / bind / validate-document` 已接通，使用现有区域 ID 和原生项目中的稳定节点 ID；返回源码范围、实际分页以及缺失、溢出等诊断。独立语义字段与 `inspect-slots` 已通过模板 v2 实现，详见 [可复用内容字段](TEMPLATE_SLOTS.md)。Agent 的标准过程应为“读取模板与源结构 → 修改副本 → 查看差异与预览 → 验证真实内容 → 保存项目”，无需改变原始 Markdown 来模拟位置。自动从 PDF 提取建议区域可作为后续辅助，结果仍进入同一编辑、校验流程。

### Agent 内容绑定与真实试排（2026-10-14）

```sh
.venv/bin/inkstruct document template inspect-content input.inkdoc
.venv/bin/inkstruct document template bind input.inkdoc --bindings bindings.json --output bound.inkdoc
.venv/bin/inkstruct document template validate-document bound.inkdoc
.venv/bin/inkstruct document render bound.inkdoc --plotter --optimize-paths --output machine-output
```

三个模板内容命令都可加 `--template layout.json` 显式选择另一模板；不加则使用项目内的模板。`inspect-content` 返回完整顶层块的 `node_id`、类型、原文和源码范围（Unicode 标量偏移，不是 UTF-8 字节偏移），现有绑定、两种页型的填写区域/锚点，以及可编辑的 `binding_request` 对象。检查时不改动原项目、不重新生成身份、不进行试排。

把返回的 `binding_request` 对象单独保存为 `bindings.json`，修改其 `bindings` 数组。请求必须且只能包含 `schema_version: inkstruct_template_binding_request_v1`、`project_sha256` 与 `bindings` 三个键。每项沿用 `TemplateBinding`：`region`、`node_ids`，可选 `pages`（`first` / `all`）、`scale`、`anchor`。节点 ID 必须取自本次检查输出；不猜测或根据文本生成 ID。脚注定义不能单独移入固定区，含脚注引用的正文块仍走既有脚注规则。

请求明确采用**全部替换**：要保留的绑定也必须列出；空数组解除全部绑定，未绑定块恢复到正文流。多个块仍按源码次序填写，不按请求中的编号顺序重排。请求中的项目 SHA-256 必须匹配本次加载的完整项目快照；期间有编辑、资源或配置更新时需重新检查。此哈希只锁定输入项目，不替代调用时显式选择的外部模板。

`bind` 用项目内嵌资源和编辑器同一内核试排，检查有效区域/锚点、源身份、缺字和溢出。存在错误时返回非零退出码与诊断，不创建输出项目；警告保留在报告中。通过后只另存到不存在的 `.inkdoc`，保留正文、身份、评审、字形资源与已有选样、样式、路径优化设置，模板相关配置按请求改变。布局可为原先未排过的内容增加确定选样，不能覆盖原有已选字形。

`validate-document` 只读构建并返回页数、实例数、诊断、`exportable` 与 `plotter_exportable`，不写回项目。含位图的项目即使普通预览可导出，也不能直接作为机器 SVG；实际机器出口仍由 `document render --plotter` 完整校验。所有报告都不能代替打印机/写字机的纸面校准。

当前绑定入口仅接收已保存的 `.inkdoc`：纯 Markdown 在每次新会话中会创建不同身份，不可将一次临时解析的 ID 直接用于另一次调用。先用编辑器保存项目，或通过已有 `document render --mode markdown --save-project ...` 创建含资源的原生项目。可复用语义字段已接通，另提供 `slot_request` 契约；GUI 已提供基于当前真实试排的“适配报告…”及问题定位、JSON 另存；Agent 的内容验证返回相同 fit_report。自动建议匹配仍是后续工作，目前不自动猜测“姓名”“实验名称”等字段。
