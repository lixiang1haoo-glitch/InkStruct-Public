## 最终行为

导出弹窗和所有选项保留：指定页码、表格内容、路径优化、横纵比例校正、定位点及位图跳过确认。输出位置选择前仍完成严格校验并冻结 PlotPlan、页序、笔迹、来源和导出范围；后续编辑不改变本次输出。没有重新排版、重选字形或更改原 Markdown。

冻结输入交由后台 QThread 处理，同一排版窗口最多一个导出任务。非模态进度窗口显示优化/写出阶段，允许继续编辑和滚动；再次触发导出返回当前进度窗口。关闭进度窗口也请求取消；关闭应用时先取消并等待清理，再次关闭即可退出。

开启路径优化且至少两页未命中缓存、合计不少于 512 笔时，按页进行 spawn 进程并发。上限为四个进程，同时受页数、可用逻辑 CPU（预留两个）及可用内存预算限制。进程仅在本次导出内复用，结束后回收，没有引入常驻池；单页不拆分候选。少于阈值、未开启优化或缓存命中的工作沿用串行/缓存路径。512 笔是保守接入门槛，并不保证门槛以上的所有小文档都更快，冷启动仍有成本。

子进程运行原 `route_page`，只返回笔序及方向；父进程校验排列、连续执行域与空行程保底，从原始不可变页面重建轨迹及来源记录。没有减少候选、降低预算、精度或机器协议检查。A-B-A 执行域不被合并或跨越；页面按原顺序写出。

启动失败、通信中断、工作进程崩溃、单页超过 120 秒或返回无效决定时，回收本任务的子进程，对未完成页用原算法串行重算。已验证的完成页可保留。串行仍遇到真实错误则报告失败，不把损坏输入当作成功。进程通信独立于调度线程，子进程读取前挂起造成的管道发送阻塞也可取消或超时。串行回退期间的取消在当前页计算返回后处理，不声称可随时中断任意 Python 循环。

输出继续使用新目录暂存和一次性发布，禁止覆盖既有目录。取消与最终发布共享状态锁：取消先发生则清理暂存，不发布半成品；发布先完成则保留成功输出，迟到的取消不能删除结果。原文档和冻结选样不改。路径优化偏好只在成功后、原文档与偏好版本仍匹配时保存；取消不提交，旧任务不覆盖用户期间的新偏好。
