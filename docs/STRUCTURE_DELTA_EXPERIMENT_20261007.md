# 固定风格的结构修复传递与作用范围消融

2026-10-07。接续 `bce906c` 的源结构审计，仍暂停风险分类模型扩展。生产默认不变，不修改原数据库、档案和作者轨迹。

## 本轮解决的问题

源路径修好后，全图重新生成会同时改变笔画签名、原型选择、部件布局、残差尺度及画布适配，可能引入新的交叉。需要区分源修复本身与这些连带变化，而不是把新版参考直接等同于生成质量改善。

核查既有 `ReviewedGeometryProcessor` 后，将其作为 R 对照，不重复声称首次解决黧/瀝近空笔。其余 A/B/C 使用前轮封存输出与同一固定训练档案。

逐笔追踪 64 个受影响组合：

- B 改变 625 笔参考中心线没有变化的生成笔。
- 32 笔签名改变、30 笔 legacy 原型键改变。
- 599 笔残差前跨度出现数值变化，其中 317 笔差异超过 0.000001 字格，避免把浮点尾差全部当成显著改变。
- 4 个组合的整字画布适配参数改变。
- 黧 s1 的残差前跨度从约 0.0038 变为 0.25；瀝 s6 从约 0.0066 变为 0.15，原型键也改变。因此不能把新交叉单独归因于某一个阶段。

## 新实验方法

T：固定 A 的生成风格实现，只传递新旧参考路径的差向量。使用原档案全局线性变换和原画布尺度，不重新选择原型、缩放残差或重算其他笔画布局。

- 去裁剪修复使用源顶点索引一一对应；以恢复后的弧长参数建立变化场，避免旧裁剪造成的重复点吞掉尾部恢复。
- 近空中心线重建后点数不同，使用新旧路径的归一化弧长对应。这是估计，不是作者轨迹对应真值。
- 交付折线包含 A 与修正场的全部参数节点，不再次经过 B-Spline、平均或统一点数降采样。
- 原稿来源标记的笔画保护；其他未修正笔的坐标和压力保持一致，时间按输出笔顺重新排列。

G：T 加既有 0.06 字格位移预算、0.002 步长和间距保护。只允许修正笔移动以消除相对 A 新增的严格交叉；仍有冲突或越界则整字提案回退 A，不重新缩放整字以掩盖越界。逐笔 events 记录提出的传递，顶层 `applied` 表示整个提案最终是否交付。

SB/SC：另做作用范围消融，将 B/C 中对应源修正笔替入 A，其余笔保留 A，使用相同保护。它们是在看到 T/G 结果之后执行的机制研究，不能作为独立留出确认。

这些操作属于参考结构估计的生成实验，不涉及混搭作者真实部件实例。

## 执行与效果

沿用前轮全部 246 个作者—字组合，其中 64 个参考改变、182 个参考不变。包括 144 个有原稿旧回归组合；另有保护字原稿，共 149 个评分组合。没有新增盲测或未观察留出结论。各阶段生成先封存，再读取原稿评分。参数没有按原稿质量寻优。

| 路径 | 输出改变组合 | 未改参考笔被改动 | 协议失败 | 新严格交叉笔对 |
| --- | ---: | ---: | ---: | ---: |
| B 全图重生成 | 64 | 625 | 0 | 6 |
| R 既有近空修复 | 6 | 0 | 0 | 0 |
| T 变化量传递 | 64 | 0 | 3 | 1 |
| G 变化量＋保护 | 61 | 0 | 0 | 0 |

- T/G 在三份真实档案的黧、瀝六个案例均恢复近空笔，弧长从 0.0008–0.0078 恢复到约 0.173–0.275，且**这六例无需平移便没有新严格交叉**。这些字无作者原稿，不能评价作者相似度。
- R 也恢复六例且无新交叉，因此 G 的优势目前是机制更局部、避免这六例的修复后平移，不是已证明作者质量优于 R。
- T 唯一新交叉来自一个缺弯曲修复案例；G 的 0.01 字格平移消除了它。
- G 拒绝 3 个越界提案，返回 A；没有通过大面积回退制造“全通过”：其余 61 个受影响组合实际交付修正。
- G 的 182 个未改参考组合原样返回；全部输出中 2,448 笔未修改笔的坐标和压力核对一致。相对 A，G 也没有删除既有严格交叉。
- 协议检查包括笔数、标准 ID、笔顺、有限坐标、压力、单调时间及画布边界。没有新严格交叉不代表视觉、笔宽接触或自交全部正确。
