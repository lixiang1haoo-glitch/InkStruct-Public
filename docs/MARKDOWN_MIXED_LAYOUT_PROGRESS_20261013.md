### 编辑身份与选样

- `SourceSession` 按真实编辑区间维护字符锚点；前插、删除、复制粘贴、替换、撤销和重做有测试。原样复制也创建新实例，撤销恢复原锚点，revision 单调增加。
- occurrence ID 由文档 ID、源码锚点、显示文字和角色派生，不使用当前行号、页面或前文字符数。身份记录校验原始源码哈希，禁止把 LF 版本套到 CRLF 版本。
- 新 `AssetResolver` 将生成汉字与采集符号转换为同一个 `ResolvedGlyph` 测量接口。基于稳定 occurrence、种子和字符选样，保存实际样本 ID、内容哈希及度量版本；重新打开、添加其他样本或更换种子不替换已有选样。
- 原样本缺失、同 ID 的内容变化或校准变化均产生可识别错误，恢复原资源后再继续；不会悄悄换用另一个写法。
- 内容缓存键与 revision 分开。Qt 编辑事务和 `.inkdoc` 持久化已在 M2 接入；保留旧纯文本检查入口兼容性。

### 固定符号度量与资源缺口

## M3 一般表格混排（阶段完成）

### 当前已实现

`document/tables.py` 把管道表格与受控 HTML 表格归入同一网格模型；HTML 的标签、属性、实体、换行与内容具有原始 scalar 源区间，引用块缩进和 CRLF 也能回溯。单元格接受文字、数字、强调、删除线、链接、行内代码及显式换行。HTML 内使用 `<strong>/<em>/<s>/<del>/<code>/<a>/<br>` 表达行内语义；管道表格使用 Markdown 行内语法。不会把 HTML 数据中的星号自动二次解析为 Markdown。

跨行、跨列、空白单元格均保留；重叠、缺格、跨表头边界的 rowspan、超过预算的网格及任意脚本/事件/不支持 CSS 均有诊断。`cellpadding="6"` 和表级 `text-align` 显式报告采用文档毫米配置，不能把它们当完整 CSS 支持。单元格 `align`、`valign` 与受控 `text-align` 可以表达实际对齐；未知内容不静默丢失。

`TableStyle` 独立于正文，默认总宽 **160 mm**、最小行高 **8 mm**、数字高度 **3.8 mm**、四边留白各 **0.3 mm**。支持内容分配、等宽、比例、固定列宽；一般混排默认按内容分配，旧独立数字工具继续保持原规则。空白标题列仍保留正常宽度。区间约束求解处理相互重叠的 colspan，不用独立列最大值代替跨列约束；固定列宽不足时诊断，不自动缩小整表。

单元格按实际字形测量行高；多行内容默认顶对齐，单行居中。固定行高与最小行高分开，前者内容放不下就阻止成品导出。列可设小数点对齐，整数采用末尾锚点，不补小数点、不转浮点数、不更改原字符串。

导入符号资源时将数字/小数点组冻结为 `numeric_profile_v1`。真实样本的组高度为 **0.756562 em**，与旧数字工具的共同上下界一致；后续加入积分号等不改变数字高度。数字在表内采用紧凑侧边距，只平移原始导向线坐标并统一缩放，不按单字外接框拉伸、不修改原 JSON 或动态信息。该规则解决正文符号留白直接用于窄列时的溢出，同时保留用户确认的尺寸。
