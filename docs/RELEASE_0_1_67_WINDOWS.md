# InkStruct 0.1.67 · Windows

解压完整的 `InkStruct-0.1.67-Windows-x64.zip` 后运行 `InkStruct.exe`。

- 在「设置 › 应用设置 › 主题」选择跟随系统、浅色或深色。默认跟随系统。点「保存」立即切换，点「取消」放弃草稿。
- 公式设置的分类、参数、印刷参考和手写预览使用当前主题。缺字继续用红框标记。
- 主题保存在本机应用设置中。公式几何、文档选样和 SVG 导出沿用原有设置。
