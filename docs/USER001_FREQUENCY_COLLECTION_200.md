# user_001 · 200字部件频数加权采集任务

本任务基于当前结构数据库全部 9,574 个字符统计每个部件身份、部件位置上下文、字形变体、整字结构和笔画几何在多少字符中出现。推荐器以结构库覆盖频数作为权重，同时补齐 `user_001` 现有114字档案的缺口。

## 任务构成

- 180个尚未采集的新字符；
- 20个已有字符的稳定性锚点；
- CSV共200行、200个不重复字符；
- 因部分锚点需要补写2次，总书写动作约220次；
- 完成后预计档案包含294个唯一字符。

新字符首位是“找”：它同时覆盖结构库中342字使用的左侧手部件上下文、341字使用的扌变体，以及当前缺失的戈右部件上下文。它也是改善“我”字扌+戈交叠布局最有价值的近邻样本。“机”用于补齐“讥”末尾几部件的右侧上下文；“信”被保留为稳定性锚点。
