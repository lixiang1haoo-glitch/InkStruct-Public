## 当前交付与实际边界

本次修复解决生成过程中逐点裁切造成的边界压平/截短，并增加采集预防提示。代码已覆盖确定性生成、神经推理几何路径及神经置信度回退。没有重建风格档案、改动原始样本、升级模型或替换标准结构数据。

采集外部内核 `handwriting_collector`、mjb/scx 原始数据与对应档案不在当前工作副本中。已验证的是共享 Qt 提示组件与模拟画布；尚未验收真实手写设备、窗口外笔事件及完整便携 EXE。不能将此交付表述为“所有原稿截断已恢复”或“两个作者全库观感已验收”。后续启动顺序是取得这些数据，然后做小集合回归，不需要先训练模型。

## 问题 6 的实现接口

### 输出几何

- `generate.py`：全局变换和残差不裁切坐标；调用 `cubic_bspline(..., clip=False)`。内部 `_generate_raw()` 供确定性生成与神经记忆混合使用，允许超出画布，不能直接作为外部输出。
- `geometry.py`：`cubic_bspline` 新增关键字参数 `clip`，默认 True，其他旧调用维持原有行为。生成路径明确关闭它。
- `canvas_boundary.py`：`fit_glyph_to_canvas()` 是最终几何出口，在六位小数序列化之前执行。实际越界超过 1e-9 时，将所有笔画用同一个等比缩放和平移放入 `[0.02,0.98]`。能只平移时不缩小，不放大、不逐笔摆放、不改压力、时间或状态。
- 正常轨迹和恰好接触 0/1 的轨迹不移动。小于等于 1e-9 的数值漂移只由原有六位小数舍入消除。不可用/非有限几何被拒绝，不伪装成合法字。
- 神经记忆参与混合时使用未适配几何，避免与模型的未适配控制点混入不同坐标系；整字混合完毕才适配。CPU 预测桩覆盖这段真实推理代码，未运行 CUDA 检查点端到端测试。

`GeneratedGlyph.canvas_fit` 为附加字段：`policy`、`applied`、`original_bbox`、`max_overflow`、`scale`、`translation`、`review_required`。策略固定 `whole_glyph_fit_v1`。当缩放 <0.8 或平移绝对值 >0.2 时提示复核，暂不自动降低部件强度。此阈值为工程提示，不是字形错误概率。

`evaluate_run()` 新增 `canvas_fitted_count` 和 `canvas_review_characters`。基础结构合格与需要观感复核可以同时成立。现有 SVG/PNG 本身有显示留白；本修复发生在轨迹层，不能用仅缩小预览图片替代。

### 采集预防

`capture_boundary.py` 同时被 `collector.py` 和 `packaging/portable_collector.py` 调用。共享逻辑包含：

1. 85% 留白参考框；作为不接收鼠标事件的子控件，不改变采集坐标、不截断输入、不改变数据。
2. 原始点在逻辑画布宽高内检查。靠近边缘 7.5% 区域提示留白，距物理边缘 1 个逻辑像素以内或越界时提示检查。
3. 原有笔数检查通过后，触边保存会询问是否确认完整，默认“否”，允许用户确认后保留合法触边写法。无效坐标或无效画布尺寸拒绝保存。
4. 撤销、清空、轨迹变化和窗口缩放更新状态；尺寸均为逻辑像素，不再乘 devicePixelRatio。

这能防止用户忽略采集边缘风险，不能恢复驱动或外部内核已丢弃的采样点。接手后需核实外部 canvas 的坐标与保存宽高确实采用同一逻辑空间。真实设备应测：四边离开再进入、笔按下时离开窗口、高 DPI、窗口缩放、撤销重录、确认保存与取消保存。源码入口和便携包均需执行。

### 运行目录与版本

新 manifest 的 `run_identity` 包括边界策略、作者、profile/SQLite/checkpoint 文件 SHA-256、部件模式/强度、模型阈值和 PNG 选项。身份在写入 manifest 前检查；manifest 采用临时文件原子替换。相同身份允许取消后续跑；改变身份要求新 run-id。

旧 manifest、损坏 manifest、没有 manifest 的已有轨迹目录不能复用；缓存 JSON 还核对字符、作者、profile 版本与边界策略。不会通过删除原目录来升级。需要生成新 run，比如 `boundary_v1_review`，保留旧输出用于 A/B。

当前没有实现对运行目录的并发锁，也不保证有人手改缓存内容后的全文件完整性；同一 run-id 只允许一个生成进程。SHA-256 记录输入身份，不能替代运行期间对输入文件的冻结。后续不要在生产运行中改写同一个 profile/数据库文件。

## 队友下一步任务及依赖

### T0 建立真实数据基线

输入：问题说明 docx、mjb/scx 原始 JSON 和索引、其生成时使用的 profile、旧输出、外部采集内核。缺失项列出准确路径与哈希，不能自行重建不同档案冒充旧基线。

动作：固定 200–300 字，约一半为原来好看的保护字；覆盖岛/尴、徹/徼/徽、勾/匈/囊、丢/侈/黧。按作者与已见/未见字分层，同字所有重复样本在同一折。先比较旧版与仅边界修复版，复核大幅适配字；若有新明显退化，先定位具体 fit 前轨迹，不急于叠加新算法。

交付：输入清单、固定字表、旧/新 run 路径、匿名对照图和结论。禁止覆盖旧 profile 或输出。边界真实作者回归通过是后续调整默认行为的前提。

### T1 诊断与高保真档案通道

改动范围：`alignment.py`、`schemas.py`、`profile.py`，必要时独立 `trajectory_features.py`。

1. 保持原 16 点匹配计算和错序隔离规则；添加压缩前归一化折线通道，沿标准到用户笔画映射同时携带压力/时间源参数。
2. 新增明确版本的扩展档案字段，保留旧 8 点数组和 40 维模型 token。扩展为空时旧行为不变，旧 JSON 能读、新 JSON 能往返保存。
3. 仅对选择的诊断字记录原始、压缩、原型、布局、平滑、画布适配各阶段；记录源 sample_id、字符、候选 ID、权重和剔除原因。
4. profile 版本哈希纳入构建算法/参数和结构身份。当前 run 哈希已实现，不需要再次改造；profile 的语义版本仍需补充。

测试：矩形画布不改变比例、错序纠正后几何/压力/时间一致、歧义样本不进入新档案、旧 schema 往返兼容、关闭功能时输出逐点不变。

完成定义：能够证明折钩在哪一阶段被削弱，能够从原稿重建高保真轨迹；没有源 JSON 时明确回退而非推测恢复。

### T2 问题 2 特征保留重建

依赖 T1。新建受限曲线解码器，先端点/稳定折点/钩段保护和误差受限折线简化，再选择性平滑无折角片段。不用增加最终节点数替代高保真建档，不一律把作者圆弯变尖。

新路径不能使用旧 8 点 zip 融合。变长轨迹应在共同弧长参数域融合，并显式保留特征点；局部超误差就回退保真折线。先只开放高质量直达样本复杂笔，保持非触发字原输出，再扩展跨字候选。

测试：长折钩、短末钩、圆弯、直笔、稀疏/噪声输入；钩长/末端方向与局部最大偏离；时间单调、正常字不变、最终仍调用统一画布出口。

验收：原稿局部重建偏差中位数目标改善至少 30%、p95 不恶化；匿名评审确认折钩更像原稿。阈值在开发集定，留出集不能用来反复调参。

### T3 问题 3 部件视图和上下文检索

可先准备数据，生成集成在 T1/T2 后进行。改动 `component_style.py`、`profile.py`、`generate.py`，不要改动上游原始数据。

首批攵：在徼中的敫上建立可追溯子视图，使用敫的独立结构 matches 映射到目标标准 stroke_id，验证笔数、顺序和局部形状；映射歧义或缺失则返回旧路径。原型保留外层/内层上下文，不能全局合并所有“右部件”。

实现笔画所有权检查：同一标准笔画只由父或子的一套轨迹负责。优质同字直达父原型优先保留；仅缺证据或确认异常时替换子部件。候选先按作者/变体/笔数硬筛选，再根据宽高比、邻件空间、角色/父布局排序；不全局降低原有证据门槛。

交付：徹/徼/徽成组对照、候选来源和回退报告、父子不重复覆盖测试、缺失映射回退测试。少量候选切换前后检查新增严格交叉/退化/越界，但不在此任务引入大型几何求解器。

### T4 问题 4 整部件实例变化

依赖 T3 的共同候选库。为每个作者/上下文保存最多 3–5 个质量合格的代表实例，全部笔画共享坐标系。先上线确定性上下文选择，再加 opt-in 实例采样；不逐笔混搭，不对每点加随机噪声。

区分同字多次书写的自然变化与跨字的上下文变化。没有可辨别的多个合格实例时不开采样，优先对少量代表字各补采 3–5 次。固定 seed、候选 ID 和有限重试（建议最多 3 次），失败退回确定性结果。

第一版按 variant_id/run_id 产生同字不同版本。当前 generate_run 去重字符，若另需一句话内重复字不同，单独设计 occurrence_id 协议、输出文件命名与预览消费；不要破坏现有 U+XXXX 字库接口。新增 seed/模式/版本必须加入 run_identity。

测试：同 seed 可复现、续跑顺序不改变候选、差异来自真实实例、完整笔数和身份、质量回退。验收看是否像同一作者，而不是坐标方差越大越好。

### T5 小成本审计与后续发版

问题 1：准确区分严格交叉/端点接触；不要用 bbox intersects 作真值。优先丢/侈等少量明显案例，局部换候选或降权，验证回退本身也合格。

问题 5：检查极短笔及源/生成长度比，黧先复核源轮廓；不全库强拉长短笔。问题 7：在现有 canvas 报告旁补最弱笔画、低分 ID、来源与独立 geometry_warnings；置信度不是错误概率。

按 T2、T3、T4 单项消融后再组合。保护集新增已确认严重字形错误必须为 0；所有阈值及评审样本数公开，未覆盖范围和回退率单列。详细建议门槛与预算见总计划。
