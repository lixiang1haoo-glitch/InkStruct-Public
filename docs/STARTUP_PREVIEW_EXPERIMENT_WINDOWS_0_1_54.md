# InkStruct 启动首页实验 · 0.1.54

实验基于当前 0.1.54 源码，通过启动脚本注入对照。使用独立工作区及 INI 设置，正式启动入口未应用原型。

## 输入与计时

只读核对 Windows 现有默认值。当前默认模板、纸张、正文样式和排版参数都与上轮恢复副本一致。模板是四张 PDF 循环版式，实际首页是 PDF 第 1 页，纸张约 195.03 × 270.04 mm。字体是 `user_001-full-candidate-count-validation-8`，454,351,365 字节，核心哈希 `990a5e55986ab411de9c0dd128f88c63dcbae1f525e0cd508368ec11f907daee`。

同一台 Windows 11 主机，Intel Core Ultra 5 250KF Plus，原生 Qt Windows 窗口，1360 × 850 逻辑像素，显示缩放 150%，预览缩放 100%，使用现有 CPU 绘制子进程和预热。计时自拉起进程开始。每次起新 Python 和 Qt 进程，未清除 Windows 文件系统缓存。基线为当前源码启动路径，包含原启动弹窗。安装包启动、系统冷开机和其他设备的时延不在本次测量内。

主窗口可操作由可见窗口中的输入控件获得焦点并处理 QtTest 键盘事件验证。首页实际绘出要求目标页已在窗口画布中绘制缓存图像。背景加载提示和空占位不计入完成。页码样例另外核对真实字形的画布区域确实被绘到。字体可用指现有全包成员校验、索引与该请求所需候选准备结束。

## 主实验

每组 3 次，共 33 次成功，按正序与逆序交替执行。表中为进程启动后的中位数，单位秒。

| 配置 | 策略 | 主窗口处理输入 | 首页实际绘出 | 字体可用 | 弹窗关闭 |
|---|---|---:|---:|---:|---:|
| 简单模板，无字体 | 基线 | 2.25 | 2.31 | — | 2.23 |
| 简单模板，无字体 | 跳过首次防抖 | 2.22 | 2.28 | — | 2.20 |
| PDF 模板，无字体 | 基线 | 2.25 | 2.35 | — | 2.23 |
| PDF 模板，无字体 | 跳过首次防抖 | 2.24 | 2.34 | — | 2.22 |
| PDF 模板，无字体 | 跳过首次防抖，弹窗等首页 | 2.23 | 2.33 | — | 2.33 |
| 当前默认 PDF 模板及大型字体 | 基线 | 2.24 | 8.54 | 8.48 | 2.22 |
| 当前默认 PDF 模板及大型字体 | 只跳过首次防抖 | 2.26 | 8.53 | 8.47 | 2.24 |
| 当前默认 PDF 模板及大型字体 | 提前绘出空白首页 | 2.26 | 2.51 | 8.51 | 2.23 |
| 当前默认 PDF 模板及大型字体 | 提前绘出，弹窗等首页，500 ms 上限 | 2.24 | 2.48 | 8.48 | 2.48 |

默认配置基线从主窗口显示返回到首页绘出的间隔为 6.32 秒（6.32–6.36 秒）。提前绘出原型为 0.27 秒（0.26–0.27 秒）。原型绘制的是同一纸张和原 PDF 底图，提前页与最终页逐对象相等，后续可复用页面绘制结果。默认配置基线的字体索引及全包成员校验耗时 5.33–5.37 秒。模板设置读取首轮约 8 毫秒，首页栅格化约 51 毫秒。字体准备与校验仍约 8.5 秒完成。

基线的 280 ms 编辑计时器已和主窗口构造重叠。跳过首次防抖使默认配置的首次任务提交从窗口显示后约 39 ms 提前到约 22 ms。仅做这一项时，首页变化约 9 ms，处于多次运行的波动范围内。

## 边界补测

边界补测五组各两次，10 次均按预期完成。

- 页码位于首屏可见区域。提前绘制后，底图在启动后 2.48–2.51 秒绘出，真实页码在 8.59–8.61 秒绘出。页码基线为 8.56 秒。带页码时，弹窗在主窗口显示后约 0.50 秒结束。
- 只让弹窗多等约 0.5 秒时，默认 PDF 首页仍在启动后 8.56–8.61 秒绘出。
- 校验中输入“12”的两轮，真实输入在 2.50–2.54 秒被编辑器接受，原暂定页随修订变化失效。当前修订在 8.67–8.72 秒绘出这两个字。当前原型仍需等待进行中的校验结束才可排出依赖字体的新内容。
- 字体路径故意指向隔离目录中不存在的文件时，错误在约 2.29 秒到达，底图在 2.35–2.36 秒绘出。严格导出保持关闭。

如果接入正式路径，优先把空白首页与字体校验拆开。启动任务可以跳过首次防抖，后续编辑保留现有防抖。弹窗可以在首页完成时结束，最多覆盖主窗口显示后的 500 ms。遇到依赖字体的页码或读取失败，主窗口应按上限放出，并在预览区报告进度或错误。真实字体笔迹和严格导出继续以通过校验的当前快照为准。

## 复现

在项目根目录执行，输出目录须尚未存在。脚本只读使用恢复副本与字体。

```powershell
$env:PYTHONPATH = (Resolve-Path src).Path
$e = 'artifacts/startup_experiment_0.1.54'
.venv/Scripts/python.exe -B -X utf8 "$e/startup.py" "$e/recheck-native"
.venv/Scripts/python.exe -B -X utf8 "$e/startup_edges.py" "$e/recheck-edges" --runs 2
```

逐次记录、截图和日志位于 `artifacts/startup_experiment_0.1.54/native-v1/` 与 `native-edges/`。主实验输入身份在 `native-v1/inputs.json`，聚合记录在各自的 `results.json`。
