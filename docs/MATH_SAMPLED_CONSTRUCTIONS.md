# 录制字形构成的公式结构

2026-10-13。按用户要求，分数线、根号及伸缩括号可以使用采集轨迹，作为明确标记的派生几何。原始样本 JSON、笔画次序和样本文件不修改；这项结构适配允许非等比缩放，不改变普通文字/公式字符的等比排版规则。

## 当前默认（0.1.30）

新文档分数线、根号、伸缩括号默认均使用录制字形。紧凑公式策略独立使用 `inkstruct_math_style_v2` 的 `spacing_policy=handwriting`；v1 保留旧版几何与采集留白规则。数学二元/关系/函数标点默认间距分别为 0.08/0.12/0.06 em；分数、根式、括号净距分别为 0.06 em，仍受 1.5 倍笔宽的结构净距保护。上下标 0.7、分子分母 0.8 比例不变。

紧凑根号钩部宽为 0.46 em，上横线分段延长；伸缩括号按样本长宽比和括号类型计算宽度，以设置值为基础上限并保留笔宽保护。竖线不放大横向抖动。显式空格、缺样与退化诊断不变；字形和校正参考框、稳定选样及原始 JSON 保留。

统一入口：齿轮 → 排版默认设置 → 公式。旧文档不自动切换；应用全局默认到当前文档需明确勾选并核对其他默认参数。以下内容含历史验证记录。

## 使用方式

混排编辑器 → “公式设置…” → “分式”“根式”或“括号与定界符” → “构件来源” → “录制字形（缩放适配）”。三类分别设置，实时预览；确定后随 `.inkdoc` 保存，取消不改项目。当前分类恢复默认也重置该类来源。自 0.1.27 起，新文档和恢复默认时的分数线来源为“字体减号 −（横向拉伸，默认）”；根号、括号仍为几何构件。既有文档显式来源和旧记录缺省的几何来源保留。应用级旧默认仅在内存升级分数线来源，明确保存后标记已升级，用户之后可保留几何选择。以下历史样张已将三类设为录制模式。

| 结构 | 样本及适配 |
| --- | --- |
| 分数线 | 使用数学减号 `−`（U+2212），按分子/分母宽度拉长；纵向起伏按当前字号保留，不随线长放大。按真实线迹包围盒计算净距。 |
| 根号 | 使用 `√`，识别钩部/竖部和上横线；保留钩部宽度，按根内内容延长横线，纵向适配高度。支持可识别的一笔及多笔形式。 |
| 伸缩括号 | 使用对应圆括号、方括号、花括号或竖线样本，按内容高度与设置宽度缩放；单/双竖线限制横向抖动放大。包含 left/right、矩阵、分段及编号/引用括号；不可见的点定界符不绘制。 |

相同构件保留稳定选样；编辑根内内容、前插文本、撤销与新增样本池成员不会让已有选样任意改变。项目保存所选资产及原始数据，派生路径保留 asset ID、sample ID 和变换版本，便于追查来源。

不同 Unicode 字符不自动混同：ASCII 连字符 `-` 不能顶替数学减号，`∥` 与 `‖` 也不自动互换。缺少所需字符、样本退化或根号横线无法可靠识别时，给出诊断并阻止成品导出；预览中的几何调试形状不能充当已验证的替代。可另选样本，或显式切换为几何构件。

## 紧凑公式窄数字修复（0.1.31）

紧凑策略中的数字占位不小于 0.315 em（沿用表格默认参考数字高度 0.7 em、最小占位为高度 0.45 倍的约定）；不足部分对称添加到两侧，保留已有较宽占位。只影响数字，不放大小数点或字形。数字参考高度为固定标尺，不按单份样本高度或当前字体池重新归一化。分式和上下标分别使用当前层字号与实际笔宽。该修复直接作用于已有 v2 紧凑策略，不增加协议字段；旧 v1/capture 输出保持。缓存实现版本已更新。


## 2026-10-25 独立排版修复（未发版）

`bar`、`overline`、`underline` 使用与分数线相同的 `fraction_source`。录制模式选取数学减号并只调整横向长度；真实线迹边界用于净距，不随线长放大纵向起伏。资源检查、冻结选样、保存重开与机器导出均记录该来源；显式几何模式保持直线。

伸缩定界符根据内容到数学轴的最大距离确定高度，整体围绕数学轴对称。圆括号与方括号保留端部，花括号保留端部和中腰，仅延长连接区；对跨分段边界的稀疏采样线段插入边界点，保留笔画次序。单/双竖线仍限制横向抖动放大。手写字形没有标准装配元数据，此处属于保形近似，并非完整 TeX 字体大小选择系统。

`\hbar` 与直接输入 `ℏ` 在缺少独立字形时可从 `h`、数学减号合成；英文 h 原笔迹保留，减号仅横向缩短、保留纵向起伏后移到 h 上部；只有 ASCII 连字符时，可作为这个明确合成规则的备用来源。独立字形优先，缺少来源仍报错。全角句点 `．` 可复用英文句号或小数点；保留原文字符身份。

此轮只在 `InkStruct-Layout-Dev` 开发，不改变 APP_VERSION 或主研究目录。验证记录与常用语法边界见 [语法审计](LAYOUT_LATEX_AUDIT_20261025.md)。

规则依据：[KaTeX 定界符实现](https://github.com/KaTeX/KaTeX/blob/main/src/delimiter.ts)、[OpenType MATH GlyphAssembly](https://learn.microsoft.com/en-us/typography/opentype/spec/math#glyphassembly-table)。TeX 的定界符 shortfall 允许括号稍短于内容总高度，不要求上下端都超出完整字形包围盒；横向笔宽净距仍保留。
