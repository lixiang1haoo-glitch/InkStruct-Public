# 已采集整字的原稿优先重建

2026-10-07。基线 `3ee87de`，分支 `codex/observed-glyph-reconstruction`。生产默认不变。

## 实际改变

此前跨字源部件生成会排除目标同字的所有采样。“岛、尴”虽有高保真原稿，实际入口仍可能因缺少跨字供体继续走平滑路径。新增 `--source-observed` 显式优先重建已采集整字，兼容现有 `source-raw` / `source-simplified`；Mac 界面新增默认关闭的“优先保留已采集原稿（同字重建；实验）”。

完整路径保留一个原稿的全部笔画，共用高保真建档坐标系，变换为等比尺度 1、平移 0。不逐笔拉伸，不混合供体，不拟合 A 的布局，不压缩或再次平滑，不重新舍入原顶点。此处“原稿”是建档时保留的归一化原始轨迹，并非重新恢复物理设备尺寸。

轻量简化沿用冻结误差预算 0.004，端点、稳定折点、末段邻域受保护，压力/时间通过保留源点索引取值。整字严格笔间交叉变化则回退到完整原稿。已存在于原稿、但 A 没有的交叉单独记录，不因迎合 A 而删掉原始书写关系。检测不覆盖全部自交与墨迹笔宽接触。

只有标准笔画映射完整、顺序非歧义、坐标/压力有效、笔内时间单调、笔画非退化且逐笔映射分数至少 0.35 的原稿可用。0.35 复用现有局部低分复核边界，不是美学质量概率，本轮未调整。多份合格原稿按最低映射分数、平均映射分数、样本 ID 确定性选择。缺原稿或不合格时沿用现有跨字源路径；没有跨字供体再保留原 A。

训练字符白名单同时约束同字重建和跨字候选。评估未见字时应关闭原稿优先，或把目标整个字符组排除在白名单之外；不能将复制自身纳入跨字泛化指标。输出及日志明确区分两类路径。

## 真实验证

每位作者固定“岛、尴”，其余按样本 ID 哈希补到 64 个已采集目标；额外检查丢、侈、徼、黧四个无原稿字。目标选择不依赖输出效果，参数预先固定。

| 作者 | 已采集目标 | 原稿重建 | 映射拒绝 | B 源点 | C 点数 |
|---|---:|---:|---:|---:|---:|
| scx | 64 | 60 | 4 | 17,889 | 8,393 |
| mjb | 64 | 62 | 2 | 13,759 | 7,458 |
| 总计 | 128 | 122 | 6 | 31,648 | 15,851 |

scx 拒绝字：淙、赓、坟、幢；mjb：懿、掰。拒绝字仍保留在完整图集，未隐藏或计为无损重建成功。

122 字的 B 所有坐标和压力逐项等于原稿，笔数、标准 ID、输出笔顺、有限坐标、压力范围与单调时间通过；跨笔时间按标准笔顺重新安排。C 每个点对应源顶点、保护点全部保留、误差不超过 0.004，严格笔间交叉与 B 一致。点数减少 **49.91%**；这不是“质量提高 49.91%”。

| 指标（仅重建字，字内逐笔再按字平均） | scx A | scx C | mjb A | mjb C |
|---|---:|---:|---:|---:|
| 几何均差 | 0.026758 | 0.000719 | 0.027803 | 0.000744 |
| 末向均差 | 9.69° | 约 0° | 12.69° | 约 0° |
| 弧长绝对相对差 | 9.10% | 0.44% | 11.15% | 0.44% |

B 的几何/末向偏差为浮点误差量级、弧长与端点偏差为零。直接复用原稿接近原稿是预期结果；本次证明实际入口没有额外丢失作者已采集折钩，**不证明跨字生成提升或原稿本身没有噪声**。

scx“岛”s4：A 最大偏差 0.08216、末向差 26.86°；C 为 0.00395、0°。“尴”s3：A 为 0.04813、32.26°；C 为 0.00323、0°。这两笔未被自动短钩指标判为可测量末钩，因此不编造钩长改善百分比；原顶点、局部图和末向检验提供直接证据。

实际写出 408 个 A/B/C 轨迹；272 个 B/C 文件续跑后哈希不变。两个作者各 4 个无原稿目标，开关开/关时的全部字形字段相同，仅增加明确的重建回退诊断。切换开关复用同 run-id 被拒绝，原档案与旧运行未覆盖。

另通过实际 CLI 命令生成 scx“岛尴”，两个字均采用完整原稿，写出成功。

Mac Qt 离屏操作真实窗口与 Worker 生成“岛尴侈劓”，确认默认关闭、岛/尴标注同字重建、侈走跨字回退、劓的 s13 低分仍显示。未验证真实采集设备。

## 使用与报告

```bash
.venv/bin/inkstruct generate --writer scx --text '岛尴侈' \
  --trajectory-mode source-simplified \
  --source-profile profiles/source_v1_20261007/scx/profile.json \
  --source-observed --output-root outputs/observed_experiments
```

不指定 `--source-observed` 保持原先源部件路径；默认 `legacy` 拒绝隐式使用源参数。CLI 使用自动生成的独立 run-id。正式跨字留出评估不应开启同字重建。

本地忽略产物：

- `artifacts/observed_reconstruction_20261007/validation_v2/report/InkStruct_已采集原稿重建报告.html`
- 同目录 `gallery.html`：128 个完整原稿/A/B/C 对照及关键笔画共享范围放大图。
- `validation_v2/frozen_plan.json`：输入、参数与实现哈希；`summary.json` 和 `cases/`：覆盖、逐笔几何、弧长、末向、钩长、来源和回退。
- `artifacts/observed_reconstruction_20261007/ui_v1/`：真实窗口事件测试、截图、日志。

`validation_v1` 保留了首次脚本因列表/元组容器差异误报的记录；修正为逐项精确数值比较后独立运行 v2，没有更改算法参数或覆盖首次结果。

验证：全套 **107 passed, 4 skipped**；新增测试覆盖完整源点/压力/时间、简化误差和交叉、同字重复白名单隔离、六种无效输入回退、续跑身份与默认关闭。相关文件 Ruff 通过。

本轮仅推进已采集字的保真输出。未采集字的末向、复杂布局、自交/笔宽、低质量源稿、真实设备与人类盲评仍是未完成项，继续保持整体目标进行中。
