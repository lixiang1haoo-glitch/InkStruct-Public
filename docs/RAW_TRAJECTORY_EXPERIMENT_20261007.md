# 完整源轨迹直接变换实验：2026-10-07

结论：**完整轨迹适合作为高保真表示；本次证据不支持把它直接设为跨字生成的默认路径。** 固定供体和变换后，B 能避免压缩、平滑造成的折角与末向损伤，C 可在误差受限的前提下减少点数。但目标字的部件实例选择、内部比例和布局仍是瓶颈：跨字留出集 B 的平均几何偏差比 A 大 14.2%，尽管平均末向误差降低了 1.71°。

实验使用已有 Mac `.venv`、scx 真实采集数据及上一轮高保真档案。生产生成器、原有档案和旧输出均未修改。分支为 `codex/raw-trajectory-experiment`，起点 `7a86882`。

## 设计、隔离和比较口径

793 个字符按字符哈希分组为训练 458、开发 179、留出 156；此前已分析的“岛、尴”强制分配到开发集。同字重复样本必须整组分配，本批数据实际没有重复字符组。高保真通道有 778 个可用样本。分别运行同字重建、跨字部件迁移，每类开发 32 字、留出 64 字，共 192 案例、1056 个路径输出。相同目标字可能出现在两类实验中，不能将两类合并为独立样本统计。

跨字候选只能来自训练组，同作者且部件 canonical/variant、位置、父布局、笔数一致，限定非根叶部件至少 2 笔；结构置信度至少 0.8，供体平均映射置信度至少 0.55。只根据标准结构的形态差、宽高比差及训练供体置信度排序。每个目标迁移一个完整部件，所有笔画使用同一变换，其他笔画沿用 A。目标原稿只在输出生成完成后进入评分，不参与候选排序、部件建档、目标包围盒或参数确定。

严格原档案 A 和严格留出不能同时满足：原档案已经包含测试目标。处理方式明确分开：

| 路径 | 同字重建 | 跨字迁移 |
|---|---|---|
| A | 原有完整 scx 档案，v4 adaptive、强度 1.0，固定不变 | 仅训练组重建一次并冻结的档案（454 个成功入档样本）；相同 v4 adaptive 算法及参数 |
| B | 完整源字全部笔画共用一次等比变换 | 一份真实供体部件全部笔画共用一次等比变换 |
| C | 与 B 同源、同变换，先保护特征再做有界简化 | 与 B 同源、同变换，先保护特征再做有界简化 |
| M，补充对照 | 同 B 源轨迹及变换，16 点→8 点→B-Spline | 同 B 供体及变换，16 点→8 点→B-Spline |

M 不做原型平均，不是生产 A。它隔离“轨迹表示变化”的影响；A 与 B/C 的差异仍同时包含原型平均、供体选择和内部布局，不能全部归因于平滑。B/C/M 的目标范围统一来自固定 A 输出对应部分的包围盒，未向目标原稿拟合。

同字参考原稿施加与 B 相同的全字变换；B 的近零误差是恒等复用的预期结果。同字留出仅表示这些字没用于 C 选参，不能把原档案 A 当作从未见过它们，也不能用同字结果证明跨字泛化。

## 开发集参数与轻量简化

C 保留真实源点索引、压力和时间关联；保护端点、起笔邻域、末端邻域及两尺度稳定折点，再对保护点之间使用 RDP。变换后的误差上限换算回源坐标。若简化改变部件内部严格笔间交叉集合，整个部件回退 B，不逐笔混搭。

开发集尝试 ε=0.0005、0.001、0.002、0.004；选择满足预设 P95 几何偏差≤0.004、绝对相对弧长变化≤2%、末向变化≤5°的最大值。冻结 ε=0.004 后才运行留出评分。它是字框坐标误差，不是设备像素误差；例如 1000 像素字框约对应 4 像素。

留出集相对 B 的 C 实测最大偏差：同字 0.00399935，跨字 0.00399445；逐笔末向变化最大分别约 0.0000015°、0.5244°。C 并非所有情况都与 B 完全同向。圆弯也可能因简化而更显折线化，低几何误差不自动代表视觉自然度更高。

C 的拓扑回退：同字开发 3/32、留出 2/64；跨字开发等比 2/32、受限非等比 2/32；跨字留出两种变换均为 0/64。回退已计入结果，没有剔除。

## 跨字迁移结果

64 个留出目标，评估仅限迁移部件，不用整字中未修改的笔画稀释差异。覆盖 32 种上下文、53 个不同供体字。目标原稿保留原始归一化位置，不进行生成阶段的真值对齐。156 个留出字中有 154 个高保真有效样本，其中 62 个找不到符合门槛的训练供体；从剩下 92 个按部件上下文轮转取 64 个。本结果针对有兼容供体的受限子集，不代表全部字符的可迁移覆盖率。

| 路径 | 平均几何偏差 | 弧长绝对相对差 | 末向误差 | 对同供体 B 的几何偏差 | 比 A 更好/更差的字数 |
|---|---:|---:|---:|---:|---:|
| A | 0.040304 | 13.92% | 20.00° | 0.021082 | — |
| B | 0.046024 | 18.31% | 18.29° | ≈0 | 21 / 43 |
| C | 0.046011 | 18.35% | 18.29° | 0.000839 | 20 / 44 |
| M | 0.046526 | 19.17% | 18.67° | 0.001779 | 20 / 44 |

- B 比 A 平均几何偏差大 14.2%，末向平均改善 1.71°。不存在“完整源轨迹普遍更接近目标原稿”的证据。
- B 相对同源 M 的平均几何偏差仅改善约 1.08%；表示保真有所收益，但不足以解决供体/布局偏差。
- 仅在评估时把整个部件等比对齐至原稿包围盒，形状距离 A/B/C/M 为 0.024029 / 0.024551 / 0.024553 / 0.024849。此辅助指标不是生成输入，也没有逐笔对齐；去掉整体位置差后，B 仍未明显优于 A。
- C 点数 5,886→2,529，减少 57.0%，几何结果与 B 接近。对供体 B 的逐笔末向误差，M 平均为 7.30°，C 为 0.0029°：**保留供体末向**的收益清晰，但供体末向未必就是目标最合适的末向。
- 示例“愕→懒”的忄明显改善；同一供体“愕→懈”却是本批几何退步最大的案例。这说明仅部件名称、位置和笔数相容还不足以保证跨字适配。两个极端均展示，完整图集保留所有结果。

短钩使用两尺度转角检测和尾段投影的操作性定义。同字留出命中 13 字/16 笔，跨字仅 3 字/4 笔。跨字钩尾长度绝对差 A/B/C/M 为 0.02845 / 0.03408 / 0.03396 / 0.02035；M 在这个很小子集反而较低。此结果不能被省略，也不能据此断言平滑更好：这是单次采集、少量尾弯，投影指标不等同于语义短钩质量。

## 交叉、退化与不变量

1056 个输出全部通过标准笔数/ID/笔顺、有限坐标、字框边界、压力范围、至少两点及全局单调时间检查；所评估笔画没有弧长小于 0.0001 的退化，也没有缩至原稿弧长 10% 以下。源笔画时间按输出笔顺重新归零、顺次拼接，每笔间隔 60 ms，保留笔内相对时间，不直接拼接原始错序时间。B/C 压力取实际保留的源点，不做原型平均。

跨字 B/C 等比路径各有 6 字比 A 新增严格笔间交叉：啖、羸、录、襁、桩、绵。逐例核查：

- 啖、绵的新增交叉在目标原稿中也存在，不能判为异常。
- 羸、襁、桩有部件内部交叉同时不同于 A 和目标原稿；可能来自供体习惯，需视觉审查。
- 录同时有内部交叉和与部件外笔画的新交叉，明确提示上下文冲突风险。

严格交叉检测包括采样顶点处的横穿，排除全局端点接触、相切及共线重叠；尚不覆盖自交、全部视觉粘连或间距不足。与原稿交叉数量不同不是自动判错依据。同字 B 与 A 新增交叉是原稿已有交叉的恢复，不是恒等变换凭空制造交叉。

## 评估方法及可信范围

不统一输出点数。使用弧长加权的双向点到线段距离，对源点多、插值点多的路径采用同一评估方法。评估积分点不写回输出，绘图直接连接原有点；折点不会因评估被丢弃。局部最大偏差包含全部原始顶点和间隔不超过 0.003 的积分点，是离散近似，理论上可能低估最大值至多约 0.0015，不能称为精确 Hausdorff 距离。末向按参考笔画确定共同的物理弧长窗口。

事后数值敏感性检查仅把积分步长减半至 0.0015：两类留出各取计划顺序的前 16 字；字级平均距离变化最大分别 0.00000113、0.00000198，B/A 排名没有翻转。没有据此改参数或输出。

完整高保真文件物理上仍含留出轨迹，但其只作为评分资料：训练索引与跨字目标交集为零，供体全部属于训练组。集成测试删除目标采集记录后仍能生成跨字 A/B/C/M。计划、档案、源索引、数据库和几何实现均有哈希记录；每例保留供体 ID/源哈希、所有候选、标准笔画映射、变换矩阵、保留源点索引和回退原因。另逐点核验 576 个 B/C 输出中的 68,815 个源点索引，坐标变换、压力和重排后的笔内相对时间全部吻合。

只有一个作者、一次采集，没有盲评、独立重复采集或多作者验证；不做显著性或跨作者推广结论。源轨迹可含噪声，弧长更接近原稿不等于质量更高；本文测量几何保真和目标拟合，没有证明感知风格、可读性或识别率提升。

## 是否替代及逐步接入

1. **适用**：同字回放/重建；真实源实例已确认形态适配的整部件；折角、短钩、末向敏感的高保真存储与生成。B 保留信息最完整；C 可作为空间/点数优化，但应审查圆弯折线化。
2. **暂不适用**：仅按部件名称和笔数就迁移到未知上下文；供体内部比例不同、上下文挤压明显、布局需要非刚性调整、源轨迹噪声明显、映射置信度低或缺少真实供体的情况。
3. **先作为可关闭选项接入**：保持 v4 adaptive 默认；增加整部件原始轨迹解码器和变长点列支持；候选/布局模块与解码器分离。不要再强制把新路径压回 16/8 点。
4. **建立部件准入与回退**：使用独立开发数据确定形态/比例/邻笔间距阈值；新交叉、越界、退化或置信度不足时整部件回退 A。C 改变源拓扑时退回 B，再检查与外部笔画的冲突。非等比变换另设开关与指标。
5. **扩展验证后再改默认**：按字符分组继续保持留出，增加多作者、重复采集和盲评；先灰度启用验证通过的部件。只有跨字目标拟合、风格盲评和异常率同时达标，才讨论替代平滑路径。
