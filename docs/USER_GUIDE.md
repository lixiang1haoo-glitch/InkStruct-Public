# InkStruct Windows 使用说明

## 跨设备采集与制包

- 借用电脑录字前，在「采集 › 书写者资料」导出 `.inkwriter`，到另一台电脑导入并选中该书写者再新建任务。资料文件携带稳定 ID 和显示名称。改名只影响本机显示。
- 把另一台电脑的样本带回来后，在相应的汉字或扩展采集页选中接收者，再从「书写者资料」导入 JSON、ZIP 或目录。确认窗口显示原 ID、目标 ID 和字符范围。应用保存带原样本 ID 和 SHA-256 的副本。
- 如果旧汉字批次和标点 ZIP 已录好，在「制作字体包」选中批次及 ZIP，点「核对并关联书写者…」。核对双方 ID 和样本范围后确认。授权保存在本机，只适用于该批次和该样本内容。同名的不同 ID 需要明确确认。
- `user_002` 这类旧 ID 可继续用于历史批次。要迁移到其他电脑，可新建稳定 ID 并将旧样本导入该书写者，再导出资料。

0.1.83 修复纸张行格在末基线贴近框底时隔行排版的问题。拖动正文框右下控柄时可预览缩短后剩余的行格。

0.1.82 起，Ctrl+S 在后台保存 Markdown 项目，保存期间可以继续编辑。文档无改动时跳过重复写盘。保存期间再次按 Ctrl+S，会在当前保存完成后接着保存最新改动。

0.1.81 在「生成方式」新增 v6.3.1，可读取通过校验的 v6.3 作者档案。默认仍为 v6.3。新批次及由此制作的字体会记录实际使用的方法。

0.1.80 修复带图题的 Markdown 图片与后续正文重叠或间距过大的问题。排版会先留出图片和图题所需的空间，再接排后续内容。

0.1.75 在排版预览中支持图片标注。选中图片，在「元素属性 › 表格与图片」点「编辑图片标注…」。在打开的窗口中点「添加文字…」，再点击图内的放置位置。可输入一行文字或行内公式，例如 `焦点$F_1$`。标注沿用文档字体，可在图上拖动，也可单独调整字号。点「应用」后保存项目，重新打开仍可编辑。写字机 SVG 会输出标注笔迹，单线 SVG 的图形也会随之输出。

[文档站](https://lixiang1haoo-glitch.github.io/InkStruct-Public/)提供带截图的[上手教程](https://lixiang1haoo-glitch.github.io/InkStruct-Public/guide/first-document.html)和[常见问题](https://lixiang1haoo-glitch.github.io/InkStruct-Public/guide/faq.html)。本页供快速查阅。

安装版会检查 Microsoft Visual C++ x64 运行库（14.51 或更新版本）。若提示缺失，打开微软下载，安装运行库后重新运行安装程序。免安装版请完整解压 ZIP 后运行 `InkStruct.exe`。它使用相同的系统运行库。[发行页](https://github.com/lixiang1haoo-glitch/InkStruct-Public/releases/latest) · [微软官方下载](https://aka.ms/vc14/vc_redist.x64.exe)

从 0.1.71 起，字体库预览和采集画布随深浅主题切换。深色采集画布为深灰底白色笔迹。公式设置的手写预览同时显示当前示例的各项实测毫米值，选中项高亮。

1. 打开「采集」并创建书写者，再创建任务。按提示用数位笔录制独立样本。
2. 在「生成」选择书写者、样本目录、目标字和方法。开始生成时会按当前样本准备档案。生成结果中可制作该批次的字体。
3. 制作字体时确认批次、类别和缺字，再等待完整验证与入库。用「字体库」可以管理已完成的字体包。
4. 在「排版」导入 Markdown，选择字体并试排。保存文档会保留关联的排版和字形选择。
5. 在「设置 › 应用设置 › 主题」可选择跟随系统、浅色和深色。

采集时，进度显示在左侧，右侧可调画布大小和屏幕笔迹粗细。汉字的「允许汉字连笔」仍在画布上方左侧。

从 0.1.79 起，汉字与标点采集增量绘制笔迹，每个采样点的坐标、压感和时间戳均照常记录。

汉字采集的「撤销上一笔」「重写当前字」「暂时跳过」「保存并下一个」在笔顺提示与画布之间纵向居中。按钮第二行依次显示 Ctrl+Z、Delete、Shift+Enter 和 Enter。

生成的「计算方式」默认使用自动，小于 128 字时串行，较大任务最多用 4 个进程。需要提速时可选 8 至 32 进程档，或选「高并行（按本机资源）」。实际进程数受字数、可用逻辑处理器及内存限制，可在运行记录中查看。

字体库中的带勾文档图标标出新文档默认字体，蓝线表示当前正在预览的字体。

**录制连笔汉字**时，在「采集 › 汉字样本」勾选「允许汉字连笔」，然后在「生成」选择 **v6.3 exp** 或 **v6.3.1**。建档分别报告可用的连笔整字和部件。

## 同字原稿与生成评分

从 0.1.76 起，v6.3 默认勾选「优先使用已录同字」。同一书写者录过目标字且整字校验通过时，分笔和连笔原稿均可优先使用。字体包可以保留生成备选，自动排版在同字原稿之间轮换。评估跨字生成时，取消这个选项再开始生成。已保存文档继续使用冻结的字形。

在「生成指标」可分别勾选「计算来源分」和「计算多样性分」。结果显示在生成页，并保存到批次目录的 `generation-scores.json`。

- **来源分**衡量笔迹来源。整字原稿回放计 100 分。跨字候选的完整作者部件按标准笔位计 80 分，作者单笔计 60 分，标准骨架计 0 分。先算单字，再按目标字等权平均，并报告整字回放字数。v4 缺少逐笔来源记录。
- **多样性分**按默认排版可轮换的不同字形计分。一个字有 1 份原稿和 3 份生成备选时，可轮换数是 1，该字计 0 分。可轮换数为 2、4、8 时，单字分别约为 20.63、50、80.16 分。未生成的目标字计 0 分，结果同时显示生成覆盖和可轮换字数。

0.1.68 移除了整行采集的旧入口及其运行组件。汉字单字任务和标点与扩展采集继续可用。旧整行任务与轨迹文件仍保存在原工作区。

## 自定义模板纸张行格

在模板工作台选中正文框，将「排版方式」设为「按纸张行格排版」。输入首行基线、末行基线（均从正文框顶部起算）和可用行数，用预览辅助线对齐纸面横线。首末基线都计入行数。

高公式会占用连续行格。表格横边框对齐纸面横线，行高向上取整为行格间距的整数倍。续页可重复表头，表后正文从下一条可用基线继续。辅助线仅用于配置，PDF 底图原有横线仍会显示。旧模板默认按内容排版。

## 按内容确定表格总宽

在「设置 › 排版默认设置 › 表格」可设置新文档的默认方式。修改单张表时，在排版右侧「元素属性 › 表格与图片」选中表格并开启「独立设置」。将「总宽方式」设为「按内容确定」，短表会随内容收窄，较长内容在正文框可用宽度内换行。

「列宽方式」仍控制各列在总宽内的分配，可选择按内容分配、等宽或按比例。固定列宽需要手动总宽。跨页续表沿用同一列宽。

反馈问题时使用新建测试工作区与合成输入。仓库提供两份公式 Markdown 示例。Windows 构建方法见 [README](../README.md)。
