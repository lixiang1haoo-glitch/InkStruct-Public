# InkStruct Windows 使用说明

## 写字机作业（0.1.133）

书写时，每确认完成一笔，侧栏就按剩余笔迹和空走路程更新本页预计剩余时间。暂停期间保留估值，续写时从选定的笔开始，写完后显示 0 秒。

取纸前希望笔尖移开时，在排版右侧「写字机」勾选「写完本页后抬笔回到原点」。此项默认关闭，按设备记忆。每页写完并确认抬笔后，写字机会按当前运动速度返回该页登记的原点。等侧栏提示已到达再取纸；多页作业在此时提示换纸。

排版侧栏和对位窗口共用「落笔 / 抬笔」按钮。落笔使用当前笔具的书写高度，设备到位后按钮会切换为下一项操作。

未登记设备工作范围时，「开始书写」和续写确认框会显示相对当前笔尖的 X/Y 范围，包括笔间空走和边缘余量。现场检查整个矩形都可到达且无夹具，再勾选「我已核实上述区域，仅本次书写使用」。已识别的 N1 在区域内部可连续空走，出现 X/Y 引脚信号时暂停追加指令，核对已发送的轨迹、终点和信号释放情况。控制器报警、偏离轨迹或复核失败时停止。此确认仅对该次发送生效。

连续滚动预览时，写字机侧栏会跟随所选页。首次打开笔迹较多的页面时会显示「正在计算本页预计用时…」，期间可以继续翻页。返回近期查看的页面会复用计算结果；运动速度改变后会按新速度显示估算。

- 写到一半需要离开时，可点「写完本笔并保留进度」。意外中断后，重新打开原文档，连接原设备，并为原稿确认本页对位。界面显示已确认完成的笔数和需要在纸上核对的笔号。对照原稿选择「重写这一笔」或「从下一笔继续」。
- 在「设备管理 → 初始化纸面校准」中记录两个已知纸面位置 A、B，测量设备的方向和比例。需要核验时可用第三点 C 读取横向和纵向偏差。每台设备只保存一组校准，所有页面和摆放共用。
- 换笔或换厚纸时，在设备管理点「校准笔高」。先试触纸，再向右试写 2 mm。看到短线清楚、抬笔离纸后保存。以后可从设备管理直接选择这支笔。
- 侧栏显示本页预计剩余时间。「查看抬笔与空走详情」列出抬笔次数和优化前后的空走距离。默认启用「优化书写路径（同 SVG 导出）」。它与 SVG 导出按同一规则分组、排序和选择笔段方向，减少笔间空走。关闭可沿用源文件的顺序与方向。续写会锁定中断时的顺序与方向，包括旧版留下的笔序。完整执行的书写时段用于校正同一设备、笔具和速度的估时。

未启用软件工作范围时，已识别的炽写 N1 在自动抬笔移动中也会分短段确认到位，长距离空走的实际均速可能降低。持续限位、复合限位、报警或坐标异常会停止。自动运动的故障回包可在工作区的 `plotter-last-motion-fault.json` 查看。

## 本机大容量字体（0.1.118）

在字体库制作字体时，预计候选超过 30,000 份会先提示。选择「保留全部，继续制作」即可保留所选包类型和全部候选。较少候选但带有大量来源详情时，也可先勾选「使用本机大容量模式」。导入这类包时会单独确认。制作、校验与导入可能占用较多内存、临时空间和时间。字体库会标明「本机大容量」。

排版和重开文档沿用已入库的字体。若要在 OpenInk 中使用，选择「导出字体包 → 通用 v1 副本（选择候选）」。可先为每字每种字形选一份，再逐候选调整；导出时校验通用格式的候选数、点数和体积，原字体保留全部数据。

## 生成后的评分（0.1.118）

「计算方式」同时控制生成和评分。需要评分时可单选或同时勾选「计算来源分」和「计算多样性分」。自动模式会按字数、可用内存和处理器数量选择评分进程，大批次最多使用 8 个；高并行和指定进程数沿用设备资源上限。评分阶段单独显示已评分字数。此时点取消会保留已经生成的字形，批次标记评分未完成。

## 导入统一字库（0.1.117）

在「字体库 → 导入字体」选择 .inkfont。统一 v1 字库可以直接排版。InkStruct 旧包会在后台校验并另存为 v1，默认携带数学轴和字形来源。需要保留逐点压力、时间时，从导入按钮的下拉菜单选择「导入旧字体并携带压力与时间」。普通排版只读取字形、来源和公式度量。

旧包的完整副本保存在字体库的 `originals` 子目录，包含原授权与开发记录。打开已有 .inkdoc 时，文档沿用冻结的选字和版面；重新连接原版本时也能找到这份副本。经过完整校验的旧包如果超出 v1 转换预算，仍可按原格式导入。


## 关于 InkStruct

在「设置 → 应用偏好 → 关于」查看应用版本，打开 GitHub 或文档站，也可选中或复制「InkStruct墨构交流群」的群号 1035966437。

## 当前文档的排版设置

在排版页点左下角「设置」，默认打开「当前文档」。弹窗显示项目名和实际参数，源码、并排或预览模式保持打开前的状态。点「应用到当前文档」重新排版，按 Ctrl+S 保存项目。点「取消」放弃各范围内尚未应用或保存的改动。专用页面模板可从「页面设置」进入模板编辑器。

「新建文档默认」供以后新建的文档使用。也可在「当前文档」点「设为新建默认…」，核对本分类现有默认和新值，确认后保存。面板中尚待应用的文档草稿仍可继续编辑。主题、预览绘制和采集显示位于「应用偏好」。

## 写字机 USB 直连

从 Windows 排版页打开「视图 → 写字机设备管理」，添加或选择炽写 N1。InkStruct 按设备保存轴向、X/Y 比例、运动速度和工作范围设置。

### 首次设置纸角和纸面摆放

1. 用抬笔点动确认 X 正向朝右、Y 正向朝下。根据实际运动方向调整镜像、轴交换及比例，保存设备设置。若要「试画 X/Y」，先确认笔尖四周 100 mm 内可绘制。
2. 让纸的两条边靠齐同一组挡边。在「机身定位」中用抬笔点动对准可见、可安全抵达的纸角，点「登记纸角…」。名称可写成「左上挡边 · A4 纵向」。若设备没有 USB 序列号，按提示核对所连实物。
3. 在「设置模板原点…」里单击纸面标记，保存模板。排版时打开「对准纸张…」，点动笔尖对准纸上同一位置，点「将当前笔位设为原点」并确认。按 Ctrl 滚动滚轮可放大，拖动可查看细节。需要换纸沿用时，勾选「使用固定纸张限位」并填写摆放名称。旧模板沿用原有方向和比例，直到为设备保存初始化校准。

模板工作台为每个源版式保存一个纸面原点。修改库中模板后，将新版本应用到当前文档。排版时任选一张已设原点的页，点击「对准纸张…」，把笔尖对到纸上的同一标记并确认。同一设备连接和摆放下，侧栏会显示其他页沿用的来源。每页按自己的纸面原点和设备校准换算笔位。例如 1–4 循环时，在第 1 页对准一次，即可书写全部已设原点的页，包括使用其他源版式的第 2、3、4 页。

缺少纸面原点时，直接点侧栏「补设模板原点…」，在预览中点击纸上的标记，再点「保存并应用」。模板库会保存新修订，当前文档和同一源版式的循环页立即使用。保存文档后重开仍可沿用。同一摆放已经对准时，补设后可直接书写。暂时跳过该版式时，批量书写的确认框会列出跳过的页号。也可以选中该页临时对位并单页书写。重新连接设备后，普通摆放需要重新对准一次；模板中已保存的纸面原点可继续使用。

**换纸。** 同一台设备、同一组挡边、相同纸型和摆放方向下，将新纸靠齐。使用模板时，找回机身基准后，与已登记版式匹配的页面会自动沿用固定摆放。侧栏显示摆放名称、来源版式；本版本在本稿登记的记录还显示登记页号。多页作业仍需确认换纸，再开始下一页。调过挡边或改了纸张朝向，需重新登记摆放。若移动的挡边同时定义了机身纸角，也需更换纸角并重新核对安全范围。PDF 套打或原稿续写时，再用原稿上另一处可见标记核对印刷内容的位置。

**设备重启或重连。** N1 可能在停机的位置重新报零。让纸按原方向靠紧挡边，用短步抬笔点动对准已登记的纸角，点「笔尖已对准纸角」。软件根据当前读数恢复机身坐标，然后可沿用匹配的纸面摆放。若已启用工作范围，此时也会恢复此前在该基准下确认的范围。若纸角会被原稿遮住，可在首次定位后预先登记一个可见、固定的备用点，重连时对准它。旧版摆放仍可载入记录的方向与比例，要在后续重连中复用实地原点，先在新基准下重新记录。发现撞边、打滑或笔位有偏差时停止书写，重新定位并核对纸面。

### 书写与限位提示

在排版右侧的写字机面板、设备管理或当前页对位窗口，方向键旁的「点动步长」可选 0.1、0.5、1、2、5、10、20、50、100 mm，默认 1 mm。选好后按一次方向键移动一步。「运动速度」可选 200、500、1000、2000、2500、3500、5000 mm/min，新设备默认 2500 mm/min。选择速度会立即保存到当前设备，三个入口同步显示，后续点动、空走和书写共用这个 X/Y 速度。已有设备的列表外速度显示为「当前值」，可继续沿用。

新建设备默认关闭「启用安全工作范围」。关闭后，软件不按矩形坐标拦截越界移动。关闭软件工作范围时，已识别的 N1（CX-Elite V2.1.003、控制器硬限位关闭）将手动抬笔点动分成最长约 0.75 mm 的小段，逐段核对到位。运动中若出现一次 X 或 Y 信号，须在终点连续两次报告空闲且引脚释放才继续。信号持续、连续两段触发、空闲时触发或控制器报警，均会停止。 没有已核实范围时，落笔期间上报轴限位会立即停机。请按实际行程、纸面和夹具位置选择点动步长。开始书写前可用「预览落笔区域」和「抬笔试走」核对路径。

要使用范围保护，在设备管理勾选「启用安全工作范围」，输入或记录安全矩形的最小角和最大角，核对后保存。需要重新确认时，核对当前坐标和实际边界，再点「确认本次工作范围」。升级旧设备档案时，已保存有效范围的设备继续启用保护，原来范围为空的设备保持关闭。开关和边界分别保存。

同一笔画的短路径点可分批下发，每批最多六条。开启范围保护、范围已经确认、固件为 CX-Elite V2.1.003 且设备报告硬限位关闭时，软件可以复核范围内部短暂的 X/Y 输入。应用先暂停追加移动，待已发送路径到达预期终点、设备空闲且引脚释放后才继续。边缘出现限位信号、信号持续触发或轨迹异常时停止。控制器报警在两种范围设置下都会停止作业。

## 预览绘制

长篇 Markdown 的屏幕预览由后台进程组装和绘制。调整缩放、切换渲染加速或滚动高倍率页面时，已缓存的页面绘制数据可复用。自动恢复副本仍按原有时机保存。

「设置 › 应用偏好 › 预览绘制 › 渲染加速」默认开启，通过简化路径点加速渲染。简化按当前缩放和屏幕设备像素比计算，笔迹中心线的简化阈值为 0.1 物理像素。切换时立即用现有排版结果重绘可见页，点「保存」可保留选择，「取消」恢复上次保存的选择。导出 SVG 使用原始笔迹和笔序。

在「设置 › 当前文档 › 正文与段落 › 更多正文设置」可调整字母与数字间距。需要让旧项目的正文数字采用字母间距时，勾选「正文数字采用字母间距」，点「应用到当前文档」后保存项目。公式、表格数字和代码各自沿用原有排版规则。

## 段落对齐区块

起止指令各占一行，可包含多个普通正文段落。

```markdown
\begin{paragraphalign}{center}
这一段居中，长句仍会在正文框内自动折行。

这一段也居中，区块可跨页和正文框。
\end{paragraphalign}
```

区块支持 `left`、`center` 和 `right`。区块内每段正文的首行都取消额外缩进。称呼等需要顶格的内容可放在 `left` 区块里，已有的 `left` 区块也按此规则排版。普通正文继续使用文档的正文对齐和首行缩进设置，其中「两端对齐」只拉伸自动折行的非末行。标题、表格、图片、独立公式、列表和引用各自照常排版。

旧文档的 `justify` 区块会按文档的正文对齐和首行缩进排版。两行指令仍会在预览和导出中隐藏，起始指令所在的源码行会提示可删除这两行指令。

区块在文档顶层书写，代码中的指令是原样文本。缺少结束指令、嵌套或参数无效会在对应源码行提示，受影响正文沿用文档默认对齐。

## 样本库

从左下「样本库」或 Alt+6 打开独立页面。左下依次为样本库、字体库、模板库和设置。在「采集」点「样本库…」会打开同一页面，并带入当前书写者。

扫描期间，右侧预览区中央显示「正在读取样本库…」。读取结束后显示结果或对应的空状态。

同字样本按预览区宽度自动换行，样本较多时可纵向滚动。

样本库默认按采集比例显示笔迹。标点、字母和数字依据保存的书写起点、基线和字面大小定位，汉字按录制画布显示。将鼠标放在预览中，按住 Ctrl 滚动可围绕指向的位置缩放。放大后按住左键拖动。「并排比较」同步两边的倍率与视野。点预览区的倍率可恢复默认视野，「参考线」只控制采集参考线的显隐。

在顶部按书写者、字符或 U+ 编码、类别、采集任务筛选。点击左侧字符，在右侧查看原始笔迹、录制时间、采集任务和来源。有多份时，可点缩略图切换，或用「并排比较」在同一比例下对照两份笔迹。「技术详情」可查看原始书写者 ID、哈希和文件位置。

用字符旁的复选框勾选该字在当前筛选内的样本，也可在右侧逐份勾选。目录和缩略图均可用方向键浏览、空格键勾选。同一书写者内切换筛选会保留勾选，底栏标明筛选之外仍勾选的份数。切换书写者时各自保留勾选范围。点「导出所选…」，核对范围后生成 `.inkcapture`。

从样本库的「导入样本」打开采集包、旧 ZIP、JSON 或样本目录。未选择书写者时，按来源记录的书写者导入。本机缺少该书写者时，确认导入后会自动登记。也可以先选本机书写者作为接收者。核对双方身份及新增、重复、冲突数量后确认。新样本连同原始来源保存在本机，重复和冲突项会跳过。采集进度仍通过「任务列表」管理。 [采集包格式](CAPTURE_BUNDLE_FORMAT.md)

在「正文与段落 › 更多正文设置」可选择整字宽或按笔迹紧凑排列。自然书写的「字距变化」可叠加在任一模式上。

## 推荐录制任务

在采集页点击「新建任务…」，可在弹窗顶部选择或新建书写者。采集页已选的书写者会自动带入。汉字可以选择推荐字表或导入 TXT/CSV，标点与扩展可以按类别选字或导入 TXT/CSV。

标点与扩展弹窗先显示类别，点「展开逐字选择」可逐字调整。选定书写者后，已有样本在后台核对，期间可继续编辑字表、份数和任务名称。换书写者后可为新作者重新指定共用供体。确认摘要后点击「创建并开始采集」。

推荐字表按历史字表的前 32、100、400 字累计全集补缺，每字 1 份。例如一位书写者在前 100 字中已有 20 字合格样本，新建 100 字目标时本次待录 80 字。旧任务和导入样本通过相同资格校验后也会计入。

无当前任务时可继续最近未完成任务。录制中的「查看 / 重录」紧邻进度，「暂停并关闭」保留进度。「更多…」提供取消任务，历史任务可在「任务管理…」中查找和恢复。0.1.101 及以前创建的分段任务继续沿用其原始字表、身份和进度。

0.1.103 起，点击「继续录制」后会在后台检查该任务的待录样本。如果在画布上使用的设备与当前「录制输入」不一致，控件旁会显示收到的输入和切换按钮。选好录制方式后，再在画布上落笔。

## 跨设备采集与制包

- 借用电脑录字前，在「采集 › 书写者资料」导出 `.inkwriter`，到另一台电脑导入并选中该书写者再新建任务。资料文件携带稳定 ID 和显示名称。改名只影响本机显示。
- 把另一台电脑的样本带回来后，在相应的汉字或扩展采集页选中接收者，再从「书写者资料」导入 JSON、ZIP 或目录。确认窗口显示原 ID、目标 ID 和字符范围。应用保存带原样本 ID 和 SHA-256 的副本。
- 如果旧汉字批次和标点 ZIP 已录好，在「制作字体包」选中批次及 ZIP，点「核对并关联书写者…」。核对双方 ID 和样本范围后确认。授权保存在本机，只适用于该批次和该样本内容。同名的不同 ID 需要明确确认。
- `user_002` 这类旧 ID 可继续用于历史批次。要迁移到其他电脑，可新建稳定 ID 并将旧样本导入该书写者，再导出资料。

0.1.83 修复纸张行格在末基线贴近框底时隔行排版的问题。拖动正文框右下控柄时可预览缩短后剩余的行格。

0.1.82 起，Ctrl+S 在后台保存 Markdown 项目，保存期间可以继续编辑。文档无改动时跳过重复写盘。保存期间再次按 Ctrl+S，会在当前保存完成后接着保存最新改动。

0.1.81 在「生成方式」新增 v6.3.1，可读取通过校验的 v6.3 作者档案。默认仍为 v6.3。新批次及由此制作的字体会记录实际使用的方法。

0.1.80 修复带图题的 Markdown 图片与后续正文重叠或间距过大的问题。排版会先留出图片和图题所需的空间，再接排后续内容。

0.1.75 在排版预览中支持图片标注。选中图片，在「元素属性 › 表格与图片」点「编辑图片标注…」。在打开的窗口中点「添加文字…」，再点击图内的放置位置。可输入一行文字或行内公式，例如 `焦点$F_1$`。标注沿用文档字体，可在图上拖动，也可单独调整字号。点「应用到当前文档」后保存项目，重新打开仍可编辑。写字机 SVG 会输出标注笔迹，单线 SVG 的图形也会随之输出。

[文档站](https://lixiang1haoo-glitch.github.io/InkStruct-Public/)提供带截图的[上手教程](https://lixiang1haoo-glitch.github.io/InkStruct-Public/guide/first-document.html)和[常见问题](https://lixiang1haoo-glitch.github.io/InkStruct-Public/guide/faq.html)。本页供快速查阅。

安装版会检查 Microsoft Visual C++ x64 运行库（14.51 或更新版本）。若提示缺失，打开微软下载，安装运行库后重新运行安装程序。免安装版请完整解压 ZIP 后运行 `InkStruct.exe`。它使用相同的系统运行库。[发行页](https://github.com/lixiang1haoo-glitch/InkStruct-Public/releases/latest) · [微软官方下载](https://aka.ms/vc14/vc_redist.x64.exe)

从 0.1.71 起，字体库预览和采集画布随深浅主题切换。深色采集画布为深灰底白色笔迹。公式设置的手写预览同时显示当前示例的各项实测毫米值，选中项高亮。

1. 打开「采集」并创建书写者，再创建任务。在「录制输入」中选择「数位笔」「触屏」或「鼠标 / 串流」。汉字与标点页共用此设置，默认「数位笔」，再次打开应用时会记住选择。
2. 在「生成」选择书写者、样本目录、目标字和方法。开始生成时会按当前样本准备档案。生成结果中可制作该批次的字体。
3. 制作字体时确认批次、类别和缺字，再等待完整验证与入库。用「字体库」可以管理已完成的字体包。

触屏使用第一根接触画布的手指。鼠标和串流使用左键按住拖动。触屏和鼠标记录笔迹和时间，压感标为未采集。中断书写时保留已经抬笔的笔段。若串流断开后仍显示正在书写，可按 Esc 取消当前一笔。

在「3 · 生成结果」可以随时打开「历史生成结果…」。窗口默认筛选当前书写者，可切换到全部书写者。选择左侧批次后可以打开结果目录，或直接用该批次制作字体。

在中间的字符列表直接选字，也可按字符或 U+ 编码筛选。右侧可切换生成候选，来源网格同时显示多个来源样本。点选生成笔迹或笔段表中的一行，会高亮对应卡片和已知的原笔迹。连笔覆盖的目标笔位显示在同一行。原文件缺失时，可查看批次和导入索引仍保存的来源信息。

汉字来源按整字笔迹取景，小笔画保留相对比例。生成字形和来源笔迹在预览时平滑绘制。Ctrl + 滚轮以鼠标指向处为中心缩放，放大后可拖动，所有预览同步视野。点击倍率恢复默认视野。「复制复查信息」可复制当前候选的批次和逐笔来源。
4. 在「排版」导入 Markdown，选择字体并试排。保存文档会保留关联的排版和字形选择。
5. 在「设置 › 应用偏好 › 主题」可选择跟随系统、浅色和深色。

采集时，进度显示在左侧，右侧可调画布大小和屏幕笔迹粗细。汉字的「允许汉字连笔」仍在画布上方左侧。

从 0.1.79 起，汉字与标点采集增量绘制笔迹，每个采样点的坐标、压感和时间戳均照常记录。

汉字样本和标点与扩展的「撤销上一笔」「重写当前字」「暂时跳过」「保存并下一个」都紧贴画布左侧纵向排列。按钮第二行依次显示 Ctrl+Z、Delete、Shift+Enter 和 Enter。汉字笔顺提示显示在操作列左边。

生成的「计算方式」默认使用自动，小于 128 字时串行，较大任务最多用 4 个进程。需要提速时可选 8 至 32 进程档，或选「高并行（按本机资源）」。实际进程数受字数、可用逻辑处理器及内存限制，可在运行记录中查看。

字体库中的带勾文档图标标出新文档默认字体，蓝线表示当前正在预览的字体。

**录制连笔汉字**时，在「采集 › 汉字样本」勾选「允许汉字连笔」，然后在「生成」选择 **v6.3 exp** 或 **v6.3.1**。建档分别报告可用的连笔整字和部件。

## 同字原稿与生成评分

从 0.1.76 起，v6.3 默认勾选「优先使用已录同字」。同一书写者录过目标字且整字校验通过时，分笔和连笔原稿均可优先使用。字体包可以保留生成备选，自动排版在同字原稿之间轮换。评估跨字生成时，取消这个选项再开始生成。已保存文档继续使用冻结的字形。

在「生成指标」可分别勾选「计算来源分」和「计算多样性分」。结果显示在生成页，并保存到批次目录的 `generation-scores.json`。

- **来源分**衡量笔迹来源。整字原稿回放计 100 分。跨字候选的完整作者部件按标准笔位计 80 分，作者单笔计 60 分，标准骨架计 0 分。先算单字，再按目标字等权平均，并报告整字回放字数。v4 缺少逐笔来源记录。
- **多样性分**按默认排版可轮换的不同字形计分。一个字有 1 份原稿和 3 份生成备选时，可轮换数是 1，该字计 0 分。可轮换数为 2、4、8 时，单字分别约为 20.63、50、80.16 分。未生成的目标字计 0 分，结果同时显示生成覆盖和可轮换字数。

0.1.68 移除了整行采集的旧入口及其运行组件。汉字单字任务和标点与扩展采集继续可用。旧整行任务与轨迹文件仍保存在原工作区。

## 自定义模板纸张行格

在模板工作台选中正文框，将「排版方式」设为「按纸张行格排版」。输入首行基线、末行基线（均从正文框顶部起算）和可用行数，用预览辅助线对齐纸面横线。首末基线都计入行数。

高公式会占用连续行格。表格横边框对齐纸面横线，行高向上取整为行格间距的整数倍。续页可重复表头，表后正文从下一条可用基线继续。辅助线仅用于配置，PDF 底图原有横线仍会显示。旧模板默认按内容排版。

## 按内容确定表格总宽

在「设置 › 当前文档 › 表格」可调整本文的表格默认，并可将面板值设为新建默认。修改单张表时，在排版右侧「元素属性 › 表格与图片」选中表格并开启「独立设置」。将「总宽方式」设为「按内容确定」，短表会随内容收窄，较长内容在正文框可用宽度内换行。

「列宽方式」仍控制各列在总宽内的分配，可选择按内容分配、等宽或按比例。固定列宽需要手动总宽。跨页续表沿用同一列宽。

反馈问题时使用新建测试工作区与合成输入。仓库提供两份公式 Markdown 示例。Windows 构建方法见 [README](../README.md)。

## 排版导出

在排版页点「导出…」，选择用途并检查导出。

- 「写字机 SVG」按全部、当前或指定页输出可写笔迹。高级设置直接显示路径优化、比例校正、定位点和表格内容。位图跳过前需确认，图题和留白会保留。混合范围内没有可写笔迹的页会跳过，文件保留原页码。
- 「整页排版图」默认 PNG，可切换页面 SVG，同样支持全部、当前或指定页。单页直接保存，多页按原页码写入一个新目录。
- 「整篇 PDF」直接保存为多页 PDF，保留页序和纸张尺寸。笔迹与表格线为矢量，底图和插入的位图仍为位图。

纯底图页可输出排版图和 PDF。检查阻止正常导出时，可点「查看问题」。若范围内还有有效笔迹，可确认「仅导出可用笔迹…」，输出目录附问题清单。右侧「元素属性 → 字符校正」可用方向控件按字高百分比微调位置，核对预览后点「应用字符校正」。旧项目的评价记录随项目往返保存。
