# v6 exp：完整作者部件与完整参考回退

## 架构与边界

- 源档案只包含真实采样完整轨迹，不建 8 点原型、不平均多个形状。不读取旧档案的形状原型、几何残差或布局参数。
- 有满足部件身份、变体、位置角色、笔数及形态门槛的来源时，同一部件所有笔画取自同一次采样，共用一个正等比缩放和平移。不旋转、不逐笔拉伸、不混搭。
- 无候选或候选不通过检查时，逐点保留完整参考中心线。root-only 字在本版全用参考；空源档案也支持参考回退。
- 检索/对齐可以使用 16 点描述锚点，输出始终保留完整原点；无 8 点输出表示、无 B-Spline。
- 当前目标框架是原参考坐标，尚未迁入作者全局字形布局。参考笔画压力固定 0.5、按 700 ms/单位弧长安排时长；源笔画保留压力与内部时间差，按输出笔顺重新安排全局时间，笔间隔 60 ms。
- 需、汤的嵌套部件仅在现有顺序形态验证通过后用于检索，不修改结构库或原始笔画；另存不展开视图的对照，区分表示与候选覆盖贡献。
