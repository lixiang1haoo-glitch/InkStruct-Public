# 完整源轨迹的可选生成入口

日期：2026-10-07。分支 `codex/opt-in-source-generation`，基线 `16ab5b1`。本轮把已验证的整部件算法接入 CLI、批量写出/续跑和 Mac 生成器界面。默认生成不变；总体质量目标尚未全部完成。

## 可以实际使用的功能

- `generate --trajectory-mode legacy`：默认路径，不加载源索引，输出字段与此前一致。
- `source-raw`：完整源部件，所有笔画共享正等比缩放和平移，保留全部源点及压力。
- `source-simplified`：先完成与 raw 完全相同的整字供体选择，再按冻结开发参数 0.004 简化。保护源端点、折点、末端邻域；保留点的压力和笔内时间取自原始索引，按输出笔顺重排全局时间。
- `--source-profile` 指向独立高保真档案。验证作者、源轨迹通道和结构内容哈希；不会把普通 16/8 点档案误当完整源轨迹。
- `--source-nested-views` 允许已验证的敫、多嵌套视图，默认关闭。每个**叶部件**是独立完整单元；不把分别放置的白、方、攵描述成整个敫的一次共同变换。
- `--source-characters` 限定训练字符集。目标同字的全部重复样本始终排除，目标原稿不用于变换拟合和候选选择。

逐个处理不重叠的叶部件。目标布局保持原 A 的对应笔画布局，每次放置检查全字基础不变量、越界、相对当前输出新增严格笔间交叉及长度比。不同部件的碰撞会触发候选拒绝；没有安全供体就保留该部件。轻量简化若改变全字严格交叉关系，回退到**同一个完整供体**，不会改选别的字。

这里没有自动开启已复核的单笔平移、源轮廓推导、非等比缩放或随机扰动；它们仍是独立实验。缺供体时，岛、尴等目标仍可能保留原有平滑问题，不应把接入成功写成这些问题已经解决。

## 输出与续跑

默认 `personal_trajectory_v1` 的内容不变。显式源模式在写出的 JSON 中增加可选 `source_components` 扩展对象，包含：

- 每个部件供体字符、样本 ID、源文件哈希、源/目标标准笔画 ID；
- 所有已考察候选、分数、共同变换、拒绝和回退原因；
- 保留的源点索引、输入/输出点数和源映射支持分数；
- 最低 A 笔画分数、低分笔画 ID、局部几何审计及结构来源警告；
- 输入档案、训练字符表、结构数据库和实现身份。

内存 API `SourceComponentGenerator.generate` 返回 `(glyph, diagnostics)`；额外诊断不是默认 `GeneratedGlyph` 的字段，写出层明确附加。读取实验 JSON 的消费者应识别/忽略可选扩展，不能假定所有顶层 JSON 键都是数据类构造参数。

置信度仍继承 A，明确标为**未经校准**；源映射支持分数也不是生成字形正确率。Mac 界面用简明文字显示供体、局部复核数量、最低 A 分数及低分笔画。详细候选原因和几何风险在轨迹 JSON 中，不用整字平均分掩盖局部问题。

源模式纳入运行身份：改变模式、源档案、训练字符范围、嵌套开关或相关实现后，不能沿用旧 run-id。缓存轨迹也必须包含一致的源运行身份。没有隐式改写旧轨迹或在旧输出上补做平滑；无操作回退保留 A 全部字段。

## 实际验证

### 默认行为

用此前冻结的 80 个 A 输出作基线，与新入口 `legacy` 的结果比较：**每个字段完全一致**，包含全部坐标、点数、压力、时间、笔画来源、置信度和画布记录。证据在 `confirmation_regression_v3/legacy_equivalence.json`。

### 源模式回归

使用旧确认组 scx 27 字、mjb 53 字，并使用该组原训练 A 档案和原训练字符供体范围。该组此前已观察，**这是接入回归，不是新的独立验证，也没有据此调参**。

- 240 个 legacy/raw/simplified 输出全部通过正式评估器的基础不变量。
- 80 字的 raw/simplified 供体和共同变换一致。
- 全部实际源点与供体共同变换逐点匹配，压力与原始/保留点一致，简化原顶点到输出折线距离不超过 0.004。
- raw 无新增相对 A 的严格笔间交叉；simplified 与 raw 的全字严格交叉笔画对一致。它不检查墨迹厚度粘连、所有同笔自交等问题。
- 原始部件 4,275 点 → 简化 2,098 点，减少 50.9%。这里的 0.004 是几何距离界限，不是风格质量保证。
- 80 个 raw 轨迹续跑后文件哈希全部不变。

### Mac 界面

在 Mac 的 Qt 离屏事件循环中，操作实际窗口、选择 `source-simplified`、加载现有 scx 高保真档案，并通过真实后台 Worker 生成“侈徼劓岛”。验证默认仍为 legacy、源参数默认禁用、启用后锁定 adaptive/1、4 字写出成功以及“劓”的 s13 低分显示。离屏验证不覆盖真实手写设备输入。

高保真副档案按钮使用带时间和随机 ID 的独立 `profiles/source_runs/<run>/`，保留既有档案；源模式 GUI 输出位于 `outputs/source_experiments/`。本轮实际生成使用已有副档案，没有重新覆盖原样本/档案。

测试 **88 passed，4 skipped**（既有可选 torch 测试）。新增回归覆盖全部供体点与共同变换、压力/端点保护、原始错序时间重排、两模式供体一致、无供体全字段回退、模式/训练范围变化拒绝续跑、作者/结构不兼容拒绝、默认 CLI/输出不变、写出失败不计为成功使用源部件、取消后安全续跑、替换笔画标注实际部件上下文。相关文件 Ruff 通过。

## 复现

```bash
.venv/bin/python scripts/validate_source_generation_entry.py \
  --plan artifacts/contextual_trajectory_20261007/confirmation_v1/frozen_plan.json \
  --output artifacts/source_entry_new
.venv/bin/python scripts/report_source_generation_entry.py \
  --input artifacts/source_entry_new \
  --plan artifacts/contextual_trajectory_20261007/confirmation_v1/frozen_plan.json
```

输出目录必须未存在。上述回归脚本不负责运行 GUI；报告中的界面截图来自本轮单独的 UI 验证记录，可用 `--ui-screenshot <PNG>` 显式提供。没有截图时报告省略 GUI 验证段落。数据、轨迹、HTML 和图片均在 Git 忽略目录，代码、测试、使用说明与汇总结论提交。

## 仍未完成的质量目标

本轮完成正式入口的可关闭接入，不把它等同于最终字形质量达标。仍需：目标末向兼容策略和新数据确认、同字多次采集/自然实例变化、低覆盖部件的样本补齐、复杂拓扑与真实笔宽评估、真实设备边界采集验收，以及新路径置信度校准。当前证据支持继续试用，生产默认继续保持原算法。
