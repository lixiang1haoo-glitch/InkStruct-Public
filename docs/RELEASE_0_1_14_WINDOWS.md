## 生效与保存规则

修改先保留在弹窗草稿中，切换分类和元素不丢失输入。所有已编辑分类通过原校验后，点击“应用”统一提交，排版更新只安排一次；“确定”应用后关闭；“取消”只放弃尚未应用的修改，已应用结果保留。非法参数会定位到所属分类并显示原因，其他设置不抢先提交。采集配置写入失败时，不提交本轮文档修改。

采集显示参数保存在既有本机配置位置；排版参数属于当前文档，随 `.inkdoc` 保存。打开设置或修改显示比例不会清空尚未保存的笔迹。未修改的参数直接保留原始值，不通过界面精度重新构造全部设置。既有模板绑定、图片资源、各元素覆盖、字形选择、来源确认、评价及导出路径优化选项继续保留。
