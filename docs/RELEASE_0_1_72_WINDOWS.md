# InkStruct 0.1.72 Windows 交付

- 生成页提供手动进程档与按本机资源选择的高并行模式，上限 32 进程。默认自动模式的大任务上限仍为 4 进程。
- 汉字与标点采集进度缩短到左侧，画布大小和笔迹粗细位于右侧。连笔开关仍在汉字画布上方左侧。
- 字体库修复切换预览字体时残留的蓝线，用带勾文档图标标出新文档默认字体。

公开构建的源码提交、依赖哈希、Windows 验证记录和产物 SHA-256 随发布提供。[Windows 安装器与 ZIP](https://github.com/lixiang1haoo-glitch/InkStruct-Public/releases/tag/app-v0.1.72)
