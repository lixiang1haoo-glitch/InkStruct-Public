# 标点与扩展采集（应用 0.1.18）

0.1.11：制作字体时保留原样本的数学轴参考信息，用于公式运算符定位，并随用户版和冻结文档保存。未录轴值不会填入默认值，非法值拒绝发布。旧字体缺少该信息时需用原样本重新制包，既有字体与冻结项目保持原样。

采集包含两个标签：“汉字样本”独占汉字录制，“标点与扩展”共用标点、数字、英文、数学符号及希腊字符录制。没有用户类型或快捷预设。

创建任务时所有字符默认不选，可按类别全选或展开逐字选择。英文大小写分别选择，斜体只录需要的字母。目标份数默认 5；按同作者、同字符、同写法的活动样本补差额。中英共用标点按同一代表字符计数。导入字表自动勾选字表出现的字符，保留字表目标份数，也可继续筛选。

点击“查看笔迹并配置复用…”可逐项确认斜体复用同字母正体、或相似希腊大写字母复用英文正体；没有已录正体时不提供复用。可切换查看每份来源，也可批量勾选后确认。取消不保存；切换作者清除未提交复用。没有选择斜体既不生成样本，也不自动建立复用。可只保存复用配置，无需再录字。

确认关系绑定当时已有的样本 ID，并嵌入新任务 source，不改任务 schema。制作字体选择完整 `symbol_collection` 根目录或包含 tasks/samples 的 ZIP。来源被重录或缺失时要求重新确认，不静默替换；已有独立录制的目标写法优先。原始点列、压力、时间及基线度量保持不变，不机械倾斜；新字体记录 confirmed_reuse 来源。旧字体和冻结排版文档不自动改写。

以下旧版采集和数据约定继续适用，类别全选流程现可改为逐字选择。

当前字符使用 88 px 大字居中预览，英文正体/斜体分别显示对应字形。单击“重录已保存…”可查看旧笔迹并多选误录份次；“选择同字符／写法的全部已保存份次”便于批量纠错。确认后退回所选份次的第一次，重新保存会生成新样本身份，未选中的记录保持不变。“清空当前笔迹”只清除尚未保存的画布内容。

旧样本原始字节与任务快照保存在当前 `symbol_collection/revisions/<revision-id>/`，使用 `.json.bak` 后缀，字体导入和采集对账均不读这些历史备份。原样本不丢失，错误记录退出活动样本目录；已制作字体或冻结文档不会自动修改，需要使用修正后的活动样本重新制作字体。

操作前校验任务是否仍为最新状态。写入失败时恢复原活动样本；中断后的恢复根据任务是否已提交决定回滚或完成日志，避免旧错误样本重新变成已完成。“继续／打开任务”也可打开已完成任务进行纠错。

“创建任务”新增中文专用标点 `。、【】《》〈〉「」『』“”‘’—…`，共 18 个，每字默认 5 份（90 份）。英文直引号 `"`、`'` 加入标点组。原有任务及样本保留，不自动补入新任务项。

以下 12 对中英文标点共用一次录制：`,／，`、`;／；`、`:／：`、`!／！`、`?／？`、`(／（`、`)／）`、`[／［`、`]／］`、`{／｛`、`}／｝`、`%／％`。新任务与 TXT/CSV 导入统一使用 ASCII 代表字符；一份字表同时包含两种字符时去重，份数冲突会报错。采集提示显示共用关系，制作字体时为对应 Unicode 字符建立明确的共享候选，原始点列、压力、时间和采集 JSON 不改写。全角形式按至少一个 em 前进，墨迹不拉伸；来源摘要记录原字符、样本身份、哈希及共享规则，仍保持未审阅状态。

`。` 与 `.`、`、` 与 `,`、`—` 与 `−`/`-`、`…`、书名号和弯引号均不自动合并。已有直接录制的全角样本优先保留，不用共享候选替换。没有执行广义 Unicode 归一化。

旧符号包也可通过新版“制作字体”复用这些笔迹；旧字体包与已冻结文档不会自动改写。完整字体仍需同时选择原汉字生成结果和符号样本。直接导入原始符号 ZIP 的旧排版入口保留原字符集合，共享候选在制作字体时发布。

创建任务窗口中，未勾选类别显示空心灰框，已勾选类别保留系统强调色底和白色对勾；深色与浅色主题均可区分。

2026-10-15：统一应用采集界面提供“汉字样本”和“标点与扩展”，移除整行采集入口和其全局按键监听。汉字保留标准笔数校验；符号允许不同笔数，采集结果可加入同作者字体用于排版。原整行数据和旧任务不删除。

## 使用方法

1. 选择输出目录，打开“标点与扩展”页，填写书写者 ID。
2. 点击“创建任务”。弹窗可填写任务名称、作者，勾选英文正体、英文斜体、数字、运算符与数学符号、希腊字母、希腊变体、括号、标点等类别，设置每字符份数（默认 5，范围 1–100）。显示总样本数，未选类别时禁用创建；取消保留原任务。英文正体与斜体可以同时勾选，同一字母两种写法分别保存并支持续采。也可导入 `configs/collection/symbols_5.csv` 子集后筛选类别；导入保留字表份数，TXT 默认 5，CSV `repeats` 可指定 1—100 份。
3. 在固定画布中参考基线、大小写字高、下伸线和数学轴自然书写。五份可以有不同笔数和自然变化，不要求人为制造差异。可添加“直体”“斜体”“开口 4”等备注。
4. 抬笔后保存，或撤销、重写、跳过。任务进度与样本分开持久化；进度落盘失败时，可从已保存样本恢复。
5. “继续任务”只查找符号任务；关闭窗口时会提醒未保存笔迹。载入的任务绑定原输出目录；切换输出目录后，新建/继续任务才使用新目录，避免同一任务的样本被分散保存。

原始字表包含 188 个 Unicode 字符。英文同时选正体、斜体时分别计数；全部类别均勾选、每字五份时，共 260 个字符/写法、1,300 份样本。以下为未拆分正斜体的原始字表统计：

| 类别 | 字符数 | 样本数 |
|---|---:|---:|
| 数字 | 10 | 50 |
| 英文大写 | 26 | 130 |
| 英文小写 | 26 | 130 |
| 希腊字母大小写 | 48 | 240 |
| 希腊变体 | 8 | 40 |
| 数学符号与标点 | 70 | 350 |

字表保留 Unicode 身份，不做兼容归一化；例如 `φ` / `ϕ`、`ε` / `ϵ`、`-` / `−` 分开保存。只接受字表内的单字符，不把 LaTeX 命令、完整公式或多码点组合当作一个字形。所有采集快捷键限制在对应标签页，避免 Enter 同时保存汉字和符号。

## 数据与度量

输出目录：

```text
<output>/symbol_collection/
  tasks/<task-id>/state.json
  samples/<writer-id>/U+XXXX/<sample-id>.json
```

使用独立 `inkstruct_symbol_sample_v1` 格式，不混入 `handwriting_single_v1` 汉字训练数据。保存：

- 原始逻辑像素坐标、压力、时间、分笔与顺序，实际笔数，作者和任务身份，以及第几份/总份数。
- 固定参考框版本、原点、基线、em 尺寸、大小写字高、下伸量与数学轴。逻辑画布固定 560 × 320，em 为 200 逻辑像素；窗口或 DPI 变化不重新缩放原轨迹，DPI 比例另存。
- 基于参考线的 em 墨迹包围盒、上伸/下伸、左右边距及初步字宽。原始坐标方向向下，度量坐标方向向上；换算规则由 guides 与 metrics 字段明确记录。
- 字符语义类别、数学排版类别提示、写法备注和独立样本 ID。数学类别需结合上下文，例如减号可是一元或二元运算符，竖线可作定界符。

度量状态为 `guide_based_unreviewed`。字宽暂按最右墨迹加 0.08 em 估算；这不是经过人工校准的字体度量。样本不会按自身包围盒拉成同样大小，因此小写、下伸字母和符号的位置关系仍可恢复。数据未进行自动质量评分，所有新样本的审阅状态为未审阅。

未来可把同作者、同字符的合格样本作为候选，每次出现随机抽取；应记录随机种子和实际样本 ID，保证预览、导出及重新打开结果一致。样本池仍需筛除明显坏样本；直体/斜体等差别大的风格宜按备注筛选，不能保证任意五份随机混合都协调。上下标由排版层变换样本；根号、分数线、伸缩括号、大运算符布局、斜体修正及附件锚点需后续实现，不能只靠整字符随机抽取完成。

## 0.1.33 字体合成规则

来源齐全且目标不存在时，制作新字体自动应用 `recorded-symbol-constructions-v1`：℃ 用中文句号缩小抬高并与英文正体 C 合成；– 完整复用 U+2212 减号笔迹和度量；～ 从恰有两笔的约等号中分别提取一笔并移至数学轴，候选数为约等号的两倍。已有独立目标字形优先，不猜测拆分一笔或多笔约等号。保留点列、动态值与来源；摄氏度组合时明确记录变换及时间平移，非独立录制。旧字体扩展时另存新包，已有候选身份和数据保留。

## 0.1.34 录制数学符号规则

新规则身份为 `recorded-math-symbols-v1`，原 `recorded-symbol-constructions-v1` 和旧候选不改写。

- `*`（U+002A）、`∗`（U+2217）：合格的一笔减号按候选 ID 排序，循环配对相邻三份，缩至共同长度（最短来源的 65%，上限 0.42 em），分别旋转 0°、60°、120°并中心对齐；每个目标产生 N 份候选。N 不足 3 时明确记录重复来源。两字符可共享几何及构造身份，候选与 Unicode 身份独立。公式 `*` 仍解析为 `∗`。
- `∶`（U+2236）：目标缺失时优先选择合格全角冒号，其次半角冒号；完整笔迹等比缩至最大跨度 0.36 em，中心移至数学轴。保留原冒号身份和候选，不做 Unicode 归一化。数学比号使用关系类间距。
- `∘`（U+2218，`\circ`）：目标缺失时完整复用中文句号，等比缩至最大跨度 0.18 em，中心移至数学轴。保持原 `ord` 类别，不改为度数符号。

新结果 `source_kind=composed`，不携带伪造的采集参考线。`symbol_construction` 包含独立规则版本、来源候选/轨迹/度量/来源摘要哈希、原笔序与笔画身份、六参数仿射矩阵、各组件时间平移、构造身份、明确的构造数学轴和轴依据。压力与笔状态逐点保留；多来源组合仅平移时间并标记 `inherited_retimed`，单来源复用的时间保持原值。来源分区、缺口、警告继续传递，单点笔迹仍须机器适配。

禁用、拒绝、非录制或退化来源不会制造目标候选。新字体制作自动应用；扩展旧包通过 `inkstruct.fonts.symbol_rules.extend_font` 独占另存，返回可检查的 `construction_diagnostics`。缺失目标继续在排版中产生真实缺字错误。已有目标不替换，旧文档不会自动切换新包。
