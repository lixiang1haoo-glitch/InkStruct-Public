# InkStruct（墨构）实现与验收记录

记录日期：2026-08-19

## 交付状态

本次重构已建立一条可独立运行的结构先验流水线：原始在线 JSON 导入、标准笔画对齐、缓存式用户风格档案、主动补采推荐、确定性结构保持生成、分层神经模型原型、CLI、桌面整合、SVG/PNG 预览和评测。

原始用户 JSON 始终只读；InkStruct 当前产物写入 `artifacts`、`profiles` 和 `outputs`。旧 SDT 代码、权重和历史生成结果已在项目改名时清理。

## 已实现组件

- `src/inkstruct`：统一 Python 包及 `inkstruct` CLI。
- `CharacterGraph`：标准中心线、顺序、递归部件树、部件身份/变体/角色、部件包围盒、几何签名与笔画关系。
- `RawSample`、`AlignedGlyph`、`StyleProfile`、`GeneratedGlyph`：版本化协议与 `[0,1]`、左上原点、Y 向下坐标约定。
- 一对一优先及拆笔/合笔动态对齐；复杂映射不写入局部残差原型。
- 用户档案一次读入、版本化缓存；批量生成只读取档案，不重复扫描原始 JSON 或风格图片。
- 确定性生成：整字布局、条件化局部残差、B-Spline 平滑、用户化时间和压力。
- 分层模型：256 维，4 层风格编码器、6 层结构编码器、4 层解码器、每笔 8 个控制点；支持 CUDA episodic 训练、断点和低置信回退。
- 桌面端：拆分为独立轨迹采集器与独立风格生成器；采集器按结构库实时校验笔画数，生成器负责导入、建档、指定文本/全部生成、后台进度、取消与断点续跑。
- 旧 SDT 的 128×128、85% 字面率、固定线宽逻辑仅作为兼容适配思路保留，不进入新在线轨迹主流程。

## 2026-08-20 整组部件轨迹 v4

- `StyleProfile` 升级为 `style_profile_v4`，新增跨字符聚合与字符直达两类 `ComponentTrajectoryPrototype`。部件全部笔画共享同一个局部坐标系，同时保存8点控制轨迹、压力和时长。
