# InkStruct 用户手册源码

`main.tex` 是入口；使用 XeLaTeX，中文采用 TeX Live 的 Fandol 字体，不依赖本机中文字体。PDF 为用户文档；本文件用于维护和构建，不随正文展示内部实施细节。

## 构建

在本目录运行：

```sh
latexmk -xelatex -interaction=nonstopmode -halt-on-error -outdir=build main.tex
```

`build/main.pdf` 为编译结果。适用版本见 `main.tex` 标题页。历史 0.1.3 PDF 保存在 `artifacts/release_0_1_3/release/InkStruct用户手册_0.1.3.pdf`。将包含各章节和截图的整个手册目录复制到安装 TeX Live 的电脑，即可重新编译。

## 维护结构

- `00-reading`：适用版本、阅读路径和状态说明。
- `01`–`02`：共享概念与首次上手；跨模块共性尽量集中在此。
- `03`–`09`：编辑排版完整操作，按用户任务拆章。
- `10-generation`：v6.2/v6.1/v4、可选真实候选数量、导入建档、来源警告、不可变批次和字体交接。
- `11-capture`：统一采集页、汉字与符号交接、设备验收边界。
- `12`–`13`：故障速查与 Agent 协作附录。

后续生成、采集模块集成时，将各预留章扩成对应分部的多个章节。每章按“用途与准备 → 入口 → 操作 → 结果 → 常见问题”编写。统一使用 `\label` / `\ref` 交叉引用，避免插章后手动修页码；不要把分部和章节编号写死到截图或文案中。操作名称必须核对对应交付版本，独立程序已有能力与统一应用新入口要分开标明。

`examples/` 中三个 Markdown 示例仅使用内置数字和几何构件，可直接试排。其他正文示例含中文、字母和数学运算符，需要相应资源。Markdown 文件使用单美元行内公式和独立成行的双美元展示公式。

## 内容依据

本轮版本与大字体/候选数量说明核对日期2026-11-04，其余章节与历史截图按原记录保留。主要依据 `src/inkstruct/editor/workspace.py`、`document/schema.py` 与当前 Markdown、表格、数学、模板、图片、资源检查、恢复文档。以当前源码和交付版入口为准，历史开发记录中的旧按钮和未更新能力不直接照搬。

截图来自界面整理验收中的 workspace/review 以及录制构件验收中的分式设置，原图复制保存在 `assets/`，不是产品界面设计稿。对应资源与应用状态可能随以后版本改变，更新手册时应一并替换截图。
