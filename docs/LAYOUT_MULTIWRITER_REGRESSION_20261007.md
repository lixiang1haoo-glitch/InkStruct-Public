## 固定与隔离

- 既有比较集：scx 27 字、mjb 53 字来自上下文迁移原实验，wsq 64 字来自末向原实验。每字一次采样；都是已观察资料，不能称新留出或独立泛化验证。
- A、D 从原实验逐字段恢复，旧 v4 档案、参数、部件供体和输出固定。只检验轨迹整体布局变化，不重新选择候选，不逐笔缩放，不混搭，不进行 16/8 点压缩或平滑。
- 正式受检方案 M：上轮开发冻结的标称强度 1.0，训练经验决定实际强度，朝公共部件中心/跨度移动。B 是同供体、同实际强度、朝学习中心/跨度的诊断对照；本轮不重新在 B/M 中选优。这里的 B/M 是布局实验标签，不是最初三路径实验的 B/C。
- 每位作者分别过滤全部训练字原始记录，再建立布局证据和留一校准。沿用原算法的最低样本数、分位数、MAD 下限和回退条件；作者不同，经验半径自然不同，不复制 user_001 的具体数值。
- scx：450 个训练字，446 个校准字，半径 5.383790；mjb：242 / 233，半径 5.987116；wsq：456 / 452，半径 5.040574。
- 相同部件上下文预测数分别为 27、33、46；mjb 20 字、wsq 18 字使用相同角色和父布局回退。因此不能将所有 144 字都写成严格同部件参考。
- 原始归档包含目标记录，适配阶段先按原固定字分组过滤，只将训练记录传给证据模型。已有 A/D 文件也包含原稿，白名单导出仅保留任务公开身份、目标笔画 ID、A/D 与 D 供体，剔除原稿、原稿指标、目标采样 ID 和未使用候选。所有 144 字输出先落盘并写生成哈希清单，之后评分器才读取原稿。
- 继承的旧名单曾以原稿映射是否合格筛选，因此不声称本轮是全目标盲选。目标没有进入本轮布局建档、校准或移动决策。

原有质量门槛不变：平均几何严格改善、平均末向不超过 D +0.5°、每字几何不超过 1.05D、每笔局部最大偏差增量不超过 0.005、源路径启用不减少。D 与关闭路径作为基线，不需要严格优于自身。

B 也不能解决反例：scx「涤」约 +10.11%，wsq「铜」约 +45.82%。不用切换到 B 掩盖 M 的失败。

评分后的诊断发现，scx「涤」真实原稿到经验中心的标准化距离为 **6.8032**，超过半径 **5.3838**；wsq「铜」为 **5.7351**，超过半径 **5.0406**。两者都是合法真实样本，却位于经验范围之外。涤原 D 距离为 6.7311，甚至与原稿的偏离幅度相近，拉回会损害原有布局。

这只说明当前经验范围不是可靠的质量判别器，不证明所有范围外样本都自然，也不证明范围内样本都正确。原稿也可能有采集噪声；末钩、弧长和自然性仍需结合图像与人工审阅。原稿诊断仅写入报告，未用于回调生成。

## 核验和交付

- 720 个输出（A、D、B、M、关闭各 144 个）；核对 66,712 个源点和 1,088 次参考来源。
- 检查完整点数、共同正等比变换、压力和笔内时间，标准 ID、笔数、笔顺、有限坐标、字框与退化；全局时间单调。部件外坐标保持不变，供体实例固定，关闭输出与 D 全字段一致。
- 无相对 A 新增严格笔间交叉；此检查不覆盖自交、共线重合或笔宽接触，不能当成完整视觉拓扑保证。
- 相同弧长积分/线段距离方法处理不同点数输出。保存部件和整字几何、最大局部偏差、弧长比例/误差、末向、末端误差及操作性短钩指标。弧长接近不单独代表质量，短钩指标不是人工标注。
- 新增 2 项数据边界测试：任意替换目标原稿、评估指标和采样 ID 不影响推理输入；同字多次采样全部留在同一分组。全套 **134 passed、4 skipped**，跳过项为可选 torch 依赖；Ruff 与差异空白检查通过。
