InkStruct（墨构）轻量轨迹采集器
====================

运行方式
--------
双击 InkStructCollector.exe。

首次运行
--------
1. 选择数据输出目录。建议选择单独的数据文件夹，不要选择程序目录。
2. 填写书写者 ID。
3. 在“单字任务采集”中导入 TXT 或 CSV 字表。
4. 完成本轮重录时，可导入 user_001_rerecord.csv。

笔画数校验
----------
界面实时显示“当前笔数 / 标准笔数”。笔数不一致或字符不在结构库中时，
保存按钮不可用，轨迹不会写入磁盘。可使用“撤销上一笔”或“重写当前字”。

输出
----
兼容 handwriting_single_v1：
  <输出目录>\samples\<writer-id>\U+XXXX\<sample-id>.json

说明
----
本目录只包含采集所需运行时和约 9574 字的标准笔画数映射，不包含 InkStruct
生成器、结构数据库、PyTorch、CUDA、模型权重、训练数据或用户历史样本。
请整体复制本文件夹，不要只复制 exe；_internal 目录是程序运行所必需的。
